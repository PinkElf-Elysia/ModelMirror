## 完成结果

你会了解模镜的整体结构：从哪里找 AI 能力，到哪里完成任务，以及在哪里查看运行和连接状态。

## 适用对象

适合第一次使用模镜，或在多个入口之间不确定下一步的人。

## 开始前

先想清楚要完成的任务。无需一次学会所有模块，只阅读与你当前任务有关的部分。

## 真实范例

你要让模型查看一张图片。先在“模型”中选择能力并进入聊天；如果以后要重复同一角色，再考虑 Agent；如果要固定多个步骤，再使用 Workflow。运行失败或工具未连接时，到 Runtime 查看状态。

## 模镜怎样组织能力

可以把模镜分成三层：

| 你正在做什么 | 去哪里 | 说明 |
| --- | --- | --- |
| 找能力 | 模型、Agent、MCP、Skill、提示词 | 选择完成任务所需的模型、角色、工具、做法或模板 |
| 做任务 | 聊天、经典工作流、RAG、Coding、Agent Studio | 输入内容、组织流程或管理可重复使用的配置 |
| 查状态 | Runtime 运维 | 查看运行记录、MCP 连接、客户端宿主和环境依赖是否就绪 |

系统设置用于管理服务连接和功能开关，通常只由有权限的人操作。

## 稳定资源入口

| 入口 | 白话说明 | 适合先解决的问题 |
| --- | --- | --- |
| 模型 | 按输入、任务、状态和价格筛选模型，再进入聊天 | “哪个模型能直接完成这次任务？” |
| Agent | 浏览可重复使用的角色，也可进入 Agent Studio、AI 工作流生成器和专家团 | “是否要反复使用同一角色或多角色协作？” |
| MCP | 浏览外部工具，并区分目录、连接和可运行状态 | “AI 需要连接哪个工具？” |
| Skill | 浏览、创建或导入可重复使用的做法 | “这套方法是否值得保存下来？” |
| Runtime 运维 | 只读查看运行、连接和环境状态 | “任务为什么失败，连接是否就绪？” |
| 提示词 | 使用模板起草对话，或管理可发布的 Prompt Command | “有没有接近当前任务的提问模板？” |

“帮助”是独立工具入口，不是第七类资源。

## 工作台与设置

- **RAG 知识库**：创建资料库、上传文档，并让回答引用资料。上传前先确认资料可以用于该环境。
- **Coding**：当前页面是只读实验入口，只能读取项目并回答问题；本次验证环境显示“代码助手暂时不可用”。
- **Agent Studio**：创建和管理 Agent，配置模型、Toolset、知识和 Handoff。真实入口是 `/agents/studio`。
- **系统设置**：管理 Provider 等服务连接。当前未配置时会明确提示，普通用户不应自行填写不明凭据。

## 实验功能

- **矩阵绿洲**：当前是预告页，页面显示“世界仍在生成”。
- **Science**：本次验证没有发现独立页面，访问现有地址会回到模型市场。

实验功能的入口和范围可能变化，应以当前页面为准。

## 模型卡片常用词

| 页面用语 | 表示什么 |
| --- | --- |
| 可接收输入 | 模型声明能接收的内容形式，例如文本、图片、文件、音频或视频 |
| 可完成任务 | 模型适合完成的工作，例如图片识别或视频生成 |
| 立即面试 | 当前卡片提供可进入的交互入口；仍需在发送前检查费用和数据影响 |
| 交互待适配 | 目录里有该能力，但当前交互入口还未准备好 |
| 已适配 · 开关未开启 | 功能已有适配，但当前环境尚未启用 |
| 配置实时语音 | 该能力需要先完成相关连接配置 |
| 文件输入 · 当前入口未开放 | 当前聊天入口不能使用文件输入，请改用已开放入口 |
| 输入薪资 / 输出薪资 | 页面用“薪资”比喻调用价格；单位和计费方式要以卡片当前提示为准 |

## 常见问题

### “已适配”是否等于现在一定可用？

不等于。还要查看开关、连接、按钮状态和当前入口提示。

### “图片”与“图片识别”有什么区别？

“图片”是输入形式，“图片识别”是任务能力。找看图模型时建议同时确认两项。

### 为什么有些价格写“动态”或“按媒体计费”？

这表示不能只按固定文本价格理解。调用前要查看当前卡片和实际连接的最新提示。
