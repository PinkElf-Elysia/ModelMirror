## 完成结果

你会知道当前任务应该从哪个入口开始，以及需要资料、工具、固定流程或故障排查时该去哪里。

## 适用对象

适合第一次使用模镜，或在模型、Agent、工作流等入口之间拿不准的人。

## 开始前

先用一句话写下要完成的事。只判断眼前任务，不需要先学会所有模块。

## 用一次图片检查理解这些入口

临时查看一张新品图片时，先到“模型”筛选能够接收图片并完成图片识别的模型，再进入聊天。如果以后每周都要由同一位品牌顾问检查图片，可以把角色和要求保存为 Agent；如果每次还要读取资料、生成文案并交给人工确认，可以把这些步骤放进经典工作流。

任务需要公司资料时使用 RAG 知识库，需要连接外部服务时查看 MCP。运行失败或工具没有连接时，到 Runtime 运维查看状态。

## 先按目标选择入口

| 你要完成的事 | 先去哪里 | 什么时候使用 |
| --- | --- | --- |
| 完成一次问答、写作、看图或临时分析 | [模型](/help/modules/models) | 直接选择能力并进入聊天 |
| 反复使用同一角色和工作要求 | [Agent](/help/modules/agents) | 保存角色、说明和所需工具 |
| 每次按固定顺序处理多个步骤 | [经典工作流](/help/modules/workspace/workflow) | 固定步骤、分支和人工确认点 |
| 根据指定资料回答 | [RAG 知识库](/help/modules/workspace/rag) | 让回答先从自己的资料中查找内容 |
| 连接外部服务或工具 | [MCP](/help/modules/mcps) | 查看工具目录、连接和运行状态 |
| 保存可重复使用的做法 | [Skill](/help/modules/skills) | 创建、导入或安装可复用的方法 |
| 从现成模板开始提问 | [提示词](/help/modules/prompts) | 把接近当前任务的模板填入对话草稿 |
| 查找失败原因或连接状态 | [Runtime 运维](/help/modules/runtime) | 查看运行记录、客户端宿主和运行资源 |

系统设置用于管理模型服务提供方和其他连接，通常由有权限的人操作。

## 模块之间怎样配合

- **模型**通常是一次性任务最短的入口。
- **Agent**用于保存可重复使用的角色。Agent Studio、AI 工作流生成器和专家团都归在 Agent 下，其中专家团用于多角色协作。
- **经典工作流**位于“工作台与设置”，用于固定多步过程。Workflow Native 是单独的实验功能，不替代经典工作流。
- **工作台与设置**还包括 RAG 知识库、本地数据表、Coding 和系统设置。Coding 当前是只读实验入口；不可用时不要把它当成已开放能力。
- **实验功能**包括 Workflow Native、Science 和矩阵绿洲。入口、范围和行为都可能变化，应以页面当前显示为准。

完整入口见[按模块浏览](/help/sections/modules)。

## 常用词是什么意思

| 页面用语 | 白话说明 |
| --- | --- |
| Agent | 保存下来的角色、要求和工具组合，便于以后重复使用 |
| Workflow | 按固定顺序连接多个步骤的工作流 |
| MCP | 让 AI 连接外部工具或服务的方式 |
| Skill | 可以安装、创建和重复使用的做法 |
| RAG | 先从指定资料中查找内容，再让模型回答 |
| Runtime | 查看运行记录、连接和环境是否就绪的运维页面 |
| Provider | 提供模型或其他服务的连接方，通常由管理员配置 |

## 看见入口不等于现在可用

进入页面后还要检查三件事：按钮是否可用，当前环境是否已经配置，以及这次操作是否会发送数据或产生费用。目录中有某项能力，只能说明可以查到它，不能证明真实调用已经验证。

发送、上传或启用工具前，阅读[操作前检查可用性、费用与数据影响](/help/check-availability-cost-data)。遇到“待适配”“开关未开启”或“需要配置”等提示时，阅读[功能暂不可用时怎么办](/help/recover-unavailable-feature)。

## 常见问题

### 完全不确定从哪里开始怎么办？

先用模型完成一次真实任务。之后再判断需要重复的是角色，还是整个多步过程。

### 专家团为什么不单独列为一个模块？

专家团处理的是多角色协作，属于 Agent 下的二级功能。可以从 Agent 目录进入。

### Runtime 能直接修复失败任务吗？

Runtime 主要用于查看状态和定位问题。需要修改 Agent、工作流、MCP 或设置时，应回到对应模块操作。

## 限制

本文帮助你选择入口，不代表目录中的每项能力都已配置或可以真实运行。具体按钮、状态、费用和数据范围以当前页面提示为准。
