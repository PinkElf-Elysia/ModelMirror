## 常见问题

### 为什么选了“图片”还要选“图片识别”？

“图片”说明模型能接收这种输入；“图片识别”说明它能完成看图理解任务。两个条件一起使用，更接近“看懂新品图片”的目标。

### 为什么不直接使用排在最前面的模型？

排序不代表最适合当前任务。先确认输入形式和任务能力，再看状态与价格。

### 进入聊天页面就会收费吗？

本次验证中，打开聊天页和展开添加菜单都没有发送模型请求。是否收费以及如何计费，以当前连接和账单记录为准。

### “图片”和“视觉 / OCR”是同一个入口吗？

不是。“图片”用于把图片加入聊天；“视觉 / OCR”用于一次性分析文件，使用单独选择的分析连接。后者每次发送前都会检查网络地址：公网连接需要 HTTPS，内网连接需要管理员明确配置允许的主机和端口。目录能刷新，不代表实际分析请求一定可用。

若视觉 / OCR 提示分析服务失败，请先停止重复提交，让管理员检查连接地址、DNS、内网允许范围及网络是否依赖代理。分析请求不会使用代理环境变量、跟随重定向或在连接失败后换一个 IP 重试；不要通过放宽到任意内网地址来排障。多页视觉分析仍是每页一个计划请求，Provider OCR 将所选 PDF 页面作为一个请求；取消不代表已经发送的请求免费。

若“视觉 / OCR”呈灰色且提示未启用或没有可调用目标，请由管理员先检查配置；不要因为旁边的“图片”可选，就认为文件分析也已可用。

## 限制

- 已验证筛选、进入聊天、展开添加菜单，以及“图片”选项可用。
- 未验证选择图片后的预览、上传、模型回复、回复质量和最终费用。
- “可接收图片”只说明模型具备相应输入能力，不代表任何图片都可以外发。
