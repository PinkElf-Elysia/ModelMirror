## 完成结果

你会为只读 HTTP 请求、数据表查询或知识检索配置有界自动重试，并在最终仍失败时选择终止工作流或进入明确的错误分支。等待重试、实际尝试次数和最终去向都能在运行区核对；配置、权限和安全策略错误仍会立即终止。

## 适用对象

适合需要应对公网只读服务短暂不可用、SQLite 存储繁忙，或合格的本地知识检索后端暂时不可用的工作流用户。它不是通用重试器，也不会把凭据、内网访问、错误配置或未知异常变成成功。

## 开始前

请在[经典工作流画布](/workflow)准备一个 V2“安全 HTTP 请求”、只读“数据表查询”或 V2“知识检索”节点。自动重试默认关闭；启用后最多包含首次调用在内尝试 2 或 3 次。若还要在耗尽后继续工作流，请为成功输出和错误回执分别声明不同变量，并接好红色错误出口。

安全 HTTP 只有固定 GET 且无正文时合格；数据表只重试真实 SQLite `BUSY/LOCKED`；知识检索只允许合格的本地全文或本地 hash embedding 配置，不能带远程重排。功能开关关闭或资源不合格时，配置仍会保留在草稿中，但激活和运行会被明确阻止。

本功能本身不产生模型费用。HTTP 请求可能把你配置的数据发送到目标公网服务；数据表和本地知识检索仍遵守各自的权限与数据边界。

## 真实范例

一个只读公网 GET 用来获取状态数据：第一次返回 503，系统等待 5 秒后发起第 2 次尝试；若第 2 次返回 200，就沿普通出口继续。若连续失败并耗尽次数，才会停止或让错误分支收到安全回执。429 的纯十进制 `Retry-After` 可以延长等待，但最长 300 秒；若地址指向内网、凭据无效或返回 401/403，则立即失败关闭。

## 操作步骤

1. 在画布中选择支持该能力的只读节点，展开“失败处理”。
2. 将“自动重试”设为“仅在确认是临时故障时重试”。若面板显示不合格原因，请先修正方法、正文或知识版本；系统不会静默关闭你的配置。
3. 选择最多尝试 2 次或 3 次。第 2 次前固定等待 5 秒，第 3 次前固定等待 30 秒。
4. 在“重试仍未成功时”选择“终止工作流”，或选择“输出到错误分支”。
5. 若使用错误分支，选择独立错误变量（例如 `request_error`），再从红色“错误”出口连接恰好一条处理路径。
6. 保留普通出口的成功路径。重试成功只走普通出口；耗尽后才会停止或走错误出口，两条路径不会同时执行。
7. 用不含用户数据和密钥的合成故障手动运行，观察节点先显示“等待重试”，再显示下一次尝试已开始。
8. 在运行区核对倒计时、attempt 历史、最终安全错误码和分支去向；服务重启恢复后不应重复追加同一次尝试。

为避免把业务数据复制进持久重试记录，等待期间不会保存前序节点生成的结果。如果重试节点本身或恢复后的后续步骤仍需要这类结果，请把对应查询或检索放到重试节点之后；发布预检会阻止无法安全恢复的图。

## 常见问题

### “已处理失败”和“工作流失败”有什么区别？

“已处理失败”表示节点遇到了已归一化、允许路由的运行故障，写入安全回执后沿错误分支继续。只要后续路径成功，整个工作流可以完成，也不会触发正式失败处置入口。“工作流失败”表示错误不可路由，或错误分支本身再次失败，工作流会停止并按既有规则派发一次脱敏失败事件。

### 为什么有些错误不能进入错误分支？

配置和合同错误、凭据或权限错误、功能开关关闭、SSRF/DNS/TLS 等安全门禁、变量缺失、资源不存在、Schema 漂移、取消和未知内部异常都必须失败关闭。错误出口只处理明确识别的外部状态、网络、响应格式或只读查询运行故障。

### 为什么开启重试后仍被阻止运行？

重试资格会在发布、激活、运行和恢复时复检。HTTP 改成 POST 或添加正文、知识活动版本切到托管 embedding 或远程 rerank、功能开关关闭，都会保留配置并显示具体原因，但不会冒险执行。HTTP 的“捕获全部状态”会把非 2xx 当作正常结构化结果，因此这些状态不会自动重试。

### 页面刷新后倒计时会丢失吗？

一旦重试等待状态已经原子写入，运行区会用同一 task 恢复倒计时和 attempt 历史。这个承诺不等于外部调用进行到一半时具备 exactly-once；系统只保证已进入持久等待后的恢复边界。

重试记录只保存恢复所需的节点身份、attempt、安全错误码和调度状态，不保存前序节点产生的表记录、检索正文或其他业务变量。原始工作流输入和变量声明可重建；无法重建的前序结果必须在重试节点之后重新获取。

### 打开“新建工作流”时为什么会先询问是否恢复草稿？

如果浏览器中已有未发布的本地草稿，画布会先显示恢复选择。选择“恢复本地草稿”继续原图；选择“使用默认工作流新建”只打开默认图，原本地草稿仍保留到你保存或转换为止。这避免旧草稿被静默载入后误执行。

## 限制

本轮只覆盖 V2 安全 HTTP 请求、数据表只读查询和 V2 知识检索。自动重试禁止用于 Webhook、表单、RSS、邮件等外部入口工作流、可调用子流程目标、公共 App、Evaluation、Evolution 和 Planner；也不支持写请求、数据表写入、模型、Agent、MCP、子流程调用或知识提议重试。

错误回执只包含固定错误码、分类、节点身份、尝试次数和安全文案；不会包含 URL、请求头、响应正文、表记录、检索文本、凭据或堆栈。若业务确实需要原始外部内容，应在成功路径中显式处理，不能从错误信息中恢复。
