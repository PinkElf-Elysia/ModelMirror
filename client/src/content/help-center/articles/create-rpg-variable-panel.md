## 完成结果

在作品中显示地点、体力和背包等状态，并让它们随完整剧情回复更新。刷新或继续故事时，使用最后一份有效状态。

## 适用对象

希望自定义状态栏、物品清单或任务进度的本地卡片创作者。

## 开始前

准备一个已填写基础资料和提示词的作品。变量面板包含三部分：“数据骨架”是初始值，“面板皮肤”决定外观，“变量提示词”说明何时更新。它直接属于作品设置，无需安装插件。

下面制作“雾港灯塔”面板。预览初始面板不收费；真实更新随剧情请求完成，不另发面板整理请求。若同时启用自动总结或记忆宫殿，这些插件仍按各自任务计费。

## 操作步骤

1. 打开“基础设置”，在页面下方开启“使用变量面板”。关闭开关会隐藏设置，但保留已填写的源码。
2. 在“数据骨架”输入下面的 JSON。使用英文双引号，数字和 `true`、`false` 不加引号；`背包` 用方括号表示列表。

   ```json
   {
     "地点": "雾港码头",
     "体力": 80,
     "背包": ["航海图"],
     "任务完成": false
   }
   ```

3. 在“面板皮肤”输入下面的 HTML 模板。`{{地点}}` 会替换为实际地点；`each` 显示列表，`if` 根据任务状态选择文字。样式写在皮肤内，不需要 JavaScript。

   ```html
   <style>
   .panel { padding: 20px; border: 1px solid #bdd3dc;
     border-radius: 14px; background: #f2f8fa; color: #183847; }
   .panel h2 { margin-top: 0; }
   </style>
   <section class="panel">
     <h2>{{地点}}</h2>
     <p>体力：{{体力}}</p>
     <ul>{{#each 背包}}<li>{{this}}</li>{{/each}}</ul>
     {{#if 任务完成}}<p>任务已完成</p>{{else}}<p>任务进行中</p>{{/if}}
     <button data-panel-copy="{{地点}}">复制地点</button>
   </section>
   ```

4. 在“变量提示词”写明规则，例如：“到达灯塔后，地点改为北岸灯塔，体力减10；拾取铜钥匙后加入背包并标记任务完成。计划、询问和回顾不改变状态。”。不要把尚未发生的行动当成已完成事件。
5. 点击“预览初始面板”，确认地点为雾港码头、体力为 80、背包里有航海图。需要较大编辑区域时，点 JSON 或皮肤右上角的全屏按钮；Esc 退出全屏。预览不会保存设置或更新会话状态。
6. 点“保存”，再到“作品版本”发布新版本。若 JSON 或模板无效，按提示修正后重新预览；已有会话继续使用原版本，修改草稿不会替换它的初始状态。
7. 在“玩家输入”填入开局：“我是雾港的信使林遥，携带航海图前往北岸灯塔，找到铜钥匙并收进背包。”。通过“配置模型与会话”选择新版本、剧情模型和参数，保存配置后发送这份开局。不要把仍绑定旧作品版本的会话当作新版本的验证结果。
8. 在“实际对话”查看本轮“变量面板”和“查看状态数据”。核对剧情确实发生了相应行动，再检查地点、体力、背包和任务。点击“复制地点”可复制面板值；刷新后应保留状态，草稿里的初始体力仍为 80。

## 真实范例

截图使用离线固定回复：地点变为北岸灯塔，体力从 80 变为 70，背包新增铜钥匙，任务变为已完成。正式调用的变化取决于剧情和模型输出；格式通过校验仍需要人工核对内容。

## 常见问题

- 面板没有变化：先看本轮状态提示。缺失、非法或不完整的数据会保留上一份有效状态；合法的相同数据也不会增加状态版本。可展开“查看完整原文”核对，但不要仅为刷新显示而重复发送。
- 模板预览报错：检查字段拼写、花括号和 `if`、`each` 的闭合标签。数据骨架必须是 JSON 对象；模板支持常用条件、列表和比较，不执行脚本。
- 已改初始值，但对话还是旧值：保存与发布后建立新会话；已有会话绑定其原作品版本。
- 只有部分历史发给模型，状态会丢失吗：最后一份有效状态单独携带，不受历史窗口裁剪影响。分支继承分支点的状态，随后各自更新。
- 收到“结果待核对”：先恢复原操作，不会自动重发。完整结果确认前不推进状态。

## 限制

初始字段必须保留并保持类型，例如体力一直是数字。模型回复需提供一份完整状态，格式要求由宿主添加；作者不用改写主提示词。数据最多 64 KiB、16 层嵌套；建议从少量清晰字段开始。面板不支持任意脚本、手工改写已完成回合的状态或自动纠正剧情事实。
