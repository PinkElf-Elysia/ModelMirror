## 完成结果

为评测用例关联一张图片或一份扫描 PDF，设置要检查的视觉证据，并发布固定版本。后续修改草稿不会改变已发布版本使用的附件。

## 适用对象

需要检查 Agent 是否真正读取了图片或扫描文档，而不只是碰巧答对的用户。

## 开始前

- 打开 [智能体版本评测](/agents/evaluations)，准备一个已有文本用例的手工评测集。空评测集可在“完整用例 JSON（高级）”中加入下方范例，再保存草稿。
- 每个用例只能关联一个 PNG、JPEG、WebP 或 PDF，单文件不超过 10 MiB，PDF 不超过 20 页。视觉节点自己的页数上限也必须覆盖该文件，不会自动截取前几页。
- 只上传允许用于评测的资料。上传、保存、下载和发布评测集不会调用模型；开始评测后，图片或 PDF 页面会发送给所固定的视觉模型，后续 Agent 也可能产生费用。
- 真实视觉评测需要含视觉 V2 节点的候选或版本，并启用文件输入。视觉模型须具有有效的“已纳管绑定”，即平台已经确认可用的模型执行连接；只有模型目录名称还不够。
- “视觉节点 ref”是候选中的稳定节点标识，不是画布内部 ID。没有候选时可以先准备附件，但不要把范例 `read_scan` 当作自己的节点标识。

## 真实范例

一份自制两页扫描 PDF，第一页写着 `Quantity: 42 units`，第二页写着 `Quantity: 17 units`。用例要求按页码列出两个数量，视觉断言检查两页均已处理，并在对应页找到这些文字。

```json
[
  {
    "name": "两页扫描文档",
    "message": "分别列出两页的数量，保持页码顺序。",
    "expected": {"contains": ["42", "17"]}
  }
]
```

“断言”就是明确写下本次必须检查的事实。“内容锚点”是图片中应当被识别到的一小段文字，不应从模型回答中临时挑选。

## 操作步骤

1. 在“我的评测集”选择评测集。确认“逐例视觉附件与断言”列出了要测试的用例。
2. 展开该用例，选择“上传附件”，然后先选择“保存草稿”。上传后先显示文件名、格式和大小；保存完成后，服务端校验的页数和 SHA-256 才会显示。SHA-256 是用于发现文件内容变化的指纹。
3. 选择“添加断言”，填写候选中的“视觉节点 ref”。按范例把预期页数设为 `2`，预期状态保留“成功”；上传附件不会自动替你添加断言。
4. 选择“使用附件 hash”。断言中的文件指纹应与上方附件一致；需要限制模型时，在“预期模型 ID”填写候选已经固定的模型 ID。
5. 勾选“文字识别”，在“内容锚点 JSON”填写下方两条锚点，然后选择“应用锚点”。没有点击应用，编辑框中的文字还没有进入用例。
6. 选择“保存草稿”。保存成功后刷新页面并重新打开该用例，确认附件和断言仍在。
7. 选择“发布版本”。“固定数据集版本”应出现包含当前用例数量的新版本；这只发布评测集，不会发布 Agent 或批准候选。
8. 使用附件右侧的下载图标核对原件。确认资料、候选和预算后再单独运行真实评测；尚未准备好模型连接时停在这里，不要把附件准备完成当作模型验收成功。

```json
[
  {"kind": "ocr", "text": "42 units", "page_number": 1},
  {"kind": "ocr", "text": "17 units", "page_number": 2}
]
```

## 常见问题

### 为什么视觉模型选项不可用？

[Meta Planner](/agents/meta-agent) 的“能力授权范围”默认不启用视觉。没有有效的已纳管视觉模型时，节点和模型选择器保持关闭，不会改用其他连接。请由有权限的管理员检查模型连接，再分别确认规划模型、视觉模型和后续 Agent 模型的费用与数据范围。

### 为什么答对了，视觉证据仍然缺失？

答案分数与视觉执行证据是两回事。没有视觉断言、没有实际执行指定节点或没有选中页面，都不能证明视觉能力。运行报告应同时核对实际附件指纹、模型、页数、处理状态和锚点是否命中。

### 解除附件引用会删除旧版本的文件吗？

不会。解除图标只影响当前草稿，已发布版本仍保留其附件。替换附件后应重新检查文件指纹与内容锚点，保存并发布新版本，旧版本不变。

### 为什么评测集不能发布？

先检查用例是否保存成功、断言是否合法，以及版本冲突提示。手工评测集不要求生成校准；针对性生成的数据集编辑后还必须重新校准。附件缺失、损坏或作用域不匹配也会阻止发布。

## 限制

- 已验证自制图片和扫描 PDF 的上传、断言保存、评测集版本发布、原件下载、草稿解除引用后的版本保留及重启恢复；真实模型生成、视觉调用和完整评测仍需单独验证。
- 不支持一个用例多个附件，也不会通过 JSON/CSV 中的 URL 下载文件或读取本地路径。会话导入仍只导入文本。
- 视觉请求已经发出但结果不确定时，不会在重启后自动重发。需要人工核对费用与结果后再决定下一次操作。
- 图片 Token 缺少模型回执时显示不可验证，不会按识别出的文字长度估算。固定文件与模型连接也不保证外部模型每次回答完全一致。

## 下一步

在 [智能体版本评测](/agents/evaluations) 选择已发布评测集版本和候选，确认模型调用上限后再开始评测。检查 `workflow_vision_match` 的视觉证据与最终答案指标；通过评测也不会自动批准或发布候选。
