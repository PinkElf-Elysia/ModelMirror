## 完成结果

你会在 Agent Studio 创建一个 Agent（智能体）草稿，设置它使用的模型和工作方式，保存后完成发布预检。教程停在发布之前，不发送消息，也不调用模型。

## 适用对象

适合需要反复使用同一角色、同一回答要求或同一组工具的人。不需要编程。

## 开始前

- 确认你可以打开 [Agent Studio](/agents/studio)。
- 用一句话写下这个 Agent 每次要做什么。
- 选定模型只是在草稿中保存配置，不代表当前服务已经可以调用该模型。
- “发布预检”只检查草稿配置是否完整。它不会发布 Agent，也不会验证模型回复。

## 真实范例

你每周都要检查新品图片，希望固定使用同一套要求：看清内容、判断主体是否突出，并给出三条修改建议。与其每次重写要求，可以把它保存为“新品图片检查助手”。

## 操作步骤

1. 打开 [Agent Studio](/agents/studio)。你应该看到“+ 创建智能体”入口。
2. 选择“+ 创建智能体”。你应该进入“创建智能体”页面。
3. 填写名称“新品图片检查助手”、说明“每周检查新品图片，并按固定要求给出修改建议。”、标签“新品, 图片检查”和开场问题“请检查这张新品图片并给出三条修改建议”。`Slug` 留空即可自动生成。

![创建智能体页面已填写新品图片检查助手的名称、说明、标签和开场问题，Slug 保持为空](/help-center/b5e0e85e/agent-create-form.png)

4. 选择“创建并进入 Studio”。页面应显示刚才填写的名称，以及“未发布”状态。
5. 选择默认执行链中间的“主智能体”。右侧应该打开这个节点的设置。
6. 在“调用模型”中选择 `Qwen: Qwen3.8 Max`，并在“角色提示词”中填写：`你是新品图片检查助手。收到新品图片后，检查内容是否清楚、主体是否突出、是否适合发布，并给出三条具体修改建议。看不到图片时，先请用户补充图片，不要猜测。` 你应该看到模型和提示词都保留在“主智能体”设置中。
7. 选择“保存智能体草稿”。保存完成后，页面顶部的草稿版本号应该更新；刷新页面，模型和角色提示词仍应保留。
8. 选择“发布预检”。页面应显示“发布预检通过”和“预检通过 · 3 节点”。页面仍应显示“未发布”；在“发布 v1”之前停止。

![新品图片检查助手保持未发布状态，页面显示发布预检通过](/help-center/b5e0e85e/agent-preflight-ready.png)

## 常见问题

### “保存信息”和“保存智能体草稿”有什么区别？

“保存信息”保存名称、说明、标签等基本资料；“保存智能体草稿”保存执行链中的模型、角色提示词和其他节点设置。修改了“主智能体”后，要选择后者。

### 发布预检通过后，Agent 已经发布了吗？

没有。页面仍显示“未发布”。发布是单独操作，发布前应再次检查模型、工具、知识库、权限和费用。

### 创建和预检会产生模型费用吗？

本次实操只创建、保存并检查草稿，没有发送模型请求。真正对话、评测或运行时可能调用模型，费用以当前连接和账单记录为准。

## 限制

- 已验证创建草稿、配置模型和角色提示词、保存、刷新后保留配置，以及发布预检通过。
- 未验证发布、对话、模型回复、工具、知识库、Handoff、评测和实际费用。
- 模型出现在下拉列表中，不代表当前服务已经配置好对应连接或额度。
