## 完成结果

为同一个关键词准备两条可替换的设定。第一次交班时使用蓝灯；该角色的回复写入历史后，蓝灯进入冷却，下一次交班改用白旗。你可以在发送前看到选中了哪条及其原因。

## 适用对象

希望控制设定出现时机的角色卡和独立角色书作者。

## 开始前

从本机角色创作页打开「独立角色书」。准备一个可用于试跑的单聊或群聊会话。本例使用新建的中性角色书和离线回复。在已有作品上练习时，请另建书草稿，并从会话创建新分支。

## 操作步骤

1. 在「我的书架」选择「新建角色书」，书名填「岸灯班次」。点两次「添加条目」，两条的触发词都填「交班」，互斥组名都填「班次」。
2. 第一条的插入内容填「岸边挂起蓝灯。」，优先级填 2，冷却间隔填 1。第二条填「岗亭举起白旗。」，优先级填 1，冷却间隔留空。
3. 勾选「试算尚未进入冷却的条目」和「试算同书互斥组」，测试关键词填「交班」，点「测试触发」。应看到蓝灯正文，第二条标为同组条目 1 胜出。点「保存草稿」，再点「封存已保存草稿」。

![勾选冷却与互斥组后试算交班，第一条蓝灯胜出，第二条让位](/help-center/3c98bf8b/book-rule-trial.png)

4. 切到「会话分支」并选择来源会话。在会话用书中选择「岸灯班次」的 v1，勾选「当前全部角色」。启用「条目冷却」与「同书互斥组」，点「核对绑定」，核对书名、版本及读者，再点「确认并创建分支」。
5. 选定一名角色，在「本次输入」填「交班」，点「预览实际上下文」。确认第一条胜出后，点「生成离线夹具回复」。等「离线回复已保存」，刷新，保持同一角色，再输入「交班」并预览。现在第一条显示还差一条本角色回复，第二条胜出。

![再次预览交班时，第一条还剩一条本角色回复的冷却，第二条已纳入](/help-center/3c98bf8b/book-rule-cooldown.png)

## 其他触发规则怎么选

在条目正文开头逐行填装饰器，从下一行开始写设定。按需要在新分支勾选对应规则；书架试算使用本页自己的勾选项。

| 想达到的效果 | 如何配置和核对 |
|---|---|
| 只说一次 | 单独一行写 `@@dont_activate_after_match`。预览时可重复查看。发送时占用，完整回复入史后才记为已用。 |
| 只看眼前线索 | 写 `@@scan_depth 1`。本次有玩家输入时，这条输入占一个位置；角色接话时，检查最近一条可见消息。 |
| 等几条发言，或隔几条才触发 | 用 `@@activate_only_after 2` 或 `@@activate_only_every 2`。按该成员可见的角色消息计数，包括可见角色开场。玩家输入不计。 |
| 给主规则准备备选 | 在主规则下紧跟一行以 `@@@` 开始的备选，例如 `@@@scan_depth 1`。同时启用回退链和所需规则。预览会列出选用哪一项；已选规则未命中关键词时，本次触发结束。 |
| 首次命中后继续使用 | 写 `@@keep_activate_after_match`。首次纳入、完整回复入史后，可在后续匹配时维持。冷却和预算仍会影响本轮是否纳入。 |
| 按概率出现 | 「触发概率（%）」填 0–100 的整数并启用概率规则。0 总是跳过，100 总是通过概率检查。同一角色同一回复位置反复预览，抽取值固定。 |

## 真实范例

上述两条都匹配「交班」。第一轮蓝灯因优先级较高而胜出。第二轮蓝灯处于冷却，白旗获得位置。继续生成一条该角色的完整回复，下一轮蓝灯就可以重新竞争。

## 常见问题

- **为什么草稿命中，实际分支却没用上？** 先检查封存版本、目标角色的读者权限与启用项，再看预览列出的冷却、概率和预算原因。草稿的概率样本与实际分支分别计算。
- **两个同名组会互相挤掉吗？** 在同一本封存书、同一轮扫描内，同组候选按优先级择一；同分按原书顺序。不同书分别判定。
- **刷新或重生成会多用一次吗？** 刷新只读，精确重生成复用原请求上下文。结果未知时保留原请求及其占用，核对原结果后再继续。

## 限制与数据

这些规则在显式启用的角色书分支中使用。分支固定书版、读者和规则；修改草稿后，可封存新版本并从所需位置创建子分支。卡片导出仅包含作者定义，使用次数与请求证据归会话。冷却、概率及互斥组使用模镜扩展。
