## 完成结果

你会看懂模型卡片上的不可用提示，避免反复点击无效入口，并为同一个任务找到当前可进入的安全替代路径。

## 适用对象

适合遇到“交互待适配”“已适配 · 开关未开启”“需要配置”或“当前入口未开放”等提示的人。

## 开始前

- 先记住你真正要完成的任务和输入形式，例如“用图片做图片识别”。
- 不要通过修改地址、绕过禁用按钮或自行填入凭据来强行进入未开放能力。
- 本指南不要求调用模型，也不会要求你上传文件。

## 真实范例

你想让 AI 看图，但某张卡片显示“交互待适配”。目标不是一定使用这张卡片，而是在保持“图片输入＋图片识别”条件的前提下，找到带“立即面试”的替代模型。

## 操作步骤

1. 回到[模型市场](/models)，重新确认“可接收输入”和“可完成任务”。你应该能明确任务需要的两个条件。
2. 查看目标模型的操作按钮和卡片提示。不要只看模型名称或“已适配”。
3. 根据提示判断下一步：看到“交互待适配”或“文件输入 · 当前入口未开放”时，不继续尝试该入口；看到“已适配 · 开关未开启”或“配置实时语音”时，说明当前环境尚未准备好。
4. 保持原来的输入与任务筛选，查看其他结果。优先选择同时满足条件、操作按钮为“立即面试”的模型。
5. 进入替代模型的聊天页后，核对页面标题和输入区，并停在发送前。你应该能够确认入口正确，同时没有上传或调用任何内容。

## 常见问题

### 为什么目录里有模型，却不能使用？

目录、能力适配、环境开关和交互入口是不同状态。目录中能看到，不代表现在可以使用。

### “需要配置”时我应该自己去系统设置吗？

只有获得管理权限，并且明确知道要配置哪项服务时才进入系统设置。普通用户应先选择当前已开放的替代模型。

### RAG 或 Skill 显示重排受控策略未就绪怎么办？

这是 Rerank Provider 的独立控制面门禁，不代表 RAG 检索、Skill 目录或其他模型能力整体不可用。管理员应在[系统设置](/settings?section=providers)确认连接具备 `rerank` scope、刷新目录并完成精确模型的 Rerank 能力认证，再到[路由与实验](/settings?section=routing)分别检查 `rag_rerank` 与 `skill_rerank` 的 Binding、访问方式和策略状态。Dedicated Rerank API 与 LLM JSON 适配是两种独立访问方式，必须在发送前选定，不能靠失败后切换来探测。

如果策略明确选择“词法降级”，页面或回执应显示 `local_non_model_fallback`；这表示保留原检索顺序，不是模型重排成功。如果没有显式选择词法降级，Managed Provider 不合格或调用失败时会失败关闭。Skill 的语义重排即使调用成功，也仍需通过 Skill 自己的 Shadow、评测、晋级和回退治理，不能自动获得上线资格。

### 为什么设置里能选择多模态 Adapter，却不能运行认证或激活？

R8A 建立了图片、文档、语音、视频和 Realtime 的控制面基础；R8B 已接入图片 Chat、原生 PDF Chat、RAG/Workflow/Xpert Vision 和图片生成。管理员仍需为连接添加明确的 `chat`、`document` 或 `image` scope，刷新目录，完成精确模型、执行形态和 Adapter 的真实认证，再到“路由与实验”激活对应入口。认证通过不等于已生产启用，Feature Flag 默认关闭。

STT/TTS、Chat Audio、音频生成、视频和 Realtime 仍等待 R8C—R8F；这些入口的认证按钮和 Managed 激活会继续阻断且不会产生付费调用。图片与原生 PDF、工具或其他未按同一形态认证的组合请求也会在发送前阻断。不要通过修改请求或打开 Feature Flag 绕过门禁。

### RAG Formal 显示“引用已失效”或“不可重放”怎么办？

历史指标仍可查看，但不能据此推广索引。“引用已失效”表示知识库或索引版本已经不存在；“不可重放”表示语料、配置、代码指纹或 Provider 回执与运行时不一致。请选择当前已发布的 Gold 和两个确切索引版本，重新运行 Formal。结果必须显示“可重放”，并且执行证据和 Promotion Gate 同时通过，推广按钮才会启用。

全文检索 Formal 不应产生 Embedding 调用；向量或混合检索必须使用未降级、可校验的真实 Embedding 身份。出现 hash、fail-open、指纹不一致或非零执行错误时，应保留历史记录并重新修复链路，不能沿用旧的绿色门禁。

### 没有任何替代结果怎么办？

清除不必要的筛选，只保留任务必须条件；仍没有结果时，记录页面提示和任务条件，交给有配置权限的人处理，不要尝试绕过限制。

## 限制

- 本指南验证的是模型市场中的恢复路径，不代表所有模块都使用相同状态文案。
- 替代模型可能有不同价格、输入限制或输出表现；发送前仍要重新检查。
- 没有验证需要管理员配置、供应商凭据或真实调用的恢复方式。
- Rerank 能力认证可能产生少量供应商费用；真实认证或 Smoke 必须获得单独授权。
