# ADR-0001：采用同仓独立实验目录并保持可 subtree 拆分

- 状态：已接受（R0）
- 日期：2026-08-06

## 背景

矩阵绿洲需要在模镜仓库中孵化，但原项目模块只能作为未来可复用工具箱。任何隐式共享都会增加回退风险，并使实验难以分割成独立项目。

## 决策

在 `experiments/matrix-oasis-engine/` 建立自包含模块：

- 独立 npm 根、lockfile、源码、测试、文档与验证脚本；
- 父项目交互初始为 `none`，白名单为空；
- 未来适配器必须在独立轮次完成版本化设计和人工审批；R0 不限定协议；
- 每轮保留 `git subtree split` 验证；
- 所有 R0 变更只增加这个目录。

Godot 4.6.x 在 R0 只作为未来工具诊断，不创建工程或提交二进制。

## 结果

### 正面

- 模块可以在不依赖父前后端的情况下安装、构建和验证。
- 拆分可以保留模块自身提交历史。
- 逆序 revert 或删除唯一新增目录即可回退。

### 代价

- 依赖与工具配置会与父仓重复维护。
- 在适配器获批前不能直接复用父组件、主题、资产或 API。
- 根 CI 不会自动发现模块，R0 依赖模块本地验证和人工验收。

## 被拒绝方案

- 直接加入父前端：会修改主路径并破坏独立回退。
- 共享父 `node_modules` 或源码别名：拆分后无法独立安装。
- 立即建立 submodule/新仓库：会提前引入仓库管理和发布决策；R0 用 subtree 演练保留可分割性。
- R0 创建 Godot 工程：超出隔离基线，且当前工具尚未准备。
