# ADR-0013：R12末班地铁初版闭环治理

状态：已接受

## 决策

R12以最初末班地铁案例的真实自然语言到可玩3D全流程作为初版唯一退出门。实现采用通用acceptance profile、兼容assembly v2和同一Marble world的空间源物化，不复制或替换R1–R11权威合同与执行器。

冻结案例仅作输出语义oracle，不进入模型提示或运行分支。另用既有中性真实缓存通过相同R12代码，以区分通用链路与案例过拟合。

初版声明由机器状态和验收证据共同控制：在真实模型、Marble、六个Meshy资产、Node/Godot三结局与循环、300帧性能和人工交互全部通过前，`claimAllowed=false`。普通verify不得触发计费调用。

## 回退

逆序revert七个R12提交恢复R11。Git回退不会删除仓外资格run、供应商资产或远程任务；远程删除需要另行明确批准。
