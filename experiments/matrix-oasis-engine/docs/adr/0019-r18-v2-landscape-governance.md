# ADR 0019：R18第二版全景选型治理

## 状态

已接受。

## 决策

R18不继续使用R17的单层生产硬门解释所有候选，而是建立三层证据结论：架构参考、可执行短名单和正式集成推荐。正式推荐仍必须通过分类生产硬门；分层只修复证据语义，不降低集成标准。

R18使用独立合同与Harness，不修改R17包。R17证据可作为历史输入，但必须由R18重新评分和分类。R18覆盖八个赛道，机器化要求至少48个赛道条目、32个唯一候选和12–16个实际执行候选。

## 后果

- V2声明门由R24顺延至R25，R16 MVP结论不变。
- 候选完整源码和执行证据仍在仓外；仓库只保存锁、原创笔记和脱敏哈希。
- R19–R25路线在R18验收时冻结，但具体生产依赖必须以后续资格结果为准。
