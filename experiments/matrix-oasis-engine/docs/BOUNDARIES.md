# R16边界

R16只迁移Creator宿主、资格编排、事务缓存和界面，不修改R13–R15算法、Godot场景、供应商适配器或资产。普通验证与双真实缓存资格均不调用供应商；资格和媒体只发布到`C:\tmp`。

## 允许

- 新的Spatial Solution合同、Intent离线合成与确定性求解器；
- 新的隔离Godot物理复验器和已求解预览场景；
- solved overlay、Node harness、合成夹具与仓外真实缓存资格；
- 仓外`C:\tmp` facts、solution、overlay、调试捕获和日志。

## 冻结

R1–R13公共合同、Runtime语义、Scene/Spatial格式、examples、历史Creator/Godot产品场景、vendor、ADR和验收记录均冻结。精确allowlist优先于冻结根，未知路径fail-closed。

schema v14固定`activeRound=R14`和基线`296e560d5197ff1367ad75455b2b9f5852560fd8`。所有父仓路径、Docker、共享栈、父服务、数据库和父凭据存储禁止修改或依赖；R14全部执行路径禁止网络和供应商调用。

R14允许在新目录求解和复验，但R14.7人工批准前不允许切换默认预览或解除声明门。初版状态保持`pending-spatial-solver`且`claimAllowed=false`；任何提前声明均视为治理失败。
