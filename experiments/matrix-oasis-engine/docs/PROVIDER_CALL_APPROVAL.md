# Marble / Meshy 真实调用审批模板

R7 的固定策略是零真实调用。查询额度、创建任务、轮询、下载和通过 MCP/REST 请求均属于真实调用。

未来每次调用前必须向用户披露并取得同一轮明确批准：

1. 服务商、模型、接口与最大请求次数。
2. 输入内容、是否上传用户数据及数据保留风险。
3. 预计 credits/费用上限。
4. 输出格式、有效期与仓外保存目录。
5. 是否创建远程任务、轮询或下载。
6. 日志脱敏、失败清理和回退方式。

批准仅对披露的单次操作有效。不得读取或输出密钥值，不得把密钥、签名 URL、额度信息或原始服务日志写入仓库、Scene Pack、截图或验收文档。
