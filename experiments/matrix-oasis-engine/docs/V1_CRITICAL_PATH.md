# 初版关键路径

初版唯一退出目标是：纯自然语言自动生成可第一人称漫游、带现有Action终端基础交互的3D原型。

R8只负责自然语言到严格原型数据；R9负责Meshy道具/静态人物资产与离线规范化；R10负责环境素材策略、自动组装和一键预览。

R9不得为了“更完整的3D”提前引入Marble人工导出、SPZ/Splat、自由关卡生成或Creator流程。它的退出证据只需证明一个真实prop和一个静态character-placeholder在固定Kenney房间中通过Scene Pack/Godot验证。

初版前禁止新增AI NPC、稳定记忆、动态任务、世界事件、图片/全景/视频输入、数字孪生、实时世界模型、Splat、存档、多人、正式导出或父项目接入。候选功能必须直接消除关键路径中的人工步骤或解决可复现阻断；“看起来有用、风险低、容易实现”不是立项依据。
