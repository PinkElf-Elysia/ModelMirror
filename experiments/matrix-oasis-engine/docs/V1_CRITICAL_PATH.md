# 初版关键路径

R15已用R11中性和R12末班地铁双缓存完成实际输入、逐节点图形、完整录像和300帧性能资格，并通过人工验收。当前唯一关键路径是R16 Creator迁移与MVP重新资格；R16通过前`claimAllowed`保持`false`。

R8完成纯文本到严格Blueprint；R9完成Meshy道具/静态人物；R10增加Marble panorama/collider、确定性组装和Creator一键Godot预览。

R12技术链可以到达结局，但人工验收确认出生点、资产与Action终端布局不自然，因此没有通过初版完成声明门。R13提取空间语义意图与Godot环境事实；R14以通用求解器完成布局；R15又在中性与末班地铁两类缓存上通过实际InputMap重放复验同一结果。剩余阻断是Creator目前不能复现这条新profile，第二个真实环境也未从R16 Creator入口重新资格；完成R16前不得宣称初版闭环完成。

候选功能只有在直接解决空间布局阻断或消除纯文本到可玩3D原型的人工步骤时才能进入R13–R14；仅“看起来有用”不能立项。
