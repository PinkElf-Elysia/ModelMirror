# R22最小产品语义

## 用户可观察闭环

玩家在隔离R22预览中注视三米内、无遮挡且空闲的绑定NPC并按`E`，输入一次文本后看到完整外发JSON、候选Action、模型、端点、保留政策和最高费用。玩家可批准或拒绝；拒绝时零请求、零费用，R20固定策略继续运行。

批准后最多发生一次非流式请求。合法结果先以纯文本显示；若选择了披露候选，则复用R20移动与到达证明，再交给R19权威裁决。没有候选、返回`null`或任何Provider/验证故障时，只显示固定本地fallback，不产生隐藏Action。

## 确定性边界

确定性内容包括上下文选择与裁剪、候选集、Call Plan、审批hash、预算状态、choice映射、R19裁决、Ledger结果、fallback和脱敏证据。模型对白本身不要求跨请求重现，原文也不持久化；重放时Provider请求数固定为零。

临时对白最多四轮、8 KiB，只驻当前进程；reset、重启或超过展示确认期限即丢弃。R21 memory仍只包含actor自身已接受Action，不把对白包装成长期记忆。

## 明确不包含

- 自由行动、工具调用、多步Agent循环或后台自主认知；
- 新任务、世界事件、关系自动演化或Persona修改；
- 语义检索、embedding、外部记忆服务或跨timeline对话；
- 富文本脚本、动态资源、链接执行、动画、语音或Creator迁移。
