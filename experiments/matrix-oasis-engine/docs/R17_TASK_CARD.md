# R17任务卡：第二版开源资格与技术选型

## 目标

以固定来源、仓外可执行证据和统一硬门，输出第二版各技术赛道的推荐、备选、延后或拒绝结论。

## 明确不做

- 不开发AI NPC、记忆、对话、动态事件或Creator新功能。
- 不修改R1–R16产品合同、Godot产品场景、供应商适配器和真实资产。
- 不调用模型或资产供应商，不读取凭据，不使用共享Docker。
- 不提交候选源码、依赖、二进制、资产、日志或资格输出。

## 交付

- 来源与许可证机器锁。
- Candidate Lock与Qualification Report闭合合同。
- 仓外候选资格Harness及脱敏证据哈希。
- 推荐矩阵、切换条件、R18边界约束和R17验收记录。

## 回退

逆序revert六个R17提交即可移除本轮；仓外候选checkout和证据目录按各自清单单独处理。
