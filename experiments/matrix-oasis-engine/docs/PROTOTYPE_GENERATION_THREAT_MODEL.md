# R8原型生成威胁模型

## 受保护边界

- 提示词是可能被上传给模型服务的用户数据；未明确确认外部上传前不得请求。
- 模型响应是不可信输入，必须经过严格JSON、Schema、跨引用、Authoring Validator、Compiler和Runtime检查。
- diagnostics不得回显未知键名、输入值、模型原始错误、密钥、endpoint或本机路径。
- 无效候选和耗尽修复不会写入输出目录；成功输出采用同父目录事务发布。
- CLI只读取三个R8专用环境变量；Provider包本身不读取环境。stdout/stderr只输出固定状态、主机/模型规划信息或静态code/JSON Pointer。
- prompt读取前后核对bigint设备/文件身份；输出先创建同父临时目录，五个FileHandle全部绑定可信路径后才写内容，最终单次rename发布。

## 不在R8解决

R8不证明模型服务的隐私承诺、内容真实性或生成质量，也不防御拥有相同本机权限并持续替换临时文件的恶意用户。Node没有目录句柄相对的`openat`接口，因此“路径复验到open系统调用”之间的恶意竞争最多可能在被替换目标创建空文件；五个句柄全部通过身份和containment复验前不会写入候选内容。R8不执行模型产生的脚本、URL、工具调用或资源引用。
