完成一次文本实验

  1. 检查顶部模式。离线演示只返回本地模拟结果，真实模式才会调用 OpenAI。
  2. 输入合成文本，或点击“填入冒烟预设”。每轮最多 4,096 字，填入预设不会发送。
  3. 点击发送并等待轮次完成。首轮完成后，可以手动发送第二轮。
  4. 第二轮结束、失败或到期后会自动清理；也可提前点击“结束并清理”。
  5. 查看本次历史并导出回执。缺失的 usage 保留为未知，模拟结果不能用作真实调用验收。

180 秒从首轮发送开始，包含两轮调用及等待输入的时间。取消请求、轮次终态、API 删除确认和物理清理分别记录。

刷新页面只读取本次实验状态，不会重发输入。连接失败后请先刷新状态；进程重启无法恢复远端会话，请先核对原回执。

开发者启动方式
python -m experiments.openai_agents_api.web --demo
python -m experiments.openai_agents_api.web --live --model gpt-6-astra

真实模式要求服务端进程已配置 OPENAI_API_KEY。本页不接收、显示或保存密钥。
