# R5：工具登记与受限行动执行

独立、默认关闭的实验原型；常规预览离线，真实补测仅经任务专用入口及单独授权。基于公共 CoreHost/CoreStore、SessionRecords、R4 资料装配和卡片适配；没有更改旧模块。不是第三方插件 SDK，也不是角色运行器。

## 运行与验收

在 experiments/ai-rpg-engine 下：

```powershell
node agent-core/actions/server.mjs --offline-preview --port 18871
node --test agent-core/actions/*.test.mjs
```

默认记录目录为 .rpg03-work/actions-r5-preview，地址 http://127.0.0.1:18871/。占用端口时退出，不停止其他服务。没有 offline-preview 标志则拒绝启动，离线入口拒绝真实 provider；任务实测需显式 controlledReal 和独立调用授权。

1. 选择修仙或灯塔，点击“确认样例并开始”，使用原创成年样例，物资为 5。
2. 点击“先查询，再准备方案”。固定模拟输出原生 query_local_state，再输出 prepare_action。准备完成仍为 5，不会发表已执行剧情。
3. “确认并执行”后立即显示 5→3 回执。也可直接使用左侧明确行动按钮；程序重新读取并校验状态。
4. “生成结果叙事”后继续普通交流。工具结果、方案和正式叙事分开保存。
5. 在“恢复与分支验收”模拟明确失败、未知或截断。失败只能主动重试叙事或保留回执；未知只能核对原请求，不重复执行。
6. 刷新读取已有记录；可从最新检查点新建分支，原记录不变。改写必须填写原因。暂停不丢失资产。
7. 可读取 E2 导出文件检查来源。当前赠送／邀请只显示未执行及缺少动作映射，不把预计数量写入世界。

固定按钮文本是模拟用例，不能据此宣称模型已理解任意自由输入。页面没有真实调用按钮、凭据、外网请求或正式故事馆入口。

## 实现边界

- registry.mjs：可信组合登记两项工具及 schema、版本、效果、调用次数、结果大小；请求不能自行注册。
- rules.mjs：纯资源规则，修仙 use_medicine 与灯塔 fuel_lamp 共用计算；只有已登记目标，正整数、数量已知、余额足够；零数量保留档案。
- store.mjs：提案与取消不改世界。执行一次原子保存状态、事件、回执、待叙事任务。没有任意模型路径写入。
- host.mjs：规划最多两次生成、一个只读查询及一次提案；工具准备后停止等待确认。已执行叙事单独一次生成且无工具／状态增量。普通交流可一次完成。
- adapters.mjs：保留原素材和非受管规则，版本 5 职责适配；模型不能用数量增量或相抵增量维护受管资源。非受管定性判断仍沿用旧校验。
- protocol.mjs / transport.mjs：工具名白名单、调用编号对应、分片参数和不透明元数据保留。simulator.mjs 的有效结果实际经过此分片链路；错误样例直接注入以验证拒绝分支。
- e2.mjs：核对真实导出格式／内容哈希，只读检查，不冒充执行器。
- server.mjs / public：独立回环地址，来源校验、请求大小上限，正文以文本展示；没有执行作者脚本。
- 模板和状态不通用化重建。新增卡提供规则／字段适配，宿主执行和恢复逻辑不按题材分支。

## 记录与限制

证据 JSON 保留冻结请求、状态版本、工具原始消息、模拟 SSE、工具结果、实际变化、各阶段大小、尝试与回执。查询／准备只读世界，但会持久化运行记录。
已保存准备结果恢复时直接采用，不再生成；旧版本提案拒绝。结束失败叙事后，未叙述的已提交行动仍作为确认事件进入下一次请求。

模拟预览费用为 $0；该模式的 token 和真实首字为 null。字符数、传输字节和模拟完成耗时不代表真实 token、延迟或供应商资格。

当前 R5 不开放候选模型对比、自动备用、多角色执行或跨会话操作；旧 R3/R4 对比和原模式保持。父项目工具白名单未放宽。real/ 中的有限桥接仅注册于本任务临时实例，沿用认证、路由资格、出站和预算校验；不是正式平台入口。历史授权已使用完毕并结束，后续调用必须另行授权。

从检查点创建的分支保留历史来源；旧提案仍绑定原会话，不能在分支执行。旧模式不自动迁移，未导入 E2 归档状态。暂停后仍能查询与保留证据，不把维护权交回模型。

停止本轮进程即可撤下预览；保留数据与对应源码版本。不要删除共享数据或改绑定绕过版本校验。


## 已验收实测与后续边界

用户已通过第五轮原型验收。真实原生 prepare_action 在首次流解析失败后保留；恢复入口核对保存回复和状态，在独立测试会话确认执行一次，再调用一次正文。丹药 5→3、其他结构状态不变；正文补写过去经历与重复面板的问题作为后续优化，不再补丁或真实调用。

只读页面 http://127.0.0.1:18875/ 保存本机验收证据，无调用按钮。恢复实测脚本绑定本任务已有证据指纹，原始材料不随仓库公开；它是有来源约束的测试入口，不是任意导入或自动重试接口。
