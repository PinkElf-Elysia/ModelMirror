# 诡秘之主大世界

本卡提供独立的八页档案构建器、本机开局预览和受控 Gemini 验收脚本。参考界面来自[作者卡片](https://afengy.cash/zh/explore/installed/00f44d74-6980-4175-a5a4-6f13f300cf5a)。地图与雾景背景随卡提供。作者系统词单独存放在 resources，装配时验证 SHA-256，浏览器只收到本次档案字数。

## 本地运行

从仓库根目录执行以下命令。预览监听本机随机端口，打开终端打印的地址即可。

~~~sh
node experiments/ai-rpg-engine/lord-of-mysteries-card/preview.mjs
~~~

在「角色」中填写姓名，在「命数」中抽取命数与行囊，再切到「档案」核对结果。「复制档案」复制全文，「装配开局（离线）」在本机以原文生成首轮消息。当前共享 Studio 的卡片列表和 Docker 镜像没有集成本卡。

## 离线验收

~~~sh
node experiments/ai-rpg-engine/lord-of-mysteries-card/live-acceptance.mjs offline
~~~

该命令使用合成档案，在独立临时目录完成插件安装、会话授权、两轮记忆写入和召回，并检查真实调用槽位用量为零。无需 Docker、服务令牌或历史私有文件。

## 已验收的真实批次

2026-11-04，基线 c46c5acb 上的原批次使用 google/gemini-3.8-flash，temperature 0.7、top_p 0.8、max_tokens 16384。中性档案单独运行一轮，指定档案连续两轮，每轮剧情后调用一次记忆宫殿。五次均正常结束且零重试，共 254525 tokens。首轮新增四条记忆，第二轮请求包含首轮原文及四条召回记录，随后更新两条，最终保留四条。验收摘要见同目录 acceptance.json。原始请求、剧情、插件输出和个人开局只保存在原实测工作树的忽略目录。

候选版 dispatch 模式供另行授权的实测使用。调用方通过服务端环境变量 RPG_S2S_TOKEN 提供令牌，第三个命令行参数为原授权开局文本路径（脚本名之后依次传 dispatch 和文本路径）。脚本先校验开局哈希，再独占本机 live 账本目录。账本已存在时停止，禁止清空后重发。若某个请求结果未知，按原请求 ID 查回执。验收脚本最多派发五次；本机预览页面只提供离线装配。

## 回退

本卡的共享代码改动只有受控适配器中新增的卡片 ID。回退候选改动即可移除本卡，原有 earth、god 和 cultivation 的注册均保留。独立账本按实测记录留存。
