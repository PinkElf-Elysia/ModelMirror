# 新卡受控传输边界

这里的三个模块来自基线 `6977d86c0ad13e4cd18a9a641f0aae64731443a4` 的 `studio/controlled-provider.mjs`、`memory-budget.mjs`、`memory-task-provider.mjs`。

复制的原因：旧卡存档把这三个原文件的字节纳入运行指纹。直接扩展它们的卡片白名单会使既有存档失配。本轮不迁移、重签或放宽旧存档校验。金庸卡使用独立宿主与传输边界，原卡继续使用原模块。

仅调整相对导入、允许 `jinyong` 身份及其恢复回执路径。预算预留、幂等、未知结果不重放、服务地址限制、回执校验、超时及取消规则原样保留。`../card.test.mjs` 的差异约束测试防止两者在这些规则上无意漂移；旧模块若修复，需要同步评估并更新本快照，不可跳过此测试。

`../offline-store.mjs` 对应旧 God 离线适配器，但强制由本卡宿主提供 profile/models，使用新卡传输。它只返回明确标注的离线样例，不回退到外部服务。
