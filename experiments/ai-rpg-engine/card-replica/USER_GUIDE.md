# 创建角色并使用本地离线会话

适用：本轮独立“地球 OL”实验模块，尚未接入模镜正式导航。你可以创建角色、查看或复制角色卡，并用固定离线样例检查会话保存与恢复。普通启动不会调用付费模型。

## 开始前

- 开发者使用 Node 24.18.x，在本目录运行 npm.cmd ci、npm.cmd run verify、npm.cmd start -- --port 18411，随后打开 http://127.0.0.1:18411/。
- 草稿保存在当前浏览器；会话保存在当前模块的.local/sessions/。不同端口的浏览器草稿彼此独立。
- 不要清理.local；它可能包含你的会话和仅保留在本机的原文。
- 本轮真实测试已用5次额度，当前不提供继续生成的授权。下面所有“发送”都指默认离线入口。

## 创建普通角色

1. 点击“开始投胎”，选择性别，进入下一步。
2. 选择出生地，或在“自定义”中填写真实国家和城市。
3. 选择出生年代或填写出生年份，选择家庭出身。
4. 填写身高、体重、体型、发型与气质长相。
5. 选择3项天赋，再填写姓名。随机姓名词库没有提供，不能把本地编造名字当成原作者资源。
6. 到达命运卡后，使用预览和复制按钮核对角色文字；返回可以修改前面的选择。
7. 普通角色不会包含“开启深层世界”。只有主动走深层世界流程才加入宗门、根器和对应角色模板。

年龄模板沿用素材中的2025参考年，可能与当前年份不一致。本轮没有统一改写素材中的年代矛盾。

## 参数与离线会话

1. 打开顶部“参数”。当前新会话最大回复为16384，温度0.70、TOP P 0.80；保存后用于新会话，已创建会话保留原参数。
2. 从完成的角色卡进入本地预览，创建离线会话。
3. 输入文字并发送。约3秒后返回明确标注“离线预览”的固定样例，不代表真实剧情质量。
4. 生成期间可取消。取消后迟到结果不会新增到历史；已经完成的回复不会因随后点击取消而撤回。
5. 查看原文可核对保存内容。显示页面会过滤脚本、远程图片及活动内容，原文不会因此被改写。
6. 刷新页面，从“历史”重新打开会话；恢复不会自动发送。存在未确认请求时不自动重试或换请求编号绕过。

TOP K、两项惩罚和思考预算不会发送到本轮已验证路由；界面上下文数值不是静默截断策略。16384是最大输出预算，不保证每次都输出相同字数。

## 深层世界与资料缺口

深层世界是可选流程，从命运卡“回应那道凝视”进入。宗门与根器使用已收录的作者可见素材，本地抽样不代表原站概率。完整城市、随机姓名、道号词库和原概率未提供；世界书触发元数据不完整，全部候选默认关闭。

## 常见情况

- 不能继续：检查必填项、年份和天赋数量。文本空格不算有效姓名或地点。
- 复制失败：在预览中手动选择并复制。
- 页面刷新后草稿不见：确认仍是同一浏览器、同一端口；清理浏览器数据会清理草稿。
- “生成未完成”：保留记录，核对宿主状态；不要通过反复发送消耗真实额度。
- 想查看真实结果：本机18415是本轮只读审阅页；源码包不包含本机生成输出，另一台机器不会自动拥有该页。
