# 古代人生 · 命运卷轴

从模镜 RPG 列表进入 `/rpg/ancient`。依次选择人生道路、配置人物、生成命书，在最后一步复制，再手动粘贴到卡片外的输入框。网页的「装配开局（离线）」只返回装配结果的哈希。真实调用通过服务端 `createAncientHost` 显式配置，网页入口没有模型额度。

## 十七朝世界书

新建存档从命书锁定朝代，后续回合继续使用同一册；在相应时代提及辽、西夏、金时，按当前输入补入对应简目。朝代正文保持在原朝代资料的位置，随后仍是朝代锚定规则。配置与原文见 [worldbook.json](worldbook.json)，选择与插入逻辑见 [worldbook.mjs](worldbook.mjs)。旧档根据已有运行时绑定继续使用完整的 `system.txt`。

离线验收在拆分前基线建立存档，再以新版本恢复和续玩；两个新档分别走西汉二轮、南宋二轮，并对照实际本地传输记录。在实验模块运行 `node ancient-card/worldbook-acceptance.mjs <拆分前实验模块路径> <新审核目录>`。旧工作树的 client 需已有测试依赖 jsdom。回退时保留所有会话和请求记录；恢复拆分前宿主可继续运行旧档，新版创建的存档须使用对应世界书版本。
