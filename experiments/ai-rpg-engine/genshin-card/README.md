# 原神·提瓦特大陆

在故事馆 `/rpg` 选择原神卡后，可在开局面板选择旅行者、原著角色或自创角色。点击「带入聊天」会创建存档，并把开局预览写入可编辑的草稿。首次发送后，玩家可从故事馆「接着上次的故事」回到同一存档。

## 装配与运行

`resources/prefix.txt` 与 `resources/suffix.txt` 保存前后置词，`resources/worldbook.json` 保存按原文位置拆分的世界书。规范名、别名和插入位置见[触发词审核表](./触发词审核.md)。每轮的装配与误触排除由 `assembly.mjs` 实现。卡片默认使用本地离线回复。受控模式由宿主读取 `RPG_GENSHIN_CHAT_ENABLED` 和 `RPG_GENSHIN_CHAT_CALL_LIMIT`，默认关闭，额度为零。

## 验收记录

| 档案 | 既有受控实测结果 |
| --- | --- |
| A | 食材「砂糖」排除成功，找琴商量命中人物档案，首轮完整入档。 |
| B | 原档首轮以 `content_filter` 截断，正式回合数为零。独立新档先确认送货地点，完整入档后追问族群，两轮均通过。回答中的设定外推已记录。 |
| C | 日常点名雷电将军与明确挑战按已审规则分别装配，回答中的设定外推已记录。 |
| D | 海灯节日常和追问历届分流通过，两轮完整入档。 |

两批受控实测共派发 8 次，完整入档 7 次，截断 1 次，重试 0 次。提示词和世界书按已验收版本冻结。故事馆另以固定离线回复走通选卡、自创开局、首次发送、全新浏览器会话续档及刷新回读。

在 `experiments/ai-rpg-engine` 下运行 `node --test genshin-card/genshin.test.mjs` 可复核卡片装配和模拟会话。在 `client` 下运行 `npm run build` 可构建故事馆前端。
