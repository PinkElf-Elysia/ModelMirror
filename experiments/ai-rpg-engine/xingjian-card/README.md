# 行间 · 无限重生系统

主站入口为 `/rpg/rpg05`。开局界面及独立聊天由 `/rpg-app/xingjian/` 提供；旧版旅程与草稿继续使用 `/rpg-app/rpg05/`，不迁移旧数据。

## 卡面和资源

2026-11-04 对照作者公开的卡面（作品 ID `e23bbc64-4fdd-46d8-92c0-64923961e5d8`）。`resources.json` 按原顺序保存 643 个世界、3,222 个身份条目及其随身物资、10,548 条世界天赋和 472 条通用天赋。统计单位是归属于各世界的条目，保留同名项。原站与本地浏览器中两张数据表按键排序并序列化为 UTF-8 JSON 后的 SHA-256 均为 `be2c50d4a5dd1134414c477b1149d64147f9df7a8d1742c8a1f0ffc1bdf4d2ad`。

在位面搜索输入英文句点显示世界列表。选定世界后可随机适配身份，或打开指定天赋，按来源、品级和关键词筛选。导出页保留复制并增加「以此档案进入独立聊天」。确认创建只保存快照，首次发送由玩家主动触发。

## 会话与验证

行间以冻结的 `studio/rpg05-prompt.json` 为前缀，接两个换行及 `output-format.txt`（来自《格式提示词.docx》，保留段落与空行）作为一条系统消息。旧版 RPG05 不追加该文件。旧会话仍保留原运行时绑定；测试新版需新建会话。浏览器卡面运行在禁止外部连接的沙箱中。会话使用共用 ChatView，五个插件使用行间自己的注册表与会话授权；先在「会话与插件」安装，再在对话内启用。离线与受控模型数据分别存放。默认离线，演示回复不代表模型输出。真实模式需要显式开启 RPG_XINGJIAN_ENABLED、设置独立 RPG_XINGJIAN_CALL_LIMIT，并提供既有的 RPG 受控服务连接。

在 RPG 引擎目录运行 `node --test xingjian-card/host.test.mjs`。覆盖资源关联、五个插件的安装与配置、两次离线发送、记忆处理进度与创建分支。恢复旧界面可直接使用旧版入口；撤回改动无需迁移或删除会话数据。

四卡新会话的主站地址为 <code>/rpg/{cardId}/chat/{sessionId}</code>。行间使用原目录，古代人生、诡秘之主和修仙使用各自的 archive-chat 子目录。修仙旧存档从卡片页「原有修行存档与自动总结」进入。新聊天默认离线，真实路由分别由 RPG_ANCIENT_CHAT、RPG_MYSTERIES_CHAT、RPG_CULTIVATION_CHAT 前缀的 _ENABLED 和 _CALL_LIMIT 设置启用并限额。关闭对应开关可回到离线模式，保留真实会话目录。
