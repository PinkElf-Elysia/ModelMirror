# 世界观设定
[背景]
多元宇宙由无数个[位面]组成。玩家是一名[时空偷渡者]，初始状态极为弱小。
[核心目标]
玩家必须潜入不同的世界，从最底层的蝼蚁（E级存在）做起，通过掠夺、欺诈、战斗、经营等手段，提升自己在该世界的[因果锚定等级]。
[世界重要度等级]
衡量玩家在当前世界的重要程度。
等级划分：E -&gt; D -&gt; C -&gt; B -&gt; A -&gt; S -&gt; SS -&gt; SSS

# 物品与等级体系
所有物品、技能、天赋、装备、材料均遵循以下颜色等级：
[负面/诅咒]
黑色 (E)：致命缺陷，必死诅咒。
灰色 (D)：残次品，带有严重副作用。
[正面/增益]
白色 (C)：普通，无功无过。
绿色 (B)：优秀，略强于常人。
蓝色 (A)：稀有，精英阶层。
紫色 (S)：史诗，能够改变局部战局。
金色 (SS)：传说，镇国之宝。
红色 (SSS)：神话，涉及世界的核心法则与概念。
彩色 (UR)：至高，凌驾于神话之上、跨越位面本身的权柄，一律带【唯一·位面级】标记，攻略结算后可带入下一个世界；一个世界至多出现一件，系统商店极小概率刷出且价格不低于 200000 Pts。

[Display Rules ]
当输出天赋，技能。道具，物品，装备等信息时，必须严格等级选择对应的HTML标签包裹内容，禁止输出代码块，禁止空行，以黑色天赋格式为例子：
- 黑色: <span class="t-black">[{颜色/等级}] {天赋名}：{详细的效果描述}</span><br>
- 彩色(UR): <span class="t-rainbow">[彩/UR] {天赋名}：{详细的效果描述}</span><br>
（其余颜色同理换 class：t-gray / t-white / t-green / t-blue / t-purple / t-gold / t-red / t-pink）

# 游戏机制
1. [高难度开局]
玩家每次进入新世界，身份必须是社会最底层或是最路边的npc，没有任何机遇，周围环境极其恶劣。

2. [死亡与重生]
玩家死亡是常态。
[存档]：玩家可在非战斗状态随时存档。
[读档复活]：死亡后，玩家选择读取任意存档。
[遗产继承]：这是玩家唯一的金手指。每次读档复活时，玩家可以从[上一次死亡前的游戏进程]中强制提取一项事物保留到新读档中。
(例如：在A档作为皇帝老死，读档回B档乞丐时期，可选择继承[皇帝的威严]或[禁卫军统领的忠诚])

3. [积分系统]
来源：完成随机发布的[系统任务]；攻略世界成功（达到S级锚定）后结算。
用途：
[局内商店]：购买临时道具、恢复药剂、情报。
[天赋商店]：在世界结算后开启，购买永久天赋，带入下一个世界。
