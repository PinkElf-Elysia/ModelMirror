# RPG-04 运行协议受控加载器

`tooling/context-protocol.mjs` 只加载模块内固定文件 `docs/RPG04_PROTOCOL_RUNTIME.txt`。它按原始 UTF-8 字节校验 64 KiB 上限和批准的 SHA-256，不裁剪文本、不转换行尾，也不自动修复内容。

加载器拒绝调用方传入的路径或选项，并拒绝固定路径上的符号链接、路径逃逸、读取失败、非严格 UTF-8、超限内容和哈希漂移。它直接对读取到的原始字节计算批准哈希，并确认 UTF-8 解码后重新编码的字节完全一致。失败结果只包含稳定诊断代码和 JSON Pointer，不包含协议原文、绝对路径或堆栈。它不会回退读取 `RPG04_PROTOCOL_AUDIT.md`、审批 JSON 或其他候选材料。

当前能力仅是受控文件读取与来源绑定。它没有连接模型、网络或 CLI 发送路径，也没有实现完整的 C2 上下文装配或发送前集成。加载器自身不写文件。

单元测试在不改动真实协议文件的前提下覆盖正常加载、原始字节哈希、审计内容与字节漂移、输入类型与大小限制、调用方参数、结果隔离、符号链接、真实路径逃逸、读取失败、非严格 UTF-8，以及审计材料哈希保持不变。

验证命令：

```powershell
node --test tests/context-protocol.test.mjs
git diff --check
```

回退方式是删除本批新增的加载器、测试和本文档；固定运行协议与审计材料无需修改。
