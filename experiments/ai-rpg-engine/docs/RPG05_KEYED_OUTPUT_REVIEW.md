## 已关闭的实现缺口

第12次原始 SSE 回放证实：传输正常、生成 Schema 通过，完整旧合同因两份 info.rpg04.world 拒绝。原响应没有改写、去重或补提交。

新增 ui-host/keyed-turn.mjs，仅处理宿主与模型之间的版本化格式。模块ID成为固定对象键，字段ID也成为固定键；每个键使用长度0或1的数组表达缺席或提供。例如字段 [] 为未提供，[[]] 为明确提供空列表，[false]、[0]、[""] 均保留。完整字段声明由卡包生成，未知键、缺少必需键、错误类型和重复槽位直接拒绝。

所有深度的重复 JSON 键（包括 Unicode 转义后相同的键）在准入前拒绝，避免 JSON.parse 覆盖前值。只有完整 stop/receipt/DONE 且生成 Schema 通过后才执行声明式转换；转换恢复旧 format/version 及模块、字段数组，保留提供项顺序、正文、列表项、建议、状态提案和不确定项。原始字节与转换后的 JSON 字节分别保存和计算 hash，不宣称两种格式字节相同。

转换后继续执行原 validateTurnExchange。状态提案唯一性、权限、值域与其他语义约束没有取消；这不是对全部输出错误的保证。旧格式也增加了适配器出口完整校验，失败诊断分别记录 transport、JSON、wireSchema、contract 和 binding。

原始 SSE、模型文本及 hash、转换文本及 hash 只存私有证据。冻结的运行时、上下文编译与界面消费的仍是原回合合同。两世界测试确认正式提交、刷新恢复与失败不污染历史，页面投影不出现原始 wire 数据或私有消息。
