## 差异附录

- **顶部时间行：** DeepSeek 直接转录只有位置、环境、现状、出场 NPC；GLM 材料另有时间字段。时间行未加入正文。
- **玩家决定禁令：** DeepSeek 转录含禁止恶意揣测玩家意图，但未取得“禁止替玩家决定”的独立原句；该禁令只存在于用户批评报告/GLM 改写线索，未补入正文。
- **格式标签：** `format_discipline` 只根据用户 GLM 优化版中明确给出的“输出模板格式纪律”字面句恢复被渲染解析的 HTML 字面量，不能验证服务端原始字节。
- **配置 ID：** 主文保留 DeepSeek 样本观察值 `AI-FY-GAME=0e871679`；其他 GLM ID 不加入。该值不认证为卡片固定原始 ID。
- **末尾 FORBID：** `正文FORBID` 已在早先 DeepSeek 第三轮可见转录中出现，按直接来源保留；GLM 将其描述为新增要求不改变该来源事实。
- **世界书与文风：** 本共同模板只出现文风遵循要求和 World 输出面板，仍没有具体隐藏世界书正文或文风资源样例。
