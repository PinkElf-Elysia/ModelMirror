## 3. 影响范围

- 允许修改路径：工作流 NodeContract、runner、文件资产适配、工作流前端类型/配置、工作流测试与能力审计。
- 禁止修改路径：用户持久化目录、真实 `.env`、公开聊天 API、n8n 源码与容器数据、依赖锁文件。
- 实际文件数：38 个；按后端合同/运行器、前端配置、测试审计三个可独立复核批次实施。其中新增的 3 个测试文件变更专门覆盖真实验收发现的变量误报、流式 usage 提取与运行摘要落盘。
- 影响路由/API：不新增公开 API；Node Registry 安全投影与 SSE 既有变量内容会增加新节点数据。
- 影响持久化数据：不迁移 Store；复用现有文件输出记录及 TTL。
- 新增或升级依赖：无。
- 涉及密钥/网络/文件/子进程/公开访问：涉及文件、渲染 sidecar 和私有 Xpert 作用域；不读取密钥、不新增公网入口。

超过 5 个文件时说明无法安全拆分的原因：前后端联合类型、NodeContract、Registry、运行器、配置界面、测试和审计必须同步，否则会触发既有漂移门禁。38 个文件中 18 个为测试或任务卡/审计文档；通过三个独立可验收批次控制改动面。

## 4. 验收标准

- Given 合法类型化数据，When 使用对象、时间、列表和文件节点，Then 变量类型保持、文件可预览下载、重复执行不重复生成。
- Given 跨工作流/跨对话资产、非法文件名、混合类型、超限集合或 DST 歧义时间，When 校验或运行，Then fail-closed 且不泄露正文、路径或作用域信息。

## 7. 风险与停止条件

- 主要风险：classic runner 回归、文件输出幂等键错误、Xpert 会话作用域穿透、V1 配置兼容。
- 兼容风险：旧时间、文档和逗号列表行为必须保持。
- 安全风险：文件名路径穿越、正文进入日志/checkpoint、跨作用域资产读取。
- 触发停止的条件：需要数据迁移、新依赖、公开 API、真实密钥，或实际范围超出任务卡。
- 观测边界：仅保存模型供应方返回的有界 token 计数；不推算费用，不新增额度、租户或账本字段，等待统一控制面提供正式计量与对账合同。
- 需要用户确认的问题：已在计划阶段锁定，无。
