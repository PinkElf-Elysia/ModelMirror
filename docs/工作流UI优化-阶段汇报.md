# 工作流画布 UI 优化 —— 阶段汇报

> 提交人：前端组　|　日期：2026-08-17　|　分支：`feature/workflow-redo`
> 性质：阶段性成果汇报（对标 n8n / Coze / Dify）

---

## 一、摘要

本轮以「对标 n8n / Coze / Dify」为目标，对工作流编辑器进行系统性升级。从最初的设计计划书（《工作流画布UI重做方案.docx》）开始，历经 **7 个实施批次**，把工作流画布从"静态结构图"升级为"**可观测、可交互、可调试的专业级执行视图**"。

**核心结论**：
- 全部为**纯前端改动**，8 个文件，净增约 **730 行代码**；
- **后端契约零改动**（NodeContract V3、`/api/workflow/*`、节点注册表均未触碰）；
- 构建、类型检查、全量测试全部通过；
- 为「一句话让 AI 自主搭建工作流」目标打下**可读、可查、可改**的信任地基。

---

## 二、背景与目标

### 2.1 背景

ModelMirror 的终极目标是**用户一句话让 AI 自主搭建工作流并运行**。但竞品（n8n / Coze / Dify）的共同模式是：**AI 生成产物 → 回到专业画布让人看懂、检查、修正、调试**。这要求画布具备三个前提：

| 前提 | 含义 |
|---|---|
| **AI 产物可读** | 节点一眼看出当前状态（运行中/成功/失败） |
| **AI 产物可查** | 用户能快速定位问题节点 |
| **AI 产物可改** | 快速修正变量引用、节点配置 |

### 2.2 目标

对标竞品的 11 项画布共性能力，消除差距，达到"专业工具感"水准。

## 四、主要成果

### 4.1 画布交互（从"两步操作"到"一步直达"）

| 能力 | 优化前 | 优化后 |
|---|---|---|
| 节点运行状态 | 画布零反馈 | 运行中呼吸高亮 / 成功 ✓ / 失败 ! |
| 建节点方式 | 先开节点库→拖→连（两步） | 从节点拖线松手 → 弹选择器一步创建 |
| 右键操作 | 仅节点详情 | 配置 / 复制 / 删除 / 添加注释 / 撤销 / 重做 |
| 节点库 | 窄 dropdown | 左侧可驻留面板 + 搜索 |
| 撤销/重做 | 无 | 快照栈 + 快捷键 |
| 日志定位 | 无 | 点运行日志 → 画布自动定位节点 |

### 4.2 运行体验（从"黑盒"到"可观测"）

| 能力 | 优化前 | 优化后 |
|---|---|---|
| 运行控制 | 仅一个"运行"按钮 | + 取消 / 重试 / 运行历史 |
| 结束判定 | 无法区分正常/中断 | 显式完成 / 异常 / 取消三态 |
| 节点失败 | 失败伪装成成功 | 失败节点红框 + 错误角标 |

### 4.3 配置体验（对标 Dify 最大交互缺口）

| 能力 | 优化前 | 优化后 |
|---|---|---|
| 变量引用 `{{var}}` | 全手动输入 | ＋变量选择器（光标处插入，全站可复用组件） |
| 错误提示 | 绿色成功色块（误导） | 红色错误块 |
| 节点默认值 | condition/code 链路断裂 | 已自洽 |
| 资源加载 | 每次挂载重复请求 | 60s 缓存 |
| 大文本输入 | 逐键全量重建 | 80ms 防抖 |

### 4.4 视觉与效率

- 画布高度固定 → 随视口自适应；
- MiniMap 节点按类型分色（与节点卡配色呼应）；
- 顶栏从大胶囊按钮 → 紧凑工具栏，主行动色统一 brand 青。

## 七、价值与意义

1. **竞品对齐**：消除 11 项竞品共性能力中的 7 项核心差距，画布达到专业工具水准。
2. **产品主线支撑**：为「一句话让 AI 自主搭建工作流」提供**信任兜底层**——AI 产物可读、可查、可改，用户才敢点运行。
3. **工程健康**：清理 123 行死代码、修复错误语义、默认值自洽、资源缓存与防抖，降低长期维护成本。
4. **零风险落地**：全程纯前端、零契约破坏，可小步合并、随时回退。
