# OpenRouter 模型快照更新（2026-09-02）

本轮使用同一冻结时点的 OpenRouter 通用目录、模型市场、端点详情及专用视频目录，新增并适配：

- `inception/mercury-2.5-preview`：普通文本推理模型，260K 上下文，目录价为输入 `$0.04/M`、输出 `$0.15/M`。
- `anthropic/claude-fable-5.1`：文本、图片、文件输入到文本输出，1M 上下文，目录价为输入 `$10/M`、输出 `$50/M`；首页第一排旗舰位替代 Opus 5，Opus 5 下移至第二排。
- `minimax/hailuo-3-max`：复用 OpenRouter 异步 Video API；支持 480p/768p、5–15 秒、六种画幅及首帧或尾帧，费用分别为 `$0.05`、`$0.08` 每视频秒。
- `~z-ai/glm-flash-latest`：加入当前目录中的 GLM Flash 路由别名，保留为可调用卡片并放在前六排之后。

Claude Fable 5.1 的 `:batch` 条目作为基础模型的服务档位接入，不形成重复模型卡片，也不计入模型快照数量。Batch 界面只在对话页设置中出现，实际请求仍使用基础模型 ID，通过 Batch API 提交；当前档位价格为输入 `$5/M`、输出 `$25/M`，仅允许文本批处理，完成窗口为 24 小时，保留期为 30 天。

本次同步后的静态口径为 578 个计数快照：499 个明确可用、73 个“可能不可用”、6 个明确过期；站内展示 572 个非过期 OpenRouter 快照。另有 70 个不计数 Batch 服务档位。同步过程中移除了当前冻结目录已经不再列出的 5 个 Mistral Batch 档位，并采用目录现价更新 `qwen/qwen3.8-2.4t-a95b:batch`。

同一冻结时点还修正了 18 项结构化元数据漂移，覆盖目录价格、支持参数和过期时间；3 个已不在目录中的 Claude Opus Fast 条目转为“可能不可用”。模型市场侧栏元数据同步为 499 个聚合快照。复核结果为：普通模型、Batch、图片和视频缺失均为 0，结构化元数据、生命周期、operation、任务能力、市场快照及侧栏离散选项差异均为 0。

Hailuo 3 Max 已完成参数、异步提交/轮询和费用估算契约适配，但未执行会产生外部费用的真实视频生成；因此证据状态为 `adapted_contract`，不宣称完成真实 Provider 生成、播放和下载验收。

回退时可移除三个模型快照与 Fable Batch 服务档位，撤销 Hailuo 3 Max 的视频注册和市场元数据，并恢复首页显式编排；无需删除数据库或历史回执。
