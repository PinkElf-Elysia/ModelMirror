- 基线：origin/main 45ee30b5；工作树 C:/tmp/modelmirror-rpg-library；分支 codex/rpg-library-publishing；开工时干净。
- 目标：现有十个入口统一卡片排列；工作台本地发布版本自动加入故事馆；草稿与发布快照分离，保留旧会话绑定。
- 范围：client/src/pages/Rpg*、rpg 样式/目录工具、authoring 本地目录及作品入口、对应测试和帮助内容。分批修改，每批不超过五个文件。

- 接口：新增仅在 loopback 上提供的已发布作品目录 GET；只允许 loopback 故事馆读取脱敏展示字段与已发布封面。草稿、资源库和修改接口的同源校验保留。

- 风险：中；涉及本地文件读取和有限的 loopback 只读跨源访问。模型调用、安装、预算保持显式触发。
- 验收：目录 HTTP 测试（草稿不可见、版本固定、重复发布、资源/来源边界）；前端统一布局、查询/筛选、失败恢复测试；现有 authoring/server 与 RPG 回归；client typecheck/build；隔离临时库的可见发布→首页→打开作品检查。
- 回退：还原本任务源码即可；新产生版本仍按原格式保存，不回滚或删除作品数据。临时测试目录不纳入提交。
- 帮助：同步用户帮助与本地创作指南；当前无 PR 授权，后续发布前按仓库门禁补齐同基线证据。
