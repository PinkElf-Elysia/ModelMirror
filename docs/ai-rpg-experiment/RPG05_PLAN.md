## 最新交互替代原计划
1. 平台外壳负责会话、输入、生成/取消、恢复、导入、受限安全展示、阅读设置。目标卡配置适配负责角色→模式与世界→身份与天赋→核对。作者 HTML/CSS/JS 自有 UI 不等于平台 UI；本轮不加载执行作者脚本，不建设通用 UI 插件产品。
2. 角色字段：姓名/性别/年龄/外貌/性格/XP/其他设定。XP 映射 preferences，不窄化为普通旅行爱好；其他设定映射 notes。性别可自定义。不得静默截断或重写输入。
3. 开局模式按卡片声明保留全新攻略者/继承/沙盒（体验者）。mode 可存储不证明机制已实现；缺配套数据时阻止启动。自定义世界可保存，但必须验证 compatible opening/profile/scene，不借用不匹配场景或补造主持词。不修改 RPG04 运行提示词。
4. 背景与物资是可选补充，不成为目标卡必经独立步骤。身份单选、背景多选、物资数量、天赋拥有/激活分别表达。资源等级不等于人物战力或权限。
5. 删除候选审批和状态冲突审阅；生成成功并校验后由宿主内部提交，用户无需勾选状态字段。内部原子性和既有合同不因此移除。底层状态接受策略须绑定卡片允许字段，不能机械全选未经验证字段。
6. UI 不额外抽取固定人物/物品/场景状态栏，正文及卡片声明信息模块安全展示一次。未来系统权威状态栏延期。保留 raw HTML 禁用、脚本禁用、远端图不自动加载、外链显式操作，不因原卡形式放开执行。
7. 输入仅文本框与纸飞机；有输入时占位说明消失。生成时可预写草稿但不能并发发送，停止图标取消。没有快捷工具栏/生成模式切换。模型正文中的建议非穷尽；建议填入可编辑文本，不自动派发。输入 kind 映射须显式固定适配规则，不让自由文本猜测权限或任意 commandRef。
8. 重新生成只针对最新回复：新调用，旧结果直到替代成功前保留，失败/取消不丢原回合；删除最新回复先确认，回到上一回合且保留输入，不触发调用。历史证据保留，不物理抹除回执。旧公共合同保持，操作在宿主增量层实现。
9. 已批准小字号/轻量控件、暖白/深绿/书页标志。详情与保存记录默认关闭。原型示例资源、时间、token 数不能混为真实证据。显著流程/布局变化须另批原型。
