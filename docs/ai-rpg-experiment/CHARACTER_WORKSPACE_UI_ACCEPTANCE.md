## 发现与最小修复

| 问题 | 修复 |
| --- | --- |
| 手机角色库隐藏侧栏后，没有群聊入口 | 顶部提供手机导航；编辑页去除重复侧栏链接 |
| 群聊创建页刷新丢失场景、版本等输入 | 在当前标签页 sessionStorage 暂存创建字段及精确版本引用；创建成功清除；失效版本保持空选并禁止创建 |
| 版本深链接在刷新时覆盖用户后来改选的版本 | 首次预选后消费链接参数，后续使用当前创建草稿 |
| 未保存角色恢复后误显示“草稿已保存” | 恢复后明确显示“未保存”，包含尚未首次保存的新角色 |
| 版本载入时立即点击预览无响应 | 载入期间禁用编辑、预览、对话切换，完成后恢复 |
| 窄屏首次进入群聊时开场顶部被自动滚过 | 首次绘制从顶部展示，保留角色署名；后续历史更新沿用原滚动规则 |

不改变标准角色卡字段、模板封存、会话预算、网关合同、运行指纹或权限判断。聊天未发送输入的刷新持久化仍不在本轮范围；它与创建表单草稿的暂存不同。
