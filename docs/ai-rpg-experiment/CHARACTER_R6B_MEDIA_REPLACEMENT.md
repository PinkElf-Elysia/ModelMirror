# R6b 交付点 3 · 替换草稿中的已有音视频引用

交付点 1、2 已获用户验收。本次以 main@ca0bb539 建立独立工作树，逐文件核对交付点 2 的 12 个累计文件及中性素材，原工作树和证据保留。

## 作者操作

在草稿的「基础与肖像」展开「角色包资源与引用」。每条已绑定的本地音视频声明都有独立按钮；两项共用同一路径时显示引用数。先保存文字修改，在目标行选择文件。音频可在 PCM WAVE 与 MP3 之间替换，视频接受通过现有检查的 MP4。成功后草稿保存一次，作者可封存新版。已封存版本只读。刷新后仍可从原版本导出当时的资源，或另行下载导入时的完整原件。[创作指南](../../client/src/content/help-center/articles/exchange-character-charx.md)

## 绑定和写入

沿用同源创作 API，新操作为 POST /rpg-app/api/authoring/characters/charx/replace。请求字段为 workId、expectedRevision、operationId、index、extension 和 base64。index 是该修订的 V3 assets 数组位置。宿主检查作品归属、文件分类、大小、容器和期望修订；已有角色包中的图片、远程 URI 和未绑定声明不能作为替换目标。每次只修改选中声明的 uri 和 ext，保留名称、用途、顺序和未知字段。

每次替换都分配新的包内路径，包括同格式的单用途文件。生成的文件名不包含本地作品或会话 ID。保存前按同一打包器核对文件集合、体积和容器。宿主先保存不可变字节和作品归属记录，再用作品存储的修订检查写入草稿。旧版依其固定声明与封存时修订读取原字节。副本继承复制时的修订边界，后来写入父作品的路径不能通过早期副本引用。

保存采用已有操作回执；相同请求可显式重试并取得原结果。上传参数变化、双标签页修订过期及跨类替换都会被拒绝。读取、刷新和重启只恢复已有状态。若宿主报告结果未知，可点击「核对上次替换结果」查询原操作；写入中断可能留下未被草稿引用的本地内容块，原包和既有版本继续保留。
