# R7 交付点 3 · APNG 主肖像

在封存版本预览、单聊和群聊中，点击角色名旁的「播放肖像」。暂停保留当前画面，「继续播放肖像」继续播放，「静态肖像」回到独立 PNG 封面。每个面板一次播放一个角色。初次进入和刷新时均显示封面；系统切换到减少动态效果时也会静止。选择表情后优先显示所选表情。缺少动画解码能力时保留封面。

## 导入和版本

本次扩展本地 V3 CHARX 的主肖像。接受声明与文件一致的 `.png`、`.apng`，唯一用于主肖像的包内文件。动画像素支持 8 位 RGB、RGBA、非隔行，允许局部帧、透明度、独立默认图及有限或无限次循环。播放最短帧间隔为 50 毫秒。GIF、动画 WebP 和其他用途的动画继续保留原包；独立酒馆卡 PNG 继续使用原有静态肖像路径。

采用 PNG 第三版的动画控制、帧控制和帧数据语义。[W3C PNG 第三版](https://www.w3.org/TR/2025/REC-png-3-20250624/#apng-frame-based-animation)

| 单文件门槛 | 上限 |
|---|---|
| 原动画大小、数据块数 | 4 MiB、1,024 块 |
| 帧数、画布 | 60 帧、1,048,576 像素 |
| 累计解码工作量 | （声明帧数 + 1 张默认图）× 画布面积 ≤ 12,582,912 像素 |
| 单个压缩像素流 | 按该帧通道数、宽高和每行过滤字节计算精确解压长度。检查 CRC、帧数、序号、矩形、控制值、解压结束位置及行过滤值。 |

原 APNG 按哈希留在本地。封存作品使用独立静态 PNG 封面，播放版本只携带渲染所需的受支持图像块；导出 CHARX 使用该版本的原资源。新版本改用其他封面后，旧版本仍能读取原动画。资源读取核对当前入口、成员实例、参与区间、封存版本和资源标识。切换页面、恢复静态、解码失败和成员离场时终止读取、清除计时器并关闭解码器；迟到帧会关闭。

主要改动在 `character/apng.mjs`、CHARX 检查／导入／导出模块、`presentation/store.mjs`、`presentation/panel.mjs`、`presentation/portrait.mjs` 和各入口的静态文件登记。中性夹具的运行数据与首次失败记录留在独立数据目录。
