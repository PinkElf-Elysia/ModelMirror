# R7 交付点 2 · 已有音视频播放

角色版本预览、单聊和群聊的「角色包音视频」列出封存版本内的 WAV、MP3、MP4。选择媒体后点击「播放」。暂停保留位置，「继续播放」从原位置继续，「停止」释放播放器。切换媒体后须再次点击播放。MP4 的编解码支持取决于浏览器。识别到文件但无法解码时，页面提示失败并释放播放器。

## 读取与生命周期

媒体仅从已校验的本地包读取。每个播放标识绑定当前入口、确切角色版本、成员实例、资源及哈希；群聊还绑定成员本次参与区间。宿主在每次读取时验证绑定和文件内容，支持单段字节范围，返回准确的媒体类型与范围。远程引用不出现在播放列表。读取沿用入口现有权限。播放没有持久化状态，刷新后须重新操作。

三个入口复用 `character/presentation/player.mjs`。切换会话、版本、媒体，离开页面，以及自然结束、解码失败都会停止并移除媒体元素、清空资源。单聊和群聊页内刷新也会停止。群聊在本页成员状态更新时立即检查来源；媒体播放或暂停期间，每秒复核来源的参与区间。其他标签页的离场在下一次成功核对时生效；读取超时也停止。旧区间的播放标识在重入后失效。

读取实现位于 `character/charx-import.mjs`、`character/presentation/store.mjs`，由 `character/http.mjs` 与 `character/group/server.mjs` 接入。界面接入位于 `character/presentation/panel.mjs`、角色编辑器及群聊浏览器模块。播放无需改变卡片版本、聊天历史、预算或模型请求。

## 离线验收记录

| 核对项 | 结果 |
|---|---|
| 版本预览、单聊、群聊 | Chromium 在 960px 和 390px 宽度对 WAV、MP3、MP4 完成 18 组播放、暂停、续播、停止；暂停时进度稳定，续播后继续推进；MP4 已解码画面。 |
| 版本和实例隔离 | 两个封存版本使用不同的 WAV。五个来源的实际响应按原文件逐字节核对；同一群内同模板实例的播放标识可区分。 |
| 切换、离场、重入 | 切版本、切单聊、切群聊均释放原媒体。群内播放视频时点来源成员离场可停止；另一个标签页操作离场也会终止已暂停的媒体。重入后旧标识不可读。 |
| 刷新与异常 | 三入口全页刷新后无媒体读取、无自动播放。另验页内刷新、切换文件、跳转播放位置、自然结束及不支持的编码。浏览器验收期间零外部资源请求。 |
| 资源释放 | 旧节点脱离页面、暂停、无 src 属性，网络和就绪状态清零，缓冲区为空。首轮浏览器脚本误以为 Chromium 必须清空 currentSrc；单独复核后采用上述可观测指标。保留首轮失败记录。 |
| 自动检查 | Windows 组合回归 79/79，禁网 Linux 表现层 8/8。父前端与聊天前端生产构建通过，父前端保留包体积提示。 |
| Provider 审计 | 三个浏览器与宿主模块的源码指纹更新后，审计仍返回基线原有的 11 行诊断；本轮输出与同基线干净副本 SHA-256 相同。 |

本轮使用原创中性夹具。上述结果覆盖 Chromium 桌面和模拟窄屏；物理设备扬声器、真机触控和其他浏览器解码兼容仍待验。交付点 1 的设备延期和既有失败见[静态表现验收](./CHARACTER_R7_STATIC_PRESENTATION.md)。R4c ①人工采纳和精确端点、②刷新后实时增量和精确端点继续待证；④仅确认宿主停止读取，供应商最终计费待证，保留 US$0.018990 未结预留。

本地预览可以单独停止。夹具、浏览器截图和日志位于独立数据目录，旧卡片、旧会话及既有验收记录保留。
