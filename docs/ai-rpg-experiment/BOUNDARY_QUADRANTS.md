## 审计使用方式
- 第一版完成度以 A 象限中的**卡片主体链路**和 C 象限中的**零插件运行框架能力**为中心，不以四类卡片特化机制的完整度计分。
- A 象限标有 ↓ 的项目必须按弱化范围验收，不能把“能显示一个样例”报告成“已复刻完整机制或全量资源”。
- C 象限是自主设计增量，不应被描述为原卡已有能力；B 象限则是明确的未覆盖、弱化或有意排除项。
- D 象限在第一版后严格分流：角色卡和内容资源进入卡片市场；所有可选功能、模块与优化包进入插件市场。用户自主选择，卡片不得静默安装插件。
