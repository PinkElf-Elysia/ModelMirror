### API 和配置

`/rpg-app/earth/api/sessions/:id/model-catalog` GET 需要该会话已授权模型选择插件，只返回安全目录。

`.../model-selection` GET 返回当前核心选择、整数版本与能否选择；canSelect 综合插件授权、运行版本、忙碌/未确认请求及服务开关，不会因为已安装就自动放行。POST 接受 operationId、expectedSessionRevision、selectionRevision（会话整数版本）、selectionId、catalogRevision（控制面目录 hash）。浏览器不能提交受信 system、模型参数配置、API 地址或供应商。

v2 `.../send` 增加必填 expectedSelectionRevision，与聊天 revision 一并检查。旧 v1 send 接口不变；v1 不开放模型选择。

默认不启用新服务路径。只有服务器 `start({modelControl: ...})` 或 `RPG_MODEL_SELECTION_ENABLED=true` 才使用 v2 存储；CLI 还通过服务端 `RPG_CONTROL_URL/RPG_S2S_TOKEN/RPG_ENABLED` 配置 B2 适配器。未设置真实值，也未运行 CLI 开关。固定默认模型仍走原已批准路径；切到控制面模型后每次发送重新检查资格投影，失效则阻断，不回退到固定默认模型。旧/new 适配器共享 `dispatches/earth/slot-*`，不能由 modelControl 改成另一目录或另一个额度。
