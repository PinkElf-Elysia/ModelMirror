# RPG 场景插画

Earth 和 God 的共用会话支持两种入口。在插件市场安装「场景插画」，并在目标会话的插件面板启用。点击「生成图片」可以从空白描述开始；点击已完成回复旁的「生成插画」则把图片绑定到该回合。选中的文本优先作为素材；God 翻到特写面时会取当前镜头，其他情况取本回合正文。取景原文可编辑，最多 16000 个 Unicode 字符；超出时须手工缩短，避免静默截断关键镜头。

点击「改写提示词」会单独调用界面列出的文本模型一次。模型收到取景类型及素材，整理为单幅插画的主体、动作、环境、构图、光色与媒介。可以继续编辑结果或直接手填。确认生成图片时只交付最终提示词。没有自动改写、自动出图或失败自动重试。改写授权和预算独立于剧情；失败也可能占用一次派发额度。

1.1.0 新增改写权限。旧安装需通过插件管理更新并在会话重新授权；图片档案路径沿用原版。部署新版 Studio 和卡片静态资源后，在宿主启动环境设置 `RPG_ILLUSTRATION_REWRITE_ENABLED=true`、`RPG_ILLUSTRATION_REWRITE_CALL_LIMIT`（每种卡的独立上限）、`RPG_CONTROL_URL` 和服务端 `RPG_S2S_TOKEN`。文本模型默认使用 Earth 配置的 Gemini，可用 `RPG_ILLUSTRATION_REWRITE_MODEL` 指定受控目录中的模型。调用凭证和 dispatch 记录留在宿主，目录为 Studio 数据目录下的 illustration-rewrites。关闭改写开关并重启即可恢复纯手工出图。

交互参考 [SillyTavern 的场景改写与生成前编辑](https://docs.sillytavern.app/extensions/stable-diffusion/)。

目录来自 /api/multimodal/image/models，只列可调用、就绪且适合单张文生图的配置。画幅、分辨率、质量、输出格式和背景仅显示模型声明的枚举选项；模型切换会清除旧参数。目录存在单一明确的每张输出价格时显示估算，复杂费率显示单位价格，缺失价格标记为未知。没有平台积分到美元的固定兑换。

确认后，宿主校验会话授权和回合，保存操作 ID，再通过 /api/multimodal/image/generations 提交一次请求。图片调用与剧情额度、输入历史和记忆整理分开；授权剧情调用不会自动生成图片。该 API 负责提供方请求格式和返回格式归一化。首版支持单张文本生图；需要参考图的配置不在列表。剧情图片保存在对应回复下，自由生图保存在会话图片区域。可点击查看原图，展开查看原始描述，费用以控制面回报字段为准。

图片和生成记录保存在 Studio 数据目录的 illustrations 子目录，按卡片、会话和操作 ID 隔离，图片读取时验证哈希。图片附在原会话，不写入 TXT 聊天历史，不自动复制到分支。重复提交同一操作返回原记录；同 ID 不同内容会被拒绝。断线或重启后先读取记录，结果未知时不自动重发。插件停用后停止使用对应能力，重新启用可读取保留的图片。

命令行和容器宿主默认登记本插件；RPG_IMAGE_ENABLED=false 可关闭登记，RPG_CONTROL_URL 指向宿主可信的本机或 server 控制面。嵌入式测试可向 start 传入独立 illustrationService。离线演示使用固定样图和虚拟回执，不产生真实费用。

从 experiments/ai-rpg-engine 运行 node --test studio/illustrations.test.mjs 可验证授权、选择校验、重复提交、任务失败和恢复。真实验收需单独授权图片调用，核对实际模型、计费回执、像素可读性和回合归属。
