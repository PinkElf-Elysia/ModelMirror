# R5b 交付点 4 · 装饰器回退链

在新建或派生的角色书分支启用“装饰器回退链”，并勾选希望实际使用的条目规则。每个以 `@@` 起行的主规则可紧跟若干以 `@@@` 起行的备选。例如：

```text
@@fixture_lamp 1
@@@scan_depth 1
灯芯收在木盒里。
```

上例中的主规则未受支持。若该分支启用了条目扫描深度，宿主会选用第二行，并仅用最近一条可见消息检查关键词。创作试算使用书架上勾选的规则。实际分支以宿主保存的能力为准。预览列出检查过的候选、跳过原因和选择结果。

- 按声明顺序选第一个已实现、参数有效且在该分支启用的规则。未知规则、分支关闭的规则、已知规则的无效参数允许继续查找备选。选择发生在关键词匹配、时序判断、一次性占用和预算校验之前。
- 一旦选定，关键词未匹配、尚未到时、次数已用、容量或预算不足都结束于原有判断。多个主规则分别选取，再按现有组合语义共同生效。多组选择同名规则时使用首次选中的参数。
- 本轮识别一次性、条目扫描深度、延迟、周期四个装饰器。每组最多 8 个备选，每条最多 16 组，每行装饰器最多 512 个 UTF-16 代码单元（行结束 LF 之前）。任一组无可用规则、存在孤立备选、格式损坏或超限时，整条跳过并保留源文。
- 回退链只在获准的 V3 卡内书或独立角色书中解释。解析不更改模板，不执行扩展脚本。源卡导出保留所有候选、未知字段和原始换行。旧分支继续沿用原策略。
- 版本标识为 `ordered-decorator-fallback/1`。预览与发送共用装配器，发送固定原请求的正文、哈希和选择诊断。精确重生成沿用原请求，派生分支按继承位置采用规则。停用本轮预览可回到上一独立副本。

在实验目录执行 `node --test character/book-library/fallback.test.mjs` 可复验。使用 `node character/book-library/fallback-preview.mjs <独立目录> 0 0` 启动中性夹具。在初始角色的分支输入“对灯”并预览，灯芯条目选择备选，交班条目选择主规则并等待第 2 条角色消息。生成一次离线回复，再预览“对灯”，交班条目即满足时序条件。

格式依据来自[固定版本的 CCv3 装饰器定义](https://github.com/kwaroran/character-card-spec-v3/blob/f3a86af019fbd99f788f7a1155f399655b34ab35/SPEC_V3.md#decorators)。
