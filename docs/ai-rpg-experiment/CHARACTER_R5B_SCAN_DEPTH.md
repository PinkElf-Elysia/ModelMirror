# R5b 交付点 2 · 条目扫描深度

新建角色书会话分支时可勾选“在新分支启用条目扫描深度”。书架的“按条目扫描深度测试”可直接用一条输入试算草稿。会话分支预览显示每条规则的深度、实际扫描的历史条数，以及本次输入是否计入。已有分支可在选定位置派生后启用。

## 作者规则

在 V3 卡内书或独立角色书的条目正文首行写 `@@scan_depth N`，下一行写正文。N 取十进制整数 0–200。该条目的设置可以大于或小于书级 `scan_depth`。其他条目保留书级行为（历史消息默认 4 条，另加本次输入）。规则依据为 [CCv3 固定版本的条目扫描深度定义](https://github.com/kwaroran/character-card-spec-v3/blob/f3a86af019fbd99f788f7a1155f399655b34ab35/SPEC_V3.md#scan_depth-1)。

| 条目设置 | 玩家发送时 | 指定角色接话时 |
|---|---|---|
| 0 | 关键词窗口为空 | 关键词窗口为空 |
| 1 | 只查本次输入 | 只查最近一条可见历史 |
| 2 | 本次输入和最近一条可见历史 | 最近两条可见历史 |

每条完整消息占一个位置。目标成员可见且最终保留的开场按一条历史计。宿主的接话指令、对话示例和记忆均不占位。常驻条目继续沿用原常驻规则。关键词、次级关键词和受限正则均在本条窗口匹配；受限正则须单独启用。深度条目只扫描消息，其已匹配的正文仍可参与同书普通条目的递归匹配。

`@@dont_activate_after_match` 可与深度规则分行组合，顺序任意，需同时启用两项。缺失参数、超限、重复声明和未支持的组合保留源文，跳过执行。导出仍保留作者原文、扩展和换行。较晚轮次的装饰器沿用未支持行为。

## 装配与兼容

分支保存 `entry-scan-depth/1` 及启用位置。按分支点继承规则；从启用之前的消息派生时可显式启用。宿主先按成员参与区间与接收范围过滤，再计算窗口。历史因设置或容量而缩短时，用保留的消息重算命中，随后按原书级和请求级预算决定是否纳入。条目诊断保存数量和结果，省略的私信、缺席消息及其标识不会出现在成员预览中。

预览和发送使用同一装配器。宿主核验预览哈希，并保存实际请求正文、哈希和最终条目诊断。精确重生成沿用原请求。旧分支继续使用创建时的策略；源码兼容只接受已核验的精确描述符。回退时停止专用预览；旧宿主继续打开原副本。

## 离线复验

在实验目录执行 `node --test character/book-library/depth.test.mjs`。专项覆盖深度窗口与接话、无效声明及 PNG 往返、次级词和正则、缺席与私信隔离、实际容量裁剪、保存和重启、精确重生成、分支继承与一次性规则组合。

`node character/book-library/depth-preview.mjs <独立数据目录> 0 0` 在回环地址启动中性夹具。开场提到“水位”。预览“继续”，深度 2 的“上一条观测”命中；深度 1 的“眼前的水尺”未命中。清空输入后选择接话预览，两条都可看到开场。页面中的发送仅生成本地夹具回执。
