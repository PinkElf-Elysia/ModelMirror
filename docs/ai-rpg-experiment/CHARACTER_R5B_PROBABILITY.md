# R5b 交付点 7 · 概率触发

在 V3 卡内书或独立角色书的条目中填写「触发概率（%）」并封存。新建或派生角色书分支时勾选概率规则。留空沿用原有触发条件，0 表示每次跳过，100 表示每次通过概率判定。通过后仍要满足容量和预算约束。

配置存于条目 `extensions["modelmirror.probability"]`，接受 0–100 的整数。非法值保留原文，分支跳过符合其他条件的该条目并给出诊断。第三方扩展原样往返。卡片导出包含配置，抽取值与请求记录留在会话。V2 卡内书以及未启用概率规则的分支沿用原行为。该字段使用模镜独立实现的语义。[CCv3 固定版角色书字段](https://github.com/kwaroran/character-card-spec-v3/blob/f3a86af019fbd99f788f7a1155f399655b34ab35/SPEC_V3.md#lorebook-fields) · [World Info 触发文档](https://docs.sillytavern.app/usage/core-concepts/worldinfo/)

## 同一轮如何复现

| 操作 | 判定依据 |
|---|---|
| 书架草稿试算 | 固定的创作示例，实际分支可有不同结果 |
| 会话预览、编辑本次输入、刷新、正式发送 | 对同一成员、回复位置和封存条目复用同一抽取值；输入变化可改变关键词资格 |
| 另一成员回复入史 | 当前成员继续使用原判定位置 |
| 本成员有新的正式模型回复入史 | 下一次匹配按新的回复修订取值；连续两轮可能恰好抽到相同结果 |
| 未知结果与重启恢复 | 从已保存的请求核对原结果；恢复采用完整回复后才推进 |
| 精确重生成 | 重用原请求上下文及其条目诊断 |
| 新建派生分支 | 新发送使用子分支自己的取值空间，父分支记录保留 |

宿主按会话族、分支、目标成员、最近一条可见的该成员正式模型回复修订、封存来源和条目位置生成确定性百分位。抽取范围为 1–100，值小于或等于设置的百分比时通过。此规则让作者可以复核同一轮的预览与发送。

成员可见性、扫描窗口、关键词或正则、一次性、冷却等规则先决定匹配资格。通过资格判定的条目才参与概率判定；未抽中的正文不参与递归匹配。已启用持续触发的条目也要通过本轮概率判定。预算或容量裁剪后按最终可见窗口重新装配。只有最终纳入且正式回复被采用的条目才产生相应的一次性、持续或冷却效果。分支预览列出抽取值、设定概率以及最终采用或省略原因，未授权的书不返回诊断。

## 离线复验

在实验目录执行 `node --test character/book-library/probability.test.mjs`。运行 `node character/book-library/probability-preview.mjs <新数据目录> 0 0` 可打开中性夹具「渡口风声簿」。输入「听风」，观察风旗（100%）、风铃（50%）、静钟（0%）。刷新后重复预览，再生成一条离线回复，比较前后取值。回退时停止该预览并打开前一交付点副本，独立数据目录可留存。
