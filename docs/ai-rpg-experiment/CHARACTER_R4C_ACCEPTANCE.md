## 首次失败和未验证项

第一次网关收集缺少 Python 包父目录。第二次仅挂载后端，缺少三个跨语言用例的 Node 实验目录。第三次挂载两端后，父应用导入尝试写入只读世界目录；只重定向世界目录时，又遇到独立的运行时目录所有权检查。最终在一次性禁网容器内使用可写的临时后端副本和只读 Node 宿主，完整七文件门禁通过。

Windows 四入口组合回归第一次遇到固定端口占用。已改为测试使用系统分配的端口，工作台创建失败时逆序关闭已取得的资源。首次页面脚本在异步页面恢复前读取了隐藏输入框；改为等输入框可见，再断言草稿原文，两个视口通过。首次失败与后续输出分别保存在仓库外。

原生文件选择器取消、真机软键盘、触控及系统返回延后。R4b 第 5 项精确供应商端点仍按历史报告待证。R4c 的真实模型质量结论仅限上表已观察的行为。自动触发的六条消息门槛由离线回归验证。供应商真实多进程竞争、设备断电、远端 CI 与全量后端测试未验。
