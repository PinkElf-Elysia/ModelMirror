# RPG 语音输入插件开工契约

- 基线：a6563a9b（已合并 TTS PR #464）；独立工作树 codex/rpg-speech-stt，开始时干净。
- 单一目标：共用 RPG 聊天输入栏的麦克风直接录音、停止转写、追加草稿；独立插件面板保存本浏览器的启停、模型、语言与录音时长。
- 复用主线 /api/multimodal/audio/models、/api/models/provider-workload-control、/api/multimodal/transcriptions。浏览器只访问同源主仓接口；路由、认证与额度由既有服务控制，不增加独立供应商连接或预算。
- 允许：card-replica 的语音输入模块与聊天接线、必要前端测试和帮助内容。禁止：作者提示词、存档、共享容器、后端调用合同、凭据、旧阶段护栏、克隆、真实模型调用。
- 本地 UI 插件不注册新的剧情运行能力，不改变服务端插件授权或存档指纹；配置和未确认请求在浏览器保存。不会自动发出剧情消息。
- 超过五文件的原因：录音状态机、类型声明、UI、样式、测试、聊天接线与帮助必须共同覆盖同一用户操作；分批验证。
- 风险中等：麦克风权限、录音隐私、计费请求、草稿持久化。取消/离开时释放音轨；音频仅临时存在内存；请求不自动重试；结果不确定保留操作 ID，显式核对后才能新录音。
- 验收：node --test tests/voice-input.test.mjs；RPG npm test / npm run build；主仓针对性 UI 测试；独立离线预览桌面和390px操作。真实录音/供应商效果需单独授权和人工验收。
- 回退：移除新增前端入口及模块即可；无数据迁移，无部署，本轮不提交或发布。

## 交付与验收（2026-11-13）

实现范围：共用聊天界面的语音输入；默认启用、自动语言、目录首个可用模型、60 秒。玩家可保存指定模型、语言、30/60/120 秒上限。输入栏只新增44×44麦克风，设置及上次结果在独立面板，也可从会话插件面板进入。设置跨本浏览器会话共用，请求/识别结果按卡片和会话隔离。商店原型、工作台专用聊天及其他专用布局未接入。

模型合同：只读取主线语音目录并检查 multimodal_transcription / audio_transcription 控制面状态。Managed 路由只接受 certified_input_formats，Legacy 仍由主线的 ready/invocable 门禁约束；指定模型失效不回退。使用原有 multipart 转写端点及 Idempotency-Key，不新增供应商访问、密钥、预算或后端 API。TTS 既有控制面路径保留。

录音：浏览器格式交集优先，必要时本地解码为16kHz单声道PCM WAV。停止后提交一次，取消、切后台或离开时释放音轨；请求提交后停止等待不代表供应商撤销。未知结果保存操作编号，禁止自动重发。录音不落盘。识别结果只追加草稿，持久化失败不更新草稿；不自动发送，不写剧情记忆。
