## 原始发现与修复后验证

1. 首次卡片 iframe 空白：普通构建引用根 `/assets`，改用已支持的 `--base=/rpg-app/earth/` 重建，页面恢复；写入操作说明。
2. 设置浮层可能以刷新后的 revision 覆盖其他编辑：改为保存原编辑版本，冲突保留未保存文本，新增前端回归通过。
3. Windows 同时轮询与原子 rename 冲突：真实首轮正文已保存，最终 journal pending；原操作恢复成功，无重复调用。新增 HTTP 并发回归复现 EPERM，M2 会话短读写串行后原用例通过。模型选择最终发布也共用这条文件边界。初版无限轮询测试自身积压，停止后改为有限、可收束轮询再通过。
4. 桌面 radio 被卡片全局输入框宽度挤压，390px 浮层 max-width 覆盖响应式约束；分别修复局部 CSS，保留之前截图，重新实测通过。
5. 首批离线适配测试发现模拟额度越界、内部合成 token 长度不足、假响应缺 JSON Content-Type，修复测试宿主后通过；均未派发外网。
6. 日志包装器末尾以 GBK 打印 Unicode 失败，但落盘的 Node regression exitCode=0、183 pass 已核对；最后重新归档时使用 UTF-8。
7. 收尾发现 CRLF 造成已跟踪文件整篇 diff，恢复原 LF 后 diff 最小化。因 runtime 按字节绑定，新建 v3 数据；v1/v2 原证据保持不动，不迁移会话。最终 v3 四回合是 HTTP 创建审阅样例，单独标注，不冒充全路径 UI 重跑。已用浏览器重新打开 v3 四回合与设置浮层，确认覆盖第 3 回合；帮助正文和两张图片均实际加载成功。
