## 本批实现

- 新宿主通过显式 `connectSummary` 接通受控任务。HTTP、正式 UI 和离线样例适配仍在 B4；本批不更新预览服务。离线会话不能借此进入受控真实传输或预留额度。
- 零插件的首轮、续轮实际发送数组与既有装配逐字一致。M2 首轮不变；有 T 个完成回合时，摘要覆盖 1…T−1，保留第 T 回合原文，再装配本次前置词、输入、后置词。
- 摘要只在冻结 system 末尾追加一次 B0 已批准的数据段；作者正文、参数及历史原文不改。M2 生效时不应用 M1 的窗口和开局角色资料补入；停用恢复 M1 或完整历史。
- 每个剧情回合绑定请求 hash、选中回合、摘要版本和当时设置。剧情模型 revision 纳入统一上下文 revision；切模型不改摘要模型或预算，旧页面提交被拒绝。
- 分支从该回合的绑定快照继承摘要与设置，排除后来人工修订或后台总结。不继承插件授权、任务日志、可执行请求或预算；原请求回执作为来源保留。新分支可走完整历史，再明确启用 M2。
- 提交在副本中校验完整历史和回执，只替换已验证的剧情字段，保留正在运行的任务对象。已完成剧情落盘失败后，原操作可从保存的 Provider 结果恢复一次，不重新派发。
