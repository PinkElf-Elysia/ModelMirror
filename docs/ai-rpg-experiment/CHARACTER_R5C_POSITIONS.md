# R5c · 提示词插入位置

在「独立角色书 → 会话分支」启用「提示词插入位置」。为 V3 卡内角色书或独立角色书的条目指定位置时，在正文首行写装饰器，下一行写要插入的文本。未启用的分支保持原合同。

| 声明 | 纳入位置 |
|---|---|
| `@@position before_desc` / `after_desc` | 人物描述之前或之后。在描述为空时仍保留描述所在的边界。 |
| `@@position personality` | 性格段末。 |
| `@@position scenario` | 单聊场景或本群场景段末。 |
| `@@depth N` | 保留的可见聊天消息中，倒数第 N 条之前。0 表示在最新一条之后，超过保留条数时移到最早一条之前。 |

**顺序。** 宿主规则与身份 → 普通人设前条目 → 描述前条目、描述、描述后条目 → 性格及其条目 → 场景及其条目 → 普通人设后条目 → 单独标注的对话示例。历史深度只数最终保留的消息，包括保留的开场与本次玩家输入。群聊接话不补造输入；群聊调度与历史后置指令在所有聊天位置之后。相同位置依照现有书目合并顺序与 `insertion_order` 排列，优先级仍用于预算准入。

**运行边界。** 支持 0–200 的整数深度。位置和深度同时出现时，优先具名位置。性格或场景段缺失时省略该条并显示原因；不合法的值也作省略。聊天深度条目是请求中的设定消息，未写入玩家或角色的历史。宿主没有开放角色伪装、assistant 预填、文本指令深度或任意提示词位置。规范来源为 [Character Card V3 的装饰器定义](https://github.com/kwaroran/character-card-spec-v3/blob/f3a86af019fbd99f788f7a1155f399655b34ab35/SPEC_V3.md#position)。

**预览与证据。** 目标成员的阅读范围先于书条目匹配。容量裁剪后按保留的历史重算，额外消息开销放不下时按准入优先级舍弃深度条目。界面显示实际插入顺序，可展开最终消息原文。宿主保存最终消息、哈希、费用预留及原书版本上的定位记录。派生后换书仅影响新发送。精确重生成读取原上下文和插入证据，恢复不重新定位。没有位置证据的旧请求沿用原行为。

在实验目录执行 `node --test character/book-library/positions.test.mjs`。独立预览可用 `node character/book-library/positions-preview.mjs <新数据目录> 0 0` 启动，输入「巡查」。使用原创中性材料和本地夹具回执。回退时停止本轮预览并回到交付点 2 副本，本轮记录单独保留。
