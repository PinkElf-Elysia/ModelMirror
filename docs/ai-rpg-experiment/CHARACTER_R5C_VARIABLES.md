# R5c · 会话变量与条件宏

在「独立角色书 → 会话分支」核对绑定前勾选「在新分支启用会话变量与条件宏」。选择查看角色后，可保存分支共享值或该成员实例的私有值。中性夹具「渡口交班簿」以「交班」触发。两名成员读取同一天气，各自读取本岗信号。

## 作者写法

| 写法 | 效果 |
|---|---|
| `{{var::shared::天气}}` | 读取分支共享值。 |
| `{{var::private::信号}}` | 仅读取本次发言成员的同名变量。 |
| `{{if::private::信号}}已挂牌{{else}}等待挂牌{{/if}}` | 检查键是否存在。已保存的空文本也算存在。 |
| `{{if::shared::天气::晴}}桥头交班{{else}}亭内交班{{/if}}` | 按原文精确比较。缺值时条件为假，直接读取缺值则插入空文本，预览标出「缺值」。 |

条件最多嵌套四层，else 可省略。宿主检查块结构，只读取命中路径上的变量；错误配对或超限会阻止准备请求。宏仅用于目标卡支持的设定字段与可读角色书正文。玩家输入、历史、开场、关键词、装饰器和回执沿用原文。日期与选择宏可以独立开启。变量只能由作者在页面明确保存或移除，模板不执行赋值。私有范围由目标成员实例确定；作者工作台能切换查看角色。角色自行公开说出的内容仍遵守该条消息的原可见范围。

变量名为 1–32 个字母、数字或下划线，支持汉字，首字符不能为数字。`__proto__`、`constructor`、`prototype` 保留。每个范围最多 32 个现存键。值为不超过 256 个 UTF-16 代码单元的单行纯文本，排除花括号、尖括号、@、控制字符和格式控制符。值不会作为模板再次执行。每个字段最多检查 256 个变量或条件标记，记录 128 处展开；最终请求最多记录 512 处。每条分支含继承部分最多记录 256 次有效变量变更。

## 分支与请求

- 变量策略 `scoped-text-conditions/1` 仅在新建或派生时启用。会话变量由分支记录持有，角色卡和角色书导出仍保留宏原文。
- 修改定位到当时的消息总数。从第 N 条历史消息派生，只继承该条消息写入之前的修改。从「分支当前末尾」派生，会包含最后一条消息之后的修改。两种派生有意区分。子分支修改独立，早于启用位置的历史不补授变量。
- `set-variable` 沿用操作 ID、预期修订和宿主成员检查。共享写入要求空成员引用，私有写入要求本分支的活动角色。值为 null 时删除。尚有未决请求时暂停写入。预览只读，保存变量后须重新预览。
- 准备新请求时原子保存最终上下文和本次实际采用的宏快照。快照含来源、原文、位置、读取值或缺值标志；条件另记观察值及判断结果。未选择的条件分支和其他成员私有值不进入快照。刷新、重启和精确重生成读取原请求的证据。要应用新值，选择新消息或接话。
- 旧分支继续沿用原策略。回退时关闭变量预览，回到交付点 1 副本，本轮数据单独保留。
