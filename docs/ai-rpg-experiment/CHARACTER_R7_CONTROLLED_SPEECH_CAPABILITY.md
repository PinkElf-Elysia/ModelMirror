## 离线证据

1. **同名反例**。在同一中性会话中创建两个不同的原生成员 ID，用同一个角色称呼先后绑定两份模拟就绪资产。两次合法保存后仅留下第二份绑定。另将完整原生成员 ID 作为 role 提交，输入校验拒绝。用例只访问临时绑定文件，未生成语音。
2. **禁网合同回归 22/22**。执行 `character/revisions/{sources,contracts}.test.mjs` 与 `studio/{speech,voice-library,common-voices}.test.mjs`。涵盖单聊和群聊来源、分支编辑和候选、原语音宿主授权、恢复及音色不可用等情形。外部服务全部由夹具替代。
3. **首次运行记录**。第一次容器启动缺少只读挂载点。补齐空挂载点后，组合测试 21/22，来源夹具在 Linux 使用了 Windows 默认路径。显式指定独立临时目录后完整重跑通过。日志和同名反例存放于独立数据目录，未写入项目。
4. **保留项**。前轮设备、浏览器、旧存档及既有审计失败继续见[交付点 3](./CHARACTER_R7_ANIMATED_PORTRAITS.md)。R4c ①人工采纳和精确端点、②刷新后实时增量和精确端点继续待证。④仅证实宿主停止读取，供应商最终计费待证，保留 US$0.018990 未结预留。

## 恢复接入的条件

- 宿主能从会话或分支、消息 ID 及预期修订重新读取当前有效的已完成回复，并确定其发言实例、固定版本和可朗读正文。被替换、已编辑或未采纳的内容具有明确处理规则。
- 有可信的成员实例与音色资产绑定，记录音色模型及绑定修订。两位同名成员能同时选用不同音色，旧绑定和其他会话的音色不能被误用。
- 朗读操作可核验会话语音授权、预算所有者、次数及费用上界，持久化预留与原请求 ID。重复点击、额度不足、修订过期及结果未知均有离线证据后再接入页面。
