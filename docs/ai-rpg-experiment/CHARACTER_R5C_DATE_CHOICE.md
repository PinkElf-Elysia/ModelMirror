# R5c 交付点 1 · 日期与选择宏

在「独立角色书 → 会话分支」创建或派生分支时，勾选「在新分支启用日期与选择宏（UTC）」。卡内角色设定或有权读取的书条目可写「值日日期 {{date}}，班牌为{{pick::蓝灯::白旗}}」。输入关键词后点「预览实际上下文」，展开「本次宏展开」核对原文、取值和来源；已发送请求下的「原请求宏快照」可在刷新后查看。

## 写法与作用域

- `{{date}}` 使用宿主 UTC 日历日，格式为 YYYY-MM-DD。`{{pick::甲::乙}}` 从 2–16 个以双冒号分隔的纯文本选项中取一项。宏名忽略大小写；选项去除首尾空白，每项最多 80 个 UTF-16 代码单元，不能含花括号、尖括号、@ 或 ASCII 控制字符。
- 仅在完整顶层表达式求值。未知、嵌套和无效表达式保留原文。单字段最多展开 128 处，最终快照最多 512 处，超限拒绝。现有角色名、玩家名和提示词默认值继续按既有字段语义处理。
- 支持目标角色的描述、性格、单聊场景、示例、角色提示和历史后置指令，以及可读卡内书与独立书的条目正文。书版、条目位置与字段标识区分不同来源。群场景、身份快照、作者说明、触发关键词、装饰器声明、已选开场、历史、玩家输入和模型回执都保留原文。正式快照只列最终纳入的书条目与角色字段，容量省略的示例不列入。
- 选择取值依据分支族、分支、目标成员、固定角色绑定、最近一条可见的该成员正式模型回复修订、源字段／封存书条目、宏位置与原文计算。预览操作 ID、输入文本与日期不参与抽取。派生分支的新发送独立取值；不同位置可能恰好得到同一选项。证据记录 UTC、宏策略版本、字段或条目、位置、宏原文与值。

## 发送和恢复

| 时点 | 行为 |
|---|---|
| 预览、重复预览 | 不占用额度或写入书架；可核对上下文、原宏与取值。 |
| 正式准备前跨 UTC 午夜 | 宿主重新装配并核对预览哈希。纳入的日期若已改变，拒绝旧预览，保留输入。重新预览后才能发送。 |
| 请求已准备、已完成或结果未知 | 已存的请求上下文与宏快照同一次写入。恢复只查询原回执；刷新或重启可从原请求查看当时值。 |
| 精确重生成 | 读取原消息的模型上下文及关联请求保存的宏快照。原请求没有宏快照时沿用原行为。 |
| 原卡、旧分支 | 仅在装配期间对目标材料建立临时视图；原卡导出保持原文。未启用宏的旧分支沿用原运行合同。启用策略前的历史位置需显式创建带宏策略的分支。 |

## 离线复验

在实验目录运行 `node --test character/macros/date-choice.test.mjs`。专用夹具预览命令为 `node character/macros/preview.mjs <新目录> 0 0`。输入「查班」后重复预览，再生成一次离线回复，刷新并选择精确重生成，对照原请求。公开预览使用宿主当前 UTC 日期，自动化用例通过宿主注入时钟覆盖午夜，不更改系统时间。页面不能提交日期、抽签种子、宏快照或已装配的消息。

首次综合用例在已有「查班」历史的会话中期待新输入不再命中；书级默认扫描会读到上轮关键词。中性演示书改为只扫描当前输入，原失败日志留在独立数据目录。回退可停止本次预览并返回 R5b 副本，保留新书架数据。交付点 2 的变量、条件及后续提示位置、显示转换仍按路线另行安排。
