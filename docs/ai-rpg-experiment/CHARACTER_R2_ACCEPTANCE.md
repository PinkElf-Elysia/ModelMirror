## 已覆盖的关键行为

- 同名、同模板成员独立 ID；跨群成员引用和额外权限/提示词字段拒绝。
- 中文多行输入、2 与 3 角色、无开场、普通开场及 V3 nickname/用户名群开场；初始成员均能看到唯一开场。
- 玩家消息保存一次；接话只增加目标角色回复，不伪造玩家回合；重复请求不再派发。
- 草稿更新和封存新版本不改已有成员定义。其他成员私有资料不进入上下文；角色书不扫描作者说明或示例，位置与触发有断言。
- 参与区间过滤、离场拒绝运行、重新加入保留此前参与历史但不补授缺席消息。新加入成员不看到加入前历史。
- 示例先裁剪，角色书有界，必需上下文超限拒绝。没有开放完整 V3 装饰器、正则、脚本或资源执行。
- 每群及跨群任务预算在同一提交中检查；价格缺失、额度不足及身份/回执篡改拒绝。
- 提交前/后分别注入故障；本地未决写入需要显式核对。回执已保存但消息提交失败时恢复一次，不重新请求。
- 未知或 absent 查询不释放预留、不解除群锁。失败/截断输出只保留为部分结果；证明未派发的失败释放预留。
- 新运行描述符覆盖传递导入。隔离副本中的源码漂移导致运行与重开拒绝，原存档字节不变。
- 卡片导出链路不读取群账本；R1 的私有资料/导出隔离与旧适配回归继续通过。

## 页面与本地角色

实际通过页面完成：选定本地正式角色的修订 4 封存版本与原创蓝色大鱼，分别设置离线模型 A/B，配置共同场景，选择蓝色大鱼的一条开场；发送一条中文多行玩家消息，手动让另一个角色接话；离场、刷新、重新加入，再加入第三位中性夹具并接话。

最终 5 条消息为 1 条预设开场、1 条玩家消息、3 条明确标注的离线回复。刷新和进程重启未增加消息或调用。原卡版本 ID 保留在本地复制清单中，不复制正式会话或记忆。

390px 与 1280px 下分别检查横向溢出、成员抽屉、回应者、固定输入区域及消息滚动。DOM 测得 scrollWidth 不大于 viewport；Shift+Tab 可聚焦回应者且焦点边框为 solid。修复了加载期间闪现空创建表单和输入区随长历史滚出的表现。

## 保留的失败与限制

1. 第一轮新故障测试有 5 项失败：4 项误期望注入异常原文而非存储层的 OFFLINE_WRITE_FAILED/UNKNOWN，1 项误用了发布前修订号。按实际合同修正测试并加强提交前后精确状态断言后通过；batch4-recovery.log 与 corrected 日志均保留，没有修改旧存储实现或降低校验。
2. 首次本地素材副本初始化遇到 AUTHORING_ROOT_NOT_EMPTY。保留该目录，改用新编号 preview2，在空目录先初始化作品存储再复制精确文件；没有改写原作品。
3. 两项帮助失败仍为既有步骤数量超限和截图基线不一致；10 条截图诊断与 R1 保持一致，未删除断言或资产。
4. 金额硬限制依赖宿主核对价格及完整费用上界；真实供应商费用和 token 计算未验收。无美元账单的完成请求保留预留金额，不能把额度占用显示当成真实账单。
5. 只有单用户 loopback 所有者防护，无多租户权限系统；Windows 仍继承现有目录 fsync 限制，不声称已验证断电持久性。
6. 成员总数、记录容量和冻结目录是首版界限；没有自动升级、批量群运行、自动记忆或群场景编辑。
