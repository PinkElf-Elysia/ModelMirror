## 打开预览

在 `experiments/ai-rpg-engine` 运行：

```powershell
npm.cmd ci --offline --ignore-scripts --no-audit --no-fund
node local-state/server.mjs --offline-preview
```

打开 <http://127.0.0.1:18821/>。未传 `--offline-preview` 时拒绝启动；端口占用直接失败，不停止其他服务。

数据位于本工作树 `experiments/ai-rpg-engine/.rpg03-work/local-state-v1/`，由既有忽略规则排除，两个子目录分别保存会话和模拟供应商回执。不能与其他宿主共用目录。关闭该预览不会删除记录；重新运行可恢复。不是任意断电条件下的持久性保证。

建议验收顺序：

1. 核对原创成年修士林清的初值，勾选确认并开局。
2. “服用两份养息丹”：5 → 3；再选择“服用剩余三份”：3 → 0，档案和来源仍在。
3. 帮助周禾、归还工具、领取杂务报酬、学习术法、换装、疲惫等分别展示规则计算和定性判断。
4. 双候选只预览，采用后入账一次；刷新核对结果。
5. 在输入框填好动作，档案工具中模拟截断或结果未知。未知时核对原操作；明确失败可放弃整条未完成回复。
6. 查看前后差异后明确改写；从开局或任一事件创建检查点分支；停用后查看仍保留的资产。
7. 每轮可查看原始模拟回复；导出文件包含冻结请求、原回执、事件和状态。不要把这些运行材料直接公开提交。

## 字段责任

| 数据 | 本地程序 | 模型／模拟供应商 |
|---|---|---|
| 姓名、性别、初始年龄、性格、信念、灵根、体质、核心外貌 | 持久保存，禁止普通增量覆盖 | 不逐轮重写；新印记只追加 |
| 所属、声望、衣着、境界、突破、功法层次、炼丹炼器、寿命资料 | 类型校验、保存和显示 | 判断剧情变化，提供原因；不推导未声明公式 |
| 灵力、体力、伤势、精神 | 保存定性状态 | 判断疲惫、受伤、恢复；没有 HP 或百分比转换 |
| 能力、丹方、器谱、术法 | 稳定 ID、档案留存、掌握程度、NEW 标记 | 判断学会、进阶和效果 |
| 装备与物资 | 装备引用、整数数量、非负与溢出校验；零数量不删档 | 提出获得、消耗、损毁等事实 |
| 四档灵石、贡献点 | 独立账户整数加减 | 提出有依据的增减，不提交最终余额；没有自动兑换或月例 |
| 关系、信任 | 校验原卡事件区间、累加、边界限制、标签和各面板同步 | 判断事件类别、区间内幅度和原因 |
| 关系类型、印象、最近接触、势力声望 | 保存和展示 | 判断语义，不发明定量公式 |

未知数字为 `null`，显示“未设定”。相关数值操作会被拒绝，但不阻止无关、无变化的剧情。关系初值按原稿为零；档案例外只能在确认初值或明确改写中设置。

程序通过校验，不等于证明模型的语义判断正确。“信任增长更慢”“深交正向增长更难”仍是模型须遵循的原卡要求，没有假造倍率。

- `measure.mjs`：可复现的字符和 UTF-8 字节比较。

## 兼容与边界

旧 `variable-panel/1` 仍按全量快照运行；本模式是独立的 `modelmirror.rpg.local-state/1`，不改变旧解释方式。新分支绑定原稿指纹、有效提示词指纹和 `cultivation-local-state/1` 适配版本；版本不符拒绝续写，不静默迁移。

旧记录通过“确认初值＋继承正文”建立独立分支。预览支持本模式导出文件往返及规范化初值导入；**尚未提供所有旧原生存档格式的一键转换器**。只有文本时需人工整理和确认，不自动猜余额。继承正文去掉受管面板；历史关系占位符不会被当前数值冒充回填。原始正文仍保存在来源记录中。

默认不运行真实总结或记忆任务。已经复用现有自动总结和记忆宫殿的任务指令／输入装配，并验证正文与已提交变化的隔离；预览的“查看实际装配与记忆任务”可核对请求。**任务输入检查不是总结／记忆模型效果验收**，也不宣称接入了正式聊天页面全部插件 UI。

Mod、自定义配置、世界书和正则使用现有模块。世界书本地扫描可看到历史面板触发投影，但它不进入最终模型历史；状态与事件在配置触发完成后追加，不冒充新玩家输入。受管面板与本地关系占位符不接受显示正则改写。明确重复输出合同会被拒绝；不宣称能自动识别任意自然语言冲突。

查询目前由宿主按当前动作、上轮提及的名称／ID、装备引用和显式选项选择；这是透明的启发式查询，不是自主工具循环或世界书 RAG。未查询条目不等于不存在。自由输入的语义理解、漏查率和复杂剧情需要后续真实生成验证。
