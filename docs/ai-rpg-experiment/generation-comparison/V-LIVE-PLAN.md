## 3. A：创作原生跨模型比较，最多 2 次

在独立 V 真实验收目录，以创作 UI 新建中性作品“雾港来信 · V 实测”，不改原六卡或任何验收会话。通过 UI 保存、发布、建立新调试会话。正式派发前归档作品/version/artifact/resource hash，用户可以检查冻结版本。

- 主提示词：`你是中文互动故事主持人。场景是架空的雾港，所有人物均为成年人。尊重玩家明确完成的行动，不替玩家做下一步决定。故事约400至600字。不要新增与当前行动无关的人物或世界设定。`
- 开局输入：`我叫林舟，28岁，是来雾港维修灯塔的工程师。现在是傍晚，我带着工具箱站在码头，灯塔管理员周岚（35岁）正在等我。`
- A1 本轮输入：`我先检查工具箱，将一块备用电池装入手电筒，随后接过周岚递来的灯塔钥匙。请写出这段已完成的行动与周岚的回应，并在正文包含“灯塔钥匙”；停在我准备出发的位置。`
- 变量初值：`{"energy":5,"hasKey":false,"location":"码头"}`。变量提示词：`只更新明确发生的状态：本轮取得钥匙后 hasKey=true；当前地点仍为码头；energy 保持5。遵守宿主变量输出协议。`
- 面板模板通过 UI 使用 `<section><strong>{{location}}</strong><p>精力 {{energy}}</p><p>{{#if hasKey}}已取得钥匙{{else}}尚无钥匙{{/if}}</p></section>`。
- 使用本地无人物的蓝色测试图作为特殊 CG“灯塔钥匙”，关键词为“灯塔钥匙”、AI 扫描、或匹配、概率100、单一图片；解锁提示“取得灯塔钥匙”。资源通过 UI 上传，原站不良 CG 不导入。
- 创作参数/对比为原生功能；M1/M2/M3及其他会话插件关闭。变量面板、特殊CG为原生状态能力，不列为插件。
- 两候选完成前，正式剧情/变量/CG 不应变化。检查两份共享消息 hash 一致；原文和渲染分别审阅。
- 默认采用候选1，仅在输出完整且状态符合输入时采用。否则停止并报告，不用候选2自动代替失败样本。
- 采用后只新增1轮，变量只推进1次，CG只解锁1次；刷新和原操作核对不得二次推进。未采用候选保留只读。
