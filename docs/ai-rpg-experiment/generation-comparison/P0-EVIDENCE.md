## 浏览器核验

使用真实浏览器操作原型，桌面视口 1440×960、手机布局视口 390×844；另用 390×520 验证较短可视区。核验后恢复浏览器默认视口，并通过原型自己的按钮重置测试样例。不是截图推断或仅静态代码审阅。

| 场景 | 实际操作和观察 |
| --- | --- |
| 三用途隔离 | 剧情温度 0.70 改成 0.90 并应用；切换摘要、记忆仍为各自的 0.20 / 16384 样例配置 |
| 默认与显式 | 滑杆/数值联动，默认与显式可切换；切回完全相同配置后显示“已是当前配置”，不再误报未应用 |
| 模型切换 | 搜索 Opus 后保留原 0.90 / 0.80；固定样例声明的互斥冲突阻断应用，恢复 Top P 默认后解除 |
| 高级参数 | 中文停止词通过 Enter 添加并删除；显式思考预算缺少启用条件时显示诊断；启用后可选思考档位 |
| 预设 | 另存“港口叙事·0.90”，刷新后仍能打开查看；只影响本页样例存储 |
| 取消与焦点 | 未应用修改退出需确认；Esc 逐层退出；取消放弃保留编辑，确认放弃恢复已应用值；默认切换后控件焦点保持 |
| 候选设置 | 从 2 份增加至 4 份；第五份不可新增；上移、删除可操作；每份可单独选择样例模型和参数 |
| 排队与提前采用 | 三候选中同时两份运行、另一份排队；A 完成后可提前采用，B/C 继续；全部任务收束前普通发送不可用 |
| 阅读 | 渲染结果、原文切换；可展开参数等信息；桌面同时两份，手机逐份分页，关闭再进入保留原批次 |
| 聊天权限 | 关闭模型选择与参数权限后，对比仍独立可用；尝试将候选设为后续配置时显示所缺权限 |
| 额度 | 额度不足样例在开始前阻断；四候选＋发送前 M2 两次＋采用后 M2 两次＋M3 一次显示最多 9 次 |
| 前置摘要 | 打开发送前补齐样例时，候选先保持队列，演示补齐结束后才开始候选 |
| 候选未知 | 未确认候选显示可核对入口；刷新保留未知，按原记录核对仍未知；没有重新启动演示生成 |
| 采用未知 | 所有再次采用入口锁定；明确点“核对采用记录”后以固定样例完成一次提交；其他候选不能再次采用 |
| 停止与部分失败 | 四候选运行时结束其余候选，只停止未派发队列；进行中的样例继续；一份完成、一份失败；都不采用恢复输入，正式回合数不增加 |
| 手机与桌面切换 | 390px 参数面板全屏；固定底栏；无页面横向溢出；390×520 可见底部操作；回桌面无按钮重叠 |
