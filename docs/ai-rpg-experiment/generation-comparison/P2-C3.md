# P2-C3 聊天参数接口与浏览器操作恢复

## 实现前任务卡

- 目标：将 P2-C2 正式聊天合同接入同源 HTTP，贯通安装、逐会话授权、三用途模型与参数设置、预计额度、发送及原操作核对。浏览器操作记录使用现有 write-ahead 客户端。仅离线，不派发真实请求。
- 工作区：C:/tmp/modelmirror-rpg-generation-chat-parameters，codex/rpg-generation-chat-parameters，基线 d9f20fe691e8ddef8623d779a25a9359717f2e8d。已有累积修改保留；开始前 Git 状态已核对。18662、18664 和原工作区完全不写入、不重启。
- 检查发现：现有设置接口要求先选摘要／记忆模型再授权，而聊天模型配置要求先授权。仅在显式新聊天合同中改为先授权再选模型；缺少模型仍阻断发送。原生创作合同不变。
- 受信服务选项 chatParameters 默认 false，只有联合受控宿主可开启，不能与 creatorExperience 同时启用。HTTP 请求不能切换该模式。此次仅提供 API 和浏览器客户端，聊天专用可见面板留给下一子批，避免把创作原生界面误当聊天界面；聊天模式不暴露尚未适配的根页面。
- 新接口：GET joint/parameters/:session/:purpose，POST joint/parameters/configure 和 joint/parameters/reconcile。沿用同源、内容类型、容量、操作 ID 与 revision 校验。核对只查原记录，不重新校验模型或派发；未应用、已应用、未确认明确区分。
- 插件设置接口只在新聊天合同返回 parameters，安装与会话授权分开；参数相关授权写入增加预期参数 revision。发送意图绑定参数授权 revision，原生旧意图保持原格式。
- 文件范围：authoring/server.mjs、joint-settings.mjs、joint-api.mjs、joint-client.mjs、generation-session.test.mjs、joint-client.test.mjs 和本文。共七文件：同一个接口合同必须同时经过服务开关、授权日志、路由、浏览器恢复协议和两层测试，不能以直调宿主替代 HTTP 验收。
- 不改核心冻结参数合同、供应商路由、依赖、数据库、六张旧卡管线、旧入口或共享栈。无迁移、真实调用、认证、额度修改或 Git 发布。
- 最小验收：新增 HTTP 参数和客户端恢复测试。回归：正式参数会话、joint-api、joint-client、模型设置和旧原生路径。检查最终差异、源码 hash、旧入口只读响应与原工作区 hash。不得在测试运行时改源码。
- 风险：中等，涉及本地持久化授权、并发 CAS 和未知写入核对。回退：关闭 chatParameters，保留新会话及操作记录；已派发记录由原版本继续收束，不能以旧合同载入新记录。
- 二级交互门禁：本批没有新增弹窗、下拉或可见控件；不以接口通过宣称桌面／390px 聊天 UI 通过。下一批仍须先实查原站再实现未核实交互。


### 实现中发现并补齐

- 开启插件后可先进入模型选择，但两个后台用途的模型尚未选择时必须在 estimate/send 前拒绝，不能先派发剧情。补充零派发 HTTP 用例后证实既有 memoryContextPolicy / summaryContextPolicy 已阻断缺失模型；不改 joint-session.mjs，保留两条新回归。
- 参数／默认模型保存与插件变更共用设置准入队列，防止同一操作 ID 在不同日志并发落盘。核对也检查设置日志中的 ID 冲突。
- 仅将已知插件诊断投影为稳定错误码，避免把未授权误报为存储未知；不输出异常栈、路径或原始参数。

## 完成行为

1. 新聊天宿主通过受信启动选项显式启用参数合同。安装、会话授权、模型选择、参数编辑和发送仍分别校验；保存、查询与核对均不生成内容。
2. 三用途参数可以分别读取、应用或清除。后台用途先授权再选模型，未选模型不能预计或发送；更换剧情模型不覆盖摘要、记忆模型。
3. 参数保存绑定模型、参数及会话 revision。不同标签的旧状态、不同操作共用 ID、参数与插件授权并发使用同一 ID 均拒绝；准入检查与正式保存串行完成。
4. 浏览器在发送设置写入前保存原意图。丢失响应后只用原 ID 与完整意图核对；已应用可恢复收据，未确认保留记录，明确未应用后才允许丢弃本地待核对项。核对不重新执行写入、不调用模型。
5. 剧情派发绑定参数授权版本。停用保留设置，后续恢复默认值；重新安装不继承授权。已冻结的后台请求继续使用冻结参数，未知请求只按原 ID 收束。
