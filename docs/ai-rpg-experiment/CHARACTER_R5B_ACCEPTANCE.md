## 八项已验收行为

| 交付点 | 启用后如何判断 |
|---|---|
| [1 · 一次性](./CHARACTER_R5B_ONCE.md) | 预览只读，正式请求准备时占用；完整回复入史才消耗，失败与未知分别恢复。 |
| [2 · 扫描深度](./CHARACTER_R5B_SCAN_DEPTH.md) | 条目可覆盖书级窗口，本次玩家输入占一条。先过滤不可见消息，容量裁剪后重算。 |
| [3 · 延迟与周期](./CHARACTER_R5B_TIMING.md) | 按当前成员可见的完整角色发言计数，包括可见开场；玩家输入不计。 |
| [4 · 回退链](./CHARACTER_R5B_FALLBACK.md) | 选择该分支支持且参数有效的首个规则，然后判断是否触发。条件未命中不会改选后备。 |
| [5 · 持续](./CHARACTER_R5B_KEEP.md) | 首次纳入并被采用后，按成员、书版、条目和分支位置保存依据。 |
| [6 · 冷却](./CHARACTER_R5B_COOLDOWN.md) | 仅按该成员的正式入史回复推进；冷却期间保留已有持续依据。 |
| [7 · 概率](./CHARACTER_R5B_PROBABILITY.md) | 同一成员与回复位置使用可复现的百分位；未抽中不参与递归和入史状态登记。 |
| [8 · 互斥组](./CHARACTER_R5B_EXCLUSIVE.md) | 在同书同组同轮合格者中按优先级择一，同分取原书靠前者。仅胜者参与后续递归，预算排除不递补。 |

各点说明记录交付当时的支持范围，组合后的范围见上表。一次性、持续、冷却以及概率取值采用模镜的成员和分支语义。旧分支保留原装配，精确重生成使用原请求。卡片交换只携带定义，旧源码的兼容清单保留精确哈希。
