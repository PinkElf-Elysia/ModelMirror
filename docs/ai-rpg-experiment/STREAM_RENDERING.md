# RPG 流式 UI 渲染

消息工具的“流式输出”使用公共聊天组件，覆盖地球 OL、上帝模拟、星笺、古代、修仙、诡秘、肥鱼、斗罗、龙族和金庸入口。

- 保留原有 650 ms 进度轮询及请求编号；不改变模型调用、历史、记忆、额度或存档格式。
- 展示片段在本地 Worker 中调用现有 `cardPresentation` 净化器，使用与最终回复一致的 earth / god / douluo / archive 配置。模型原文和自定义显示规则的产物均不直接进入 DOM。
- 支持未闭合 HTML、Markdown、代码围栏；输入上限 2 Mi 字符（兼容显示替换），单次 Worker 4 秒超时。同一时刻只解析一个快照，等待时合并到最新快照。遇到错误保留上一安全画面并给出提示。
- DOM 增量更新保留同位置的折叠面板、checkbox 和焦点；当源结构本身改变时，相应节点可以替换。完成后仍由服务端保存的最终结果接管。
- 自定义显示规则在流式和最终显示阶段生效，替换为空时清空显示，不回退到原文；导入记录继续作为文本显示。
- 开关、取消、新请求和卸载会隔离预览状态或终止本地 Worker；进度轮询失败不重发生成请求。脚本、任意样式及远程资源仍遵循已有安全过滤范围。

## 离线验收

在 `experiments/ai-rpg-engine/card-replica` 执行：

```powershell
npm.cmd test
npm.cmd run build
python tools/verify-stream-browser.py
node tools/preview-stream.mjs
```

需先按锁文件安装 RPG 引擎及 card-replica 的依赖；Python 浏览器验收使用已有 Playwright 和 Chromium。浏览器测试固定使用 loopback 19871 端口，所有会话 API 都被中性夹具拦截，不调用模型。覆盖桌面 earth / god / douluo、移动端 cultivation，含未完成回复、表格、代码、XSS、焦点、折叠、原生视角切换、真实自定义配置插件、空替换、轮询故障、模式切换、最终接管、新请求和取消。

演示页默认 `http://127.0.0.1:19872/rpg-app/god/`，端口可作为脚本参数传入。使用生产构建和同源 CSP，数据仅在本进程内存中；开启“流式输出”后发送任意中性文字即可观看固定样例。该演示没有共享栈接入，不应当作真实模型验收。

## 部署及回退边界

流式展示部分不改变模型请求或作者原文。斗罗完成态使用相同的本地净化配置重新展示；通用 archive 服务端 HTML 投影保持兼容。斗罗的直播、marquee 弹幕、吐槽控件使用专用白名单。斗罗的 46 张已保存原图按精确 URL 映射到本地资源；提示词内 12 个吐槽头像逐一 GET 均返回 404，从随机展示候选停用并保留文字吐槽开关。未收录的地址仍不加载。详见 [配图核对清单](DOULUO_IMAGES.md)，不能把失效占位视作图片复刻完成。


## 同会话重新生成、历史版本与回收站

公共聊天页的重新生成不再调用 fork 路径：先把当前完整会话保存为历史版本，再回到所选回合前，沿用原会话 ID 发起一次普通发送。分支按钮仍单独创建分支。界面会确认影响范围，原回复及后续内容均可恢复。模型保留当前选择及选择版本号；历史窗口、总结与记忆使用该回合开始时冻结的快照；插件授权随同一 ID 保留。

- `studio/session-lifecycle.mjs` 通过独立 `session-versions/<id>.json` 原子信封承载当前版本、历史快照、回收站标记和幂等操作回执。首次管理操作前不创建信封，原 root / branch 文件不改写。原分支前缀约束仍由原档案校验。
- 历史恢复保留终态请求回执；旧请求编号不能重新派发。存在未确认请求或后台记忆/总结任务时拒绝版本切换和删除。
- 恢复版本不调用模型，当前内容先成为另一历史版本；删除只标记回收站，不删除插件授权、配置或图片资源。不提供永久删除。
- 旧 God v1 恰好引用了服务器文件；只兼容本轮基线服务器 hash，其他作者、配置和运行文件仍由原校验器验证，不通配旧 hash、不重写存档绑定。
- Windows 可能因短暂占用使 rename 返回 EPERM/EACCES/EBUSY。只对同一次原子发布最多重试 5 次；其他错误立即失败。模型/插件调用不重试。
- 前端先持久化操作编号，响应丢失可核对同一操作。核对回退结果只恢复草稿，不自动再生成。并发更新以修订号和当前回合身份检查拒绝。

在引擎目录验收：

```powershell
node --test card-replica/tests/*.test.mjs studio/session-lifecycle.test.mjs studio/message-tools.test.mjs
npm.cmd run build --prefix card-replica
python card-replica/tools/verify-stream-browser.py
python card-replica/tools/verify-session-history.py
node card-replica/tools/preview-session-history.mjs
```

生命周期浏览器验收使用生产构建、真实本地 HTTP、合成离线剧情/摘要/记忆，不拦截正常 API。覆盖同 ID 重写、恢复旧剧情与记忆、回收站刷新恢复、回退响应丢失后核对而不重发。测试端口 19874，预览默认 19873；预览输出直接会话 URL，数据位于 `.rpg04-work/session-history-preview-*`。流式验收使用 API 夹具，不能代替真实模型调用验收。

共享栈尚未部署本补丁，未改用户存档、配额或容器。正式接入需同时更新前端和宿主。回退前备份完整会话目录（包括 session-versions）；旧宿主不认识覆盖信封，直接回退会显示首次管理前的原文件，也会重新列出回收站会话。需要继续最新剧情时保留新版宿主或先导出当前会话，不应删除信封来“修复”。
