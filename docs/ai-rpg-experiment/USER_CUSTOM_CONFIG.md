# RPG 用户自定义配置

在地球 OL、上帝模拟和修仙聊天的右上角打开「工具 → 自定义配置」。新版分轮记忆会话也有同一入口。插件页可直接打开全局编辑器。首版在浏览器本地保存配置，用 IndexedDB 分开记录全局和各卡各存档的设置。浏览器、端口或访问域名不同的设备，可以用导出文件迁移。

桌面和移动设备均可编辑前置词、后置词、系统提示词、世界书、正则脚本、CSS 和 assistant 预填充。全局面板另有记忆回合数、头像及两种背景图片。图像支持 PNG、JPEG、WebP，每张最多 4 MiB。工具菜单可以暂停当前会话应用配置。取消会丢弃草稿，清空也只作用于编辑中的草稿。保存时会校验非空内容和版本，防止覆盖另一个窗口的保存。

导出配置提供复制和下载，导入支持粘贴与 JSON 文件。整份配置的本地格式是 `modelmirror.rpg.custom-config/1`。单独导入世界书模板会追加条目并重新分配条目与分类 ID。世界书界面与模板沿用创作工作树，包含分类、默认样式、关键词、搜索、深度、顺序、概率和加权正文。配置教程提供 Markdown、世界书和正则示例。

全局与会话的文本按此顺序组合。世界书先计算前后置词，再用包裹后的用户消息匹配注入系统提示词的条目。只展示的规则通过浏览器 Worker 产生显示副本。普通替换也用于后续剧情里的用户或 AI 文本，以及随当前操作派发的小总结与记忆整理的结构化历史字段。作者的系统消息保留在首位，已有存档及原始回复保持原样。预填充使用末尾 assistant 消息，能否续写取决于模型。CSS 只接受聊天范围内的常用文字、间距、边框与颜色样式；背景图片由本地文件选择器处理。

受管容器入口在既有 HTTP 身份与请求校验之外识别显式配置请求。服务端把每次快照绑定到会话与操作，不改旧卡冻结文件。模型控制面分别保存卡片原始请求与实际发送内容的摘要，并按实际消息执行容量检查。启用此功能需要同时更新前端、RPG 宿主与 Python 模型控制面。回退可先暂停当前会话的配置，再使用原镜像；浏览器配置可导出。

验收使用标准镜像、本地模拟提供方与中性档案。检查六条聊天路径的实际请求，桌面与 390px 浏览器的编辑和持久化，并运行 `node --test experiments/ai-rpg-engine/plugins/custom-config/custom-config.test.mjs`、`python -m pytest server/tests/test_rpg_custom_config.py server/tests/test_rpg_bridge.py -q`。本地文件往返是本轮的互操作基准。
