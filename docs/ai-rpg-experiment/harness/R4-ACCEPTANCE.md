## 本轮实现
- `agent-core/context/assemble.mjs`：公共的材料选择与装配。适配器先 `prepare`，提供材料、来源、用途、性质、会话/状态版本、必需项、依赖和显式绑定；公共层无题材分支，不执行检索或状态写入。
- `cultivation-source.mjs` / `reference-index.json`：原稿逐段覆盖校验；必需规则、文风与状态增量合同保留；长检查输出改成行为约束。静态资料按固定来源指纹和已登记分类选择，未分类保留。仅支持青云宗、青牛镇、东域及明确对象引用；不声称已解析全部世界依赖。
- `adapters.mjs`：修仙与灯塔均使用同一材料协议和 R3 Host/Store/Simulator。版本为 4，旧版本 3 入口、状态格式、原文和规则不改。灯塔只复用 `duty`；没有新增任务数据库或真假识别模型。
- `composition.mjs` / `server.mjs` / `public/`：默认关闭的独立启动、固定模拟供应商、场景选择、补充对象、来源与回退轨迹。既有 HTTP 服务器只增加可信构造参数，默认行为不变；公共执行器及供应商桥接未修改。

- 灯塔转述、猜测、提案的性质仅由固定样例标注；模型提出 setDuty 仍属于语义判断，不是程序证明剧情真伪。原样例“布囊/药囊”等叙事偏差仍作后续优化，不扩大补丁。
