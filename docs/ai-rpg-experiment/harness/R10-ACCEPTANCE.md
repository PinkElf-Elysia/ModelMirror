# 第十轮 · 从保存选择到读档续玩

基线 `95ce9a83f319054613d818a31c8072e9ff1996f3`，包含 [R9 场景会话](R9-CLOSEOUT.md) 与 [E6 情境建议](../feature-exploration/E6-HANDOFF.md)。用户已通过离线交互与最终赠药续答的原型验收。下文记录本地模拟、自服结算和玩家试玩；真实查询与三次赠药续答的结果另见[实测记录](R10-REAL-RESULT.md)。

## 打开预览

在 `experiments/ai-rpg-engine` 目录运行下列命令。该入口只监听本机，默认使用本工作树下的 `.rpg03-work/scene-r10-preview`。第九轮预览仍有自己的目录和启动参数。

```powershell
node agent-core/scenes/server.mjs --offline-preview --scene-choices --port 18924
```

[新开一局](http://127.0.0.1:18924/) · [本机修仙存档](http://127.0.0.1:18924/?run=run-46e9368d66b015b0981f2d47011563feb0429ad5) · [本机灯塔存档](http://127.0.0.1:18924/?run=run-4445554a47925f88b7610404ad4150bfc387b15b)。带编号链接依赖本机验收数据，新工作树可从空场景复现。

1. 选择修仙场景，以“我想向他表达谢意”为目标，请求建议，补充“周禾”。选择“先表达感谢，保留丹药”，将原话改为“我决定自己服用 2 份养息丹。”并保存。此时可以刷新，养息丹仍为 5 份。
2. 点击“用这句话继续”，可放弃提案或确认执行一次。确认后回执显示 5 → 3。点击“叙述已确认结果”。
3. 请沈砚查询余量，采用其回应，再问陆遥同一问题。沈砚可以读到 3，陆遥的查询返回无权查看。重新打开存档，向世界发送“继续眼前的场景”，能接续已采用的对话。
4. 另开灯塔，直接向世界提出“添油 2”，确认并叙述。读档后灯油为 3。灯塔复用同一世界任务、确认、回执与读档流程。

## 接入和所有权

| 所属 | 接口与职责 |
|---|---|
| E6 | 将既有投影和 E5 赠送意图导出绑定到当前场景的读取函数。建议、澄清、选项、玩家最终文本沿用原有实现。赠送的接收和人物是否在场均未知。 |
| 主线 | 每份运行记录有独立选择日志。服务器从已保存的选择读原话，在场景锁内核对存档、绑定与来源版本，向登记的世界对话任务递交一次。 |
| 世界与人物 | R9 宿主确认和结算。选择来源可追到任务、提案、行动事件。人物按各自授权读取状态，玩家采用的发言进入故事。角色卡线独立维护模板与私有会话。 |

同一选择重复递交时优先查原任务，已经结算的选择可找回原回执。未递交的选择遇到场景版本变化时，需要玩家重新核对并保存。调用结果未知时使用已有任务核对入口。检查点分支继承当时的世界与对话，分支内重新建立选择日志。演示存档与浏览器证据位于非跟踪目录。

## 发现与修正

探索线在实际页面复现了一处语义误判。“把 2 份养息丹送给周禾，给他服用，我自己不服用。”中的“服用”触发了旧模拟器的自服提案。试玩时已放弃该提案，库存仍为 5。第十轮修仙模拟器现只对完整、受支持的第一人称自服样例模拟用药提案，其他含糊用药请求可保留原话并澄清。原世界结算规则和历史回执继续适用。

探索线已在新存档复测同一反例和正例。赠送原句递交后没有提案，库存为 5。随后明确自服，确认前仍为 5，确认后为 3。这一对照验证了固定样例的协议与交互，真实模型判断和开放自然语言理解仍待另行评估。
