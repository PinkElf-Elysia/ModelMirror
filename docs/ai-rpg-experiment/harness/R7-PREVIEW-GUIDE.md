# 第七轮独立页面验收

页面：[初始修仙场景](http://127.0.0.1:18895/?run=run-dd1b734e55cb7723b3bc12218d62d5d6380ea961)，已验证 HTTP 200、初始 5 份、尚无模拟请求。这是离线固定样例，不会调用模型。

1. 创建“修仙”场景；初始养息丹 5。选择“世界均衡 / 人物迅捷”，保留并行选项。
2. 点击“准备使用 2 份”，确认之前仍为 5；点击“确认执行”后回执 5→3，世界和人物分别生成并采用。
3. 点“还剩多少？”：有登记授权的在场人物先查询、再回答剩余 3；任务详情含工具结果和两次请求。
4. 切到未在场实例问“刚才发生了什么？”，该实例不知道事件，不继承另一实例历史。
5. 选择备用策略和“主模型明确失败”，发起人物回应；应显示一次备用，不重复结算。
6. 选择“回执暂时丢失”，发起回应，再“核对原请求”；请求数量不增加，原结果采用。持续未知样例继续保留，不可通过新发送绕过。
7. 刷新页面，URL 固定场景、状态和记录仍在；不派发。可切换已保存场景，不复制额度。
8. 新建“灯塔”场景，交流、查看登记物资、确认添油，复用相同执行器。灯塔未接入修仙角色。

“仅保留回执，结束叙事”只针对已失败/被拒绝的世界叙事；不撤销消耗，结果未知时不可使用。故障选项会作用于下一次对应请求，完成测试后请切回“正常”。

页面显示模拟预留与模拟费用，不是供应商实报。样例不理解任意自由输入、不保证真实模型生成效果。所有人物均为原创成年测试夹具。

独立启动（仓库根）：
```powershell
node experiments/ai-rpg-engine/agent-core/tasks/server.mjs --offline-preview --port 18895 --data experiments/ai-rpg-engine/.rpg03-work/tasks-r7-preview-final
```
本次数据 .rpg03-work/tasks-r7-preview-final。已运行时不要再启动；端口占用即失败，不停止其他服务。无真实开关，不读取凭据。新数据精确绑定运行源码，开发版本变更需新建独立数据目录，不放宽旧指纹。

进程中断发生在行动已结算、叙事尚未开始时，页面可出现“恢复尚未开始的叙事（均衡模型桩）”。该操作只补叙事，不再扣减，也不会补发未登记的人物回答；若已有请求结果未知，仍使用“核对原请求”。

本页为自定义 loopback 静态前端，未加入正式故事馆。需要重新运行时使用以上命令及原数据；不要通过清空数据或更换记录 ID 绕过未知状态。
