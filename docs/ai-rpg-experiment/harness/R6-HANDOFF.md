## 本轮实际接口

| 入口 | 输入/输出 | 保证 |
|---|---|---|
| TaskRecords.begin | 稳定任务 ID、purpose、owner、世界/分支/人物、输入 | requestHash、顺序、阶段和所有者回执引用；不是世界账或费用账 |
| BridgeHost.worldAction | 明确确认 + 原操作 ID + 世界 revision | 调用 R5 execute；账本/事件/回执仍由 R5 原子维护 |
| world-port | 具体卡片的 action、project、summary | 公共任务协调器不访问 items 或判断题材；不复制计算规则 |
| BridgeHost.deliver | 宿主读取已确认事件 | 仅授予场景内观察，按事件 ID 幂等投递；不是跨记录事务 |
| BridgeHost.respond | 绑定 actorId + 玩家输入 | 精确模板、冻结投影及当前角色历史；最多一轮只读查询 |
| query_local_state | observations 或 inventory，按 ID/名称筛选 | 只收已过滤投影；不能自报其他会话、写路径、执行工具 |
| recover | 原任务 ID | 查询原回执；不重执行世界动作；未知不自动重发 |
| view / evidence | 本地所有者可见页面 / 完整本地审计 | owner 视图不可直接输入人物；人物请求用单独投影 |

世界动作的执行和桥接记录不共用事务。执行已提交、桥接回执丢失时，通过原 worldId/operationId 找回；观察重复投递不重复加入。演示页只提供这一个已支持动作，不引入通用行为编辑器。

角色回答即使声称已做某事也无世界写接口；显式状态协议和未声明工具会被拒绝。不能因此声称已自动检验任意自然语言真假、所有秘密或人物行为合理性。
