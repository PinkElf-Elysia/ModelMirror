## 实际模块与扩展位置

| 位置（相对 experiments/ai-rpg-engine） | 职责 |
|---|---|
| agent-core/assembly/catalog.mjs | 可信宿主登记世界适配、工具、任务所有者、模型策略及入口；冻结装配描述与哈希 |
| agent-core/assembly/runtime.mjs | 通用运行、串行/受限并行、确认、采用、恢复、停用和检查点入口；不判断题材规则 |
| agent-core/assembly/owners.mjs | 世界任务交回原宿主采用；观察消费者只取得其投影和模型执行端口 |
| agent-core/assembly/capabilities.mjs | count_registered 的确定计算示例；未知数量与零分开，登记完整不等于世界全知 |
| agent-core/assembly/store.mjs | 复用 ActionStore / SessionRecords，按精确检查点创建独立世界分支 |
| agent-core/assembly/bootstrap.mjs | 可信代码组合、实际运行依赖指纹、离线传输入口 |
| agent-core/assembly/server.mjs、public/ | 默认关闭、仅 loopback 的独立离线交互界面 |
| agent-core/tasks/scheduling.mjs | 从 R7 提取的串行锁与最多两任务槽位，原 R7 和 R8 共用 |

复用 TaskExecutor、TaskLedger、ActionHost、原生消息与回执、状态提交、上下文适配，不另建额度或世界账本。必要小改包括：工具登记构造器、可信工具声明容量参数（旧默认仍为 2）、登记用途校验、提案续写工具白名单。其余旧入口保持。

新增世界：实现已有 adapter 合同，在 catalog 中提供状态投影；不在 runtime 中加卡名分支。新增只读/计算/提案能力：在可信代码中登记 schema、effect、执行函数与限制，再由适配装配进入请求。新增观察消费者：声明用途、版本、投影和明确采用方式；不能得到完整世界或存储端口。新增模型策略：登记已支持的策略配置，复用同一任务账本。本轮没有远程插件加载器、任意路径执行或通用编辑器。

运行时只执行已经开放的能力。停用不删状态、不撤销既有事件、不把维护权交回模型；停用的提案能力不能靠续写重新出现。每次确认重新核对版本与权限。未知操作只核对原请求；明确叙事失败可以恢复，或保留回执结束本轮。每个工具任务仍最多两阶段，不是开放式自主循环。

检查点冻结世界记录及对应正文、事件与状态。分支保留来源，清除待执行操作和提案，继续共享本次运行额度，不通过分支重置预算。观察结果不自动变成世界经历，不随世界分支偷渡私有记忆；记忆共享仍待决。旧记录使用其冻结版本，R8 不做静默迁移。
