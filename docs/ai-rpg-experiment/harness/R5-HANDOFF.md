## 本轮可复用的接口

| 入口 | 输入 | 保证／边界 |
|---|---|---|
| 工具登记 | 可信 schema、版本、effect、限制、纯执行器 | 请求不能安装工具或指定其他会话 |
| 查询 | 冻结状态＋有界范围 | 只读，返回版本、未知／覆盖说明 |
| 准备 | actionId、itemId、quantity | 返回状态／绑定哈希、预期变化；不执行 |
| 宿主执行 | operationId、revision；明确动作或已确认方案 ID/hash | 当前版本重新计算，一次提交状态、事件、回执和待叙事 |
| 结果叙事 | 确认回执、必要状态及选定资料 | 不重执行、不改数值；失败保留结果 |
| 恢复 | 原操作及阶段编号 | 核对已有结果；未知不能丢弃或重新派发 |
| 显式改写 | 新状态、原因、版本 | 保留前后状态及来源，旧方案失效 |

prepare_action 返回是计算结果，不是任意自然语言意图已经得到正确解释的证明。执行目前仅 player、单会话串行；同批多写操作、跨角色竞争与多 Agent 裁定未做。
