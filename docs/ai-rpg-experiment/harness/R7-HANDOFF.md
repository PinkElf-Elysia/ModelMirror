# R7 主框架交接

基线 f31bf50b。本轮实现只在新 task-runtime/7 组合内生效，旧世界/角色/探索记录不迁移。离线原型已验收，本次有限实测已完成，真实回复已由用户验收通过；非正式部署。

## 责任与实际复用
- TaskLedger：一个 R7 allowance 记录包含任务、阶段、尝试、预算占用和原所有者回执引用；不保存另一份可写世界账本。
- TaskExecutor：通过 generate/lookup 适配既有宿主的提供者位置。宿主仍负责工具校验、执行查询和最终采用。using 固定一次所有者运行的 taskId，不能通过同名角色跨世界寻址。
- R5 ActionHost/ActionStore：保留状态写入、行动确认、规则校验、正文采用和恢复。
- R6 BridgeHost/TaskRecords：保留角色版本绑定、观察投影、历史和角色回答采用。没有改造角色单聊/群聊宿主。
- 复用 SessionRecords 所有权、CAS、提交与 reconcile，复用 R5 reserve 的输入字节上界和最大输出预留计算。JointBudget 只按旧合同计调用数，未作为通用美元预算器使用。
- 新离线 allowance 是本运行的唯一额度，所有场景共用。不是平台计费余额；未与角色 GroupStore/JointBudget 做联合消费，不声称跨旧宿主额度已经统一。

## 执行与恢复
任务冻结用途、run/session、原所有者操作、来源版本/事件、策略和输入摘要。阶段冻结真实装配请求及元数据；每次尝试独立 ID 和模型。原响应与采用结果分开。

默认直接生成一次，按需查询最多两阶段；每个任务最多三次模型尝试（含一次备用）。原生工具续传固定原模型及协议，不移除签名跨模型。一次备用只适用于没有原生续传材料的明确失败；未配置备用、额度不足或未知时不切换。返回非法状态协议、未知工具或 length 仍由原宿主拒绝，不自动改稿。

新场景全都使用固定离线模型 fixture-balanced/fixture-swift。调用记录保存模型与参数，但没有真实模型选择效果证据。费用预留/模拟收据只用于验证额度算法；此段描述初始离线交付；其后获授权的真实 3 次、费用与观察边界见 R7-REAL-VALIDATION.md。

预算 claim 在同一 CAS 记录串行完成；网络/模拟等待不持有预算锁。两项独立生成最多并行两个，各自采用。世界动作只有 R5 写入者。跨任务记录与原所有者记录不是事务：原操作回执先存在时按原 ID 核对采用，不重新结算。

未知模型结果保留尝试及预留，只调用 lookup。已过期角色结果不采用，仍保留已发生用量/未知预留，不能因正文无效免费重发。故障样例是测试配置，不是玩家自由工具权限。

## 两条并行线边界
E4-handoff/1 仍为 executionStatus=not_executed、requiresExecutionValidation=true。接受意图不等于执行授权；预计值、哈希与玩家同意引文不能变为世界事实。未新增 E4 导入执行器。

角色 R3b 的消息修订、候选/分支、身份快照继承、记忆失效及原入口联合预算归其工作树。R7 ownerRef/source 引用为将来接入提供来源位置，不搬运未合并实现，也不默认共享记忆或将人工角色回复等同世界改写。正式接入须以届时已合并合同核对。

## 文件与实际扩展接口

- agent-core/tasks/policy.mjs：离线模型/参数/预留策略；未来真实策略不能只替换模型名，必须核对报价及原生协议资格。
- ledger.mjs：任务、阶段和尝试的保存；generate 前 claim，收到回执 settle，所有者确认后 adopted。
- executor.mjs：using(taskId, ownerOperation)、generate(session, stageId, request, meta)、lookup(session, stageId)；沿用现有提供者形状，不建设通用工作流语言。
- transport.mjs：离线传输与回执核对；没有真实供应商开关、凭据或外部网络。
- composition.mjs：三个用途 world-narration、world-dialogue、actor-response；前两者调用 R5，后者调用 R6。最多两项独立生成并行，状态变更在此前完成。
- server.mjs / public：只读投影和受限按钮入口；不是正式聊天页替换。

任务 source 保存世界/分支/版本/事件/角色引用；ownerRef 保存真正采用方和操作 ID。采用方始终重新验证自身状态，sourceHash 不能独立授予世界写入权。未知调用核对前不会被备用策略或新操作绕过。

新建任务时策略冻结。若进程在结算后、任务登记前退出，页面的显式恢复只补缺失叙事，使用默认均衡模型桩；不会恢复未登记的可选并行人物任务。任务与旧存档不是跨文件原子事务；无法证明结果时保留未知。

本轮未开发角色消息编辑、群聊、候选采用、自动观察扩散或跨实例共享记忆。角色线未来接入时提供明确实例/版本、有限请求和采用回调，而不是把完整交换卡直接作为任务权限。E4 未来只有经批准且重新校验的意图才可进入 R5 提案/确认，不接受预计结果直接写账。
