# B1 — 神临凡尘界面复刻候选

日期：2026-10-09。基线 `e5a808a60b024635a1e13965558f15775c5af86a`；独立分支 `codex/rpg-god-card`。
本批实现作者卡片开局界面，等待用户验收；没有完成聊天宿主、跨卡插件或真实 Provider 验收。

## 实现范围

- 黑金／深紫首屏、神之眼、环形符文、18项神权入口、七组独立折叠栏。
- 用户档案、可增减的其他角色、16种时代、世界补充、9项布尔功能、人称和回复长度、开场白。
- 实时天书、逐项功能切换、一键复制、省略空项、浏览器草稿保存。
- 折叠 body 使用 0fr/1fr，450ms cubic-bezier(.4,0,.2,1)；符文50秒匀速旋转。关闭的内容设置 inert 和 aria-hidden，不参与 Tab 顺序；prefers-reduced-motion 时关闭动画。
- 仅静态本地预览，允许列表文件路由；不导入 Earth 配置或 Provider，CSP 禁止 connect。原冻结系统资源不通过静态服务提供。
- 第一组新增5文件：setup.mjs、index.html、styles.css、app.mjs、setup.test.mjs；第二组增加 preview.mjs；第三组交付文档和登记。没有依赖增加或父仓源码修改。

## 与原站的对照证据

观察对象是作者 iframe 的可见界面，不是原站外层聊天平台。未调用原站模型。
在原站和复刻页分别填写虚构姓名、性别、年龄、时代、自定义世界及开场白后复制：
- 省略空项的现代都市样例逐字一致，作为单测完整期望文本。
- 补查汉朝发现日期标签也参与复制。原候选仅写朝代名，已修复为“汉朝（公元前202年-公元220年）”，补回归并在浏览器核对。
- 18项神权按钮逐项点击，均为各自图标加同一句“你动了一个念头……全世界的媒体都在报道”；复制内容不因此改变。
- 原站和复刻均默认只有“总结”开启，第二人称、中等长度；此“总结”是作者配置文字，不自动启用平台 M2。
- 原站人物字段是自由文本；这里不擅自添加年龄数值规则或新必填项。

## 复刻边界与剩余差异

- 这是依据可见页面重新实现的代码，不宣称复用了作者源代码。
- 原站背景音乐未提供原文件；按钮明确提示未接入，不下载替代音源。
- 星点/眼睛的几何和光效为本地 CSS/SVG 复刻；未证明逐像素等价。神之眼反馈、快讯使用已观察到的有限文案，不宣称穷尽原站随机文案库或刷新时序。
- 神格凝聚采用本地11项填写率，已与5项45%样例一致；没有原站完整公式证据。
- 新增本地验收标识、草稿异常提示、跨标签页保存保护、刚移除角色的恢复按钮、无动画偏好支持。这些是本地辅助，不进入天书/模型消息。
- 手册中的右上角、积分、MOD、自定义配置、世界书是作者原站说明；明确标记当前只是界面，不冒充已接入的模镜功能。没有据此额外注入规则。
- 所有系统文字保持冻结；没有独立前置词、后置词、世界书原件时不自行构造。
- 尚未接入真实聊天、历史、分支、模型选择、M1/M2/M3。本批不证明跨卡泛用性已经通过。
