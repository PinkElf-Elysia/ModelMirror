## 最小内部格式

modelmirror.rpg.e5-plan/1 是玩家侧只读计划，不是可执行工作流。包含 source（已绑定会话/版本/指纹）、revision、稳定 step-ID、每步 action/槽位原文、after、单一 condition（prerequisite 或 player-claim）、问题、范围限制、顺序待审状态和当前版本保存确认。
导出固定 executionStatus=not_executed、requiresExecutionValidation=true。saved.meaning=save-plan-only；可以保存未来依赖和未核实条件，不代表所有步骤能够执行。E4格式保持原样，不将E5文件伪装成E4交接。主线现有接收器不应直接接受此新格式。

步骤顺序默认表示前序依赖；删除/移动后显式核对剩余顺序。步骤ID不复用，清空计划也不重用旧ID；历史保留输入、差异和前后顺序。数量/条件修订使保存确认失效，派生预检按当前计划重新投影。
条件值与quote相等并逐字来自当前原文，含标点。玩家陈述没有世界证明力。所有物品/人物引用复用E4登记与证据校验，不推断容器归属或人物在场。

## 复用位置

- source：直接调用 E4 openSources / source reader，使用本任务独立目录。
- plan：E4 revise / derive 只作单步校验与首步纯预检；不调用 ActionStore.propose/execute/override。
- store：SessionRecords 保存新scope e5-plans，CAS、目录所有权、提交核对沿用原实现；不自动迁移 E4 草稿。
- provider：有限离线解释器与显式JSON合同；无网络、工具调用或隐藏重试。每次输入最多一个模拟解释。
- server：loopback默认18916，GET view/export，POST plan，默认关闭，必须 --offline-preview。
