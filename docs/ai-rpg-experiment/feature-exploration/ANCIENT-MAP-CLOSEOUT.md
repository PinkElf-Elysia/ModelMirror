# 古代人生 · 崇祯元年七月四节点地图

玩家已验收独立原型。各身份共用北京至辽东的四节点底图。开局登记提供历史起点，开局后的交割属于该存档的模拟发展。独立页面使用模拟生成，Gemini 证据来自单独的受控派发。

| 路径 | 已核对的结果 |
| --- | --- |
| 宁远交割 | Gemini 主动查询宁远，引用本档接防回执提出交割。确认前归明，玩家确认后仅宁远变为后金，读档保留事件和来源。 |
| 士兵传闻 | 同袍口信按传闻登记，四节点归属保持。首次续写补造城头官旗和守军情况，又要求确认已登记事项。冻结回执补测后，正文区分亲见营中聚集和同袍所称失城。 |
| 崇祯获报前 | 首次误把视角所在的北京当作查询地点。澄清参数后，保留原问句，模型主动查询宁远。首次和续写请求均隔离未送达军报。第一次正确查询后的正文把空列表扩大为查阅内阁兵部、御前没有任何奏报。最终单独重放续写，明确最后登记归明、本次可见记录没有新报、当前实情未知。 |

最终回复中的“证据列表为空”带有工具口吻。后续可改进叙事自然度，验收时继续保留信息来源和未知范围。

## 复核与对接

[实测索引](ANCIENT-MAP-EVIDENCE.json) 按发生顺序保留五批原始回复的可见正文、函数参数、用量和本地证据 SHA-256。批次中途停止的结果保留为失败。各批在本机任务临时目录按 localRun 定位；原始供应商消息和签名留在本地。补测复用较早的回执，各批不能拼作一次独立成功的全流程。

在仓库根目录运行 `node experiments/ai-rpg-engine/feature-exploration/ancient-map/server.mjs 18968 <独立存档目录>`，打开本机该端口进行离线复核。保留原卡开局素材；该服务是独立入口。

探索线负责身份可见消息、地图投影、交割提案和玩家路径。宿主绑定视角，query_map 的 node 指玩家询问的地点。传闻可登记；拟旨和模型正文均不能改变控制方。交割须有匹配的已知凭据及玩家确认。主线负责正式宿主的事件提交、角色获知、持久化和恢复；此原型只复用原生工具协议和会话记录能力，正式接入仍须单独验证。
