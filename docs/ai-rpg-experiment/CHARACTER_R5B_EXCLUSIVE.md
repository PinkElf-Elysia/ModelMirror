# R5b 交付点 8 · 同书互斥组

在 V3 卡内书的「名称与触发规则」或独立书条目中填写「互斥组名」。将需要择一使用的条目填入同一组，并设置优先级。保存、封存后，在新建或派生的角色书分支勾选「在新分支启用同书互斥组」。书架草稿的「试算同书互斥组」可检验当前编辑的条目。

## 选择顺序

1. 宿主先按目标成员的授权选择书版和可见历史。各封存书内分别判定，同名组可以用于多本独立书。
2. 在每一轮扫描中过滤停用、扫描深度、延迟、一次性、冷却、关键词／正则及已启用的条目概率。组内以 `priority` 最高的合格条目胜出，默认优先级为 0。同分按封存书中的原始条目顺序决定。插入顺序继续控制正文的位置。
3. 仅通过选择的正文参与递归匹配。先前扫描轮已经胜出的条目保留位置，后续递归发现的同组条目让位。
4. 继续应用单书和请求预算。若胜出条目因预算被排除，本次扫描不递补。若宿主因模型容量缩小历史窗口，则用最终可见的历史重新匹配和选组。组内让位与预算排除均不会取得一次性、持续或冷却的入史记录。

组名保存在条目 `extensions["modelmirror.exclusiveGroup"]`。字符串最多 64 个 UTF-16 代码单元，区分大小写，去除首尾空白后比较。留空或缺省表示独立触发，带控制字符、超长及非字符串值在匹配时标示无效并跳过该条目。原文件与其他扩展可往返。每条支持一个组，不按权重抽签，第三方的专有字段原样保存。这是模镜的独立实现。[CCv3 角色书字段](https://github.com/kwaroran/character-card-spec-v3/blob/f3a86af019fbd99f788f7a1155f399655b34ab35/SPEC_V3.md#lorebook-fields) · [World Info](https://docs.sillytavern.app/usage/core-concepts/worldinfo/)

## 预览、恢复与继承

预览标明组名、胜出条目的原书序号及最终纳入状态；已被概率或其他条件挡下的条目保留原有理由。组名和竞争信息只来自当前成员有权读取的书。正式发送保存相同的装配和请求哈希。精确重生成与回执恢复沿用原请求。派生分支继承锚点生效的策略及书版，后续请求在子分支视野内重新评选。旧分支沿用原有配置，启用新规则通过新分支完成。

## 离线复验

实验目录运行 `node --test character/book-library/exclusive.test.mjs`。独立预览用 `node character/book-library/exclusive-preview.mjs <新数据目录> 0 0`。打开「渡口信号簿」分支，输入「看信号」并预览。灯号优先级 1；旗号优先级 2，取得组内位置；钟号优先级 3，概率为 0，未进入竞争。可在书架试算中调整优先级或清空组名，对照结果。停止本次预览并返回前一工作树即可回退，两个副本独立保存。
