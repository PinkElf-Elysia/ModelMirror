# R5b 交付点 5 · 持续触发

新建或派生角色书分支时勾选“在新分支启用持续触发”。在 V3 卡内书或独立角色书条目的正文开头单独写 `@@keep_activate_after_match`，下一行写希望长期保留的知识。该声明无参数。书架上的草稿试算仅模拟首次触发。

## 生效时点

本平台沿用角色卡路线约定的“首次命中后持续”：普通发送的最终请求实际纳入该条目，并且完整回复已被采用为本分支的正式历史，才建立持续触发的依据。策略版本是 `keep-after-first-adopted-match/1`。[固定版本的 CCv3 规范](https://github.com/kwaroran/character-card-spec-v3/blob/f3a86af019fbd99f788f7a1155f399655b34ab35/SPEC_V3.md#keep_activate_after_match)将门槛表述为此前匹配超过一次。此处记录平台门槛，以便交换时识别语义差异。

| 操作 | 分支表现 |
|---|---|
| 预览、准备、派发、未知或失败 | 命中的预览可以显示“本轮入史后开始持续”。只有正式回复可作为依据。只读恢复、失败回执和部分文本都不会启动持续。 |
| 已采用的首次回复 | 后续轮次可省略关键词。预览显示“已持续触发”，可定位首次触发的回复。没有另行配置有效轮数，持续状态无固定到期时间。 |
| 预算不足或时序不满足 | 本轮排除条目，保留已经成立的依据。之后符合条件时可恢复纳入。 |
| 精确重生成 | 复用原请求上下文。生成候选不会建立或延长持续状态。 |
| 派生分支 | 仅从分支点之前或位于该点的可见正式回复取得依据。分别从玩家输入和随后的回复派生，继承结果可以不同。 |
| 同模板其他成员、换书与撤权 | 按成员实例、卡片或书的封存版本及条目位置分别识别。仅在可读来源中查找当前条目。换回原版时可沿用本分支已有的有效依据。 |

首次匹配遵循关键词、深度、受限正则和容量裁剪。持续后免去关键词匹配，禁用状态、成员可见性、时序和书及请求预算仍生效。“一次性”与“持续”写在同一组条件时会标记冲突并跳过；通过回退链作为两种备选时，按分支能力选择其一。模板和 PNG 导出保留装饰器原文和未知扩展。首次回复定位、分支策略和使用情况归会话保存。

## 离线验收

在实验目录执行 `node --test character/book-library/keep.test.mjs`。运行 `node character/book-library/keep-preview.mjs <独立目录> 0 0` 可启动中性预览。输入“蓝绳”后预览并生成一次离线回复，刷新，再预览“继续”。“系绳位置”持续出现，“当次标记”不命中。切换到另一成员预览“继续”，可对照成员隔离。

回退时停止本交付点的独立预览，保留该数据副本。交付点 4 原分支及其预览仍使用原宿主。
