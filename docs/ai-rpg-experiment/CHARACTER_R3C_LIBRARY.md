# R3c 角色库整理

从创作页的角色库可以按名称、卡片标签或个人标签搜索，按收藏及个人标签筛选，按最近更新或名称排序。勾选角色后可批量收藏、取消收藏、添加或移除个人标签。撤销恢复最近一次有效整理前各角色的状态。另一页面先写入时，当前页面需按最新修订重新选择。

“复制草稿”以已保存的当前草稿创建独立作品。“查看来源”展示已记录的导入文件、原始哈希、卡内来源、作者说明及复制来源。分发许可需根据原作者的声明判断。个人整理数据由本地创作库单独保存，角色卡导出只读取角色定义和对应版本。

导入检查区分原文件相同、完整角色定义相同两种情况。名称相同本身不足以判重。定义相同的资源包仍可能含不同媒体；可打开已有作品，也可将本次文件另存为新作品。显式另存 CHARX 保留本次资源绑定，重复同一操作返回同一作品，跨导入模式复用同一操作编号会被拒绝。
