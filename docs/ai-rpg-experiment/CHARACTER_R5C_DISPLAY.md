# R5c · 回复显示转换

打开「独立角色书 → 会话分支 → 回复显示设置」。勾选「启用显示转换」后，可把散文里的连续字面换行显示为段落，也可以把一段文字按字面替换或隐藏。点击「应用显示设置」，再展开回复下的「查看转换前原文」对照。默认显示原文。

- **设置范围**。当前标签页按分支族、分支与查看角色保存偏好。刷新同一页面可以恢复。新分支或另一成员从各自的设置开始。禁用浏览器会话存储时只在当前页面生效。
- **转换范围**。作用于具有生成记录的可见回复和显式打开的本次生成结果。开场、玩家输入、历史位置选择器、实际请求预览、原文和回执保持原样。换行规则复用群聊既有的散文保护；单个转义、代码、路径、URL 和结构化文本跳过自动换行。查找区分大小写，替换内容按纯文本一次展开。查找限 80、替换限 160 个 UTF-16 代码单元，每条限 512 次匹配、输出限 100000 个代码单元。超限时完整显示原文。页面不执行素材中的脚本、HTML 或正则替换程序。
- **原文核对**。「查看转换前原文」直接呈现入史正文。当前角色生成的消息还可展开「核对原始响应与回执」。此操作对照书架保存的已完成回执与独立夹具回执，验证请求、模型、目标成员和内容哈希，再返回原始响应文本、回执正文和核对用的哈希。历史继承的可见消息可以按消息引用核对；另一个分支的请求 ID、其他成员的回执和未完成结果不会作为本次生成回执返回。
- **刷新与重生成**。精确重生成在原上下文上产生独立候选。「查看本次响应与回执」显示该候选自己的正文和回执。显示设置可以随时修改，在请求准备和派发之间也不会改变预览哈希。回执读取不会派发或恢复请求。
- **兼容与回退**。本轮在角色书分支页面增加展示组件及只读 `display-receipt` 操作，书架格式、运行指纹、原有 `view` / `preview` / `send` 合同保持不变。关闭显示转换即可恢复默认阅读；也可以停止本轮预览，返回上一交付点的独立副本。

在实验目录运行 `node --test character/book-library/display.test.mjs character/group/message-display.test.mjs`。专用预览命令为 `node character/book-library/display-preview.mjs <新数据目录> 0 0`。预览预置一条原创中性夹具回复，使用「蓝牌 → 青色标记」即可同时验收替换与字面换行，并核对后续请求。原生选择器取消、真机软键盘／触控／系统返回及 R4c 真实供应商待证项沿用原记录。
