# R4c 对话与记忆提案

在 R4b 资料页进入「对话与记忆提案」，从一条单聊或群聊资料分支创建独立续聊。选择当前角色，发送消息，查看生成中的文字。完整回复到达后，点击「采用回复」才会把它写入后续对话。草稿按分支和角色保存在当前标签页。导出只读取所选角色的正式可见对话。

## 记忆提案

- 「从最近发言提取」最多取 6 条可见正式发言。宿主先按成员参与区间和接收范围筛选，再选择来源；开场、未采用的候选、生成中的文字、请求附件和其他成员私有资料均不作为提案输入。
- 自动提案默认关闭。启用时记录当前消息位置。本分支同时至多指定一个成员，累计 6 条新增可见发言触发一次。切换成员重新起算。分支以创建时的角色、身份、历史和有效资料快照开始，自动设置需重新开启。
- 提案使用独立的 `memory` 用途。输出仅接收正文和来源 ID／修订列表，必须与实际提供给模型的材料相符。同一成员、同一来源范围重复点击会复用已有请求。来源校验只能证明引用存在，内容是否正确由玩家判断。
- 玩家可以改写后采纳或拒绝。采纳把草稿与采纳事件在一次本地提交内写成成员私有的经历资料，沿用 R4b 的可见性规则。未采纳的正文只在提案面板显示。失败或格式错误会留在原请求上。
- 宿主提供提案调用次数及微美元子限额，默认均为零。手动和自动提案共享子限额，同时受来源和任务总额控制。浏览器只能开启或关闭自动触发。关闭自动提案会撤销尚处准备阶段的自动意图；已派发请求仍需核对原回执。

## 输出、中止与附件

普通回复使用独立的单聊／群聊消息合同。受控网关直接读取上游字节流，经完整 SSE 事件、文本、模型及凭据检查，保存可显示前缀。页面按 Unicode 码点游标增量读取。提案等待终态回执后才展示，推理字段和工具数据不作为显示片段。

- `GET /api/rpg/v1/authoring/live/{session_id}/{request_id}` 按 `sourceRequestHash` 和 `cursor` 查询原请求。
- `POST /api/rpg/v1/authoring/live/{session_id}/{request_id}/stop` 绑定相同的来源哈希。网关记录停止意图，活动执行者取消上游读取并退出 HTTP 响应上下文。终态已先到达时仍按原回执处理。
- 两个接口均使用现有 S2S 鉴权。浏览器只访问本机工作台的同源接口；凭据、模型路由、完整提示词、价格及授权留在宿主。
- 宿主按请求和成员保存附件，包括来源哈希、可见正文、游标和状态。两个标签页或宿主与浏览器同时读取时会校验已有前缀。重新打开只读取既有进度。网关暂时不可达时仍能查看已保存片段。
- 已派发后中止或丢失回执可能留下结果未知。未知继续占用调用和费用预留，后续仅查询原请求。供应商停止计算及最终费用需要供应商证据。派发前中断则允许在预算所有者证明未派发后显式关闭。部分文字保存在请求附件及原始受控证据中；只有采用的完整候选可以成为正式角色消息。

## 宿主组合和历史账本

受信任入口为 `character/live-memory/workspace.mjs` 的 `startLiveWorkspace(options)`。组合原入口、R4a、R4b 和 R4c 时，所有入口使用同一个任务预算所有者。R4c 使用独立账本 scope 和版本化运行指纹。页面的来源选择只接受 R4b 资料引用，分支读取不会修改原资料分支。

已有 R4a 预算时，向宿主提供 `legacyBudgetDirectory` 和原 `legacyBudgetPolicy`。旧验证器以历史配置验证并持有独占锁，新账本按来源承接历史占用、原初始余额和来源限额。若 R4a 本身承接过更早的账本，`prior` 还需提供该历史验证所需的原配置。存在未结请求或缺少历史所有权证明时拒绝交接。不要给原入口和新入口分别启动两个可用的预算所有者。

## 离线复现和回退

在实验目录运行 `node character/live-memory/preview.mjs <新的独立目录> <起始端口>`。预览建立两个原创中性人物、本地模拟受控服务及单聊和群聊来源。从指定端口起依次使用七个 loopback 端口，提案页为起始端口加五的 `/live`。测试工作台可用端口零，由操作系统分配监听端口。

组件回归运行 `node --test --test-concurrency=1 character/live-memory/*.test.mjs`。网关回归入口为 `server/tests/test_rpg_live_output.py`，包括实际 Node 宿主经 ASGI 到 MockTransport 的流式与中止验证。相关历史合同及旧存档说明见 [R4b 交接](./CHARACTER_R4B_HANDOFF.md)。

## 已有请求与回退

关闭本机页面或撤下新入口时，继续保留原预算所有者、请求绑定、输出附件和未结预留。对于已派发且结果未知的请求，只能按原来源和请求哈希读取进度或回执。所有权不能证明时应阻止新派发。真实验收④在宿主中止后仍计入一次调用及 US$0.018990；本轮整理未执行预算交接、账本写入或供应商对账。先前受权部署的是当时共享容器中的网关补丁。重建容器后的合同可用性须重新核对。

帮助入口为「审阅角色记忆提案与中止回复」。功能、回执、人工采纳及设备验收的证据边界见[本轮验收](./CHARACTER_R4C_ACCEPTANCE.md)。
