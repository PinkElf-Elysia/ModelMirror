# R6a 交付点 3 · 按封存版本导出图片 CHARX

在角色库打开一个可用的 V3.0 版本，进入「预览」中的「版本文件」，点击「导出此版本的 CHARX」。桌面编辑侧栏也有版本导出按钮。下载名中的版本号对应当前选择。原始文件有独立下载入口，其字节与导入时相同。

## 版本与图片

宿主的 `POST /rpg-app/api/authoring/characters/charx/export` 仅接收 `workId` 和 `versionId`，返回二进制附件。服务端先验证作品下的不可变版本，再从快照的角色定义、资源声明与肖像生成 ZIP。V2、缺少版本、跨作品版本和未绑定的包内图片会被拒绝。JSON、PNG 及仅保留混合原包的路径继续沿用既有接口。

- 按卡中资源声明的顺序和路径写出图片，同一路径只写一份。未知扩展及作者元数据保留封存时的值。远程 URI 保留为文本。
- 换过主肖像的版本导出实际采用的图片。原路径仅供肖像使用且格式一致时沿用该路径；若背景或其他用途还在引用旧图，新肖像使用独立路径，其他用途继续使用原字节。补充肖像的 V3 卡可以新增主图声明。
- 大图沿用导入时核验过的作品归属和内容哈希。普通 V3 JSON 角色也可从可用版本生成 CHARX。缺少包内文件时返回诊断。
- 写包限额与导入一致。写出后通过同一检查器再次核对，成功后才返回附件。导出的 ZIP 只含版本卡及其引用的包内图片。宿主设置、存储索引、会话、身份、记忆和回执均不参与打包。
