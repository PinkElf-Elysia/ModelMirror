# R5a 交付点 3 · V3 角色卡创作与离线运行

## 作者流程

在角色库打开草稿，在「作者与标签」编辑昵称、多语言说明和群开场，查看来源、创建时间与修改时间。V2 作品可先保存，再创建独立 V3 草稿。保存多语言说明时保留原卡中的未知语言键。

保存草稿或封存版本后，在「导出角色卡」选择 V3 PNG。导出器使用 UTF-8 JSON、Base64 和 PNG `tEXt/ccv3`。需要同时给旧读取器使用时，选「附 V2 兼容副本」并核对损失清单。导入发现两个有效版本时默认采用 V3。源文件仍可单独下载。静态肖像随图导出，动画或嵌入资源存在时先展示损失，资源 URI 保留。修改时间使用导出时的 Unix 秒，只写入导出副本。JSON 上限 16 MiB，PNG 上限 32 MiB。

在「开场与示例」选择「按发言整理示例」。独占一行的 `<START>` 开始一组，`{{user}}:` 或 `{{char}}:` 开始一条发言，后续正文可跨行。可调整组和发言顺序。只有核对原文差异并选择采用后才替换标准 `mes_example` 字符串。遇到混合换行、未知说话人或含糊标记时保留原文，显示无法解析的位置；作者可以继续用原文，或明确从空白重新整理。示例继续遵循上下文示例预算，聊天历史、角色书扫描和记忆提案均有独立来源。

## 正则触发合同

卡内 V3 条目可勾选 `use_regex`，每个主键写成 `/表达式/标志`。创作页可试算。进入会话前，在独立角色书页面为新建或派生分支勾选「在新分支启用 V3 受限正则」。策略版本为 `v3-bounded/1`。既有分支和精确重生成沿用冻结的原策略与上下文。启用分支内，独立角色书同样遵守成员授权、版本固定、书内递归和共同预算。

| 项目 | 支持范围 |
|---|---|
| 文法 | 字面字符、转义标点、换行、回车、制表符、点、字符类与区间、反向字符类、分组、选择、行锚点、贪婪重复 `? * + {n} {n,m}` |
| 标志 | `i` 折叠 ASCII 大小写，`m` 以 LF 识别行边界，`u` 按 Unicode 码点读取；中文可直接写入 |
| 诊断 | 未支持的标志、特殊分组、回溯引用、属性转义、惰性重复、可空表达式及超限分别说明。条目中任一模式有问题则跳过整条。有效主键取或；正则条目只以主键匹配触发 |
| 规模 | 每条至多 8 个主键，每个模式体 256 码点、4 层括号、显式重复上限 32、512 个状态；单次扫描限 16,384 个可见码点 |
| 整次请求 | 编译为有限自动机；每次访问状态或尝试边均扣步。所有可见书、递归轮和历史裁剪重算共用 1,000,000 步。耗尽时撤回本次所有正则命中，用普通条目重新装配；仅向当事成员展示可见诊断 |

预览和封存请求都从同一分支及成员读取策略和资料。旧书架通过精确源码指纹校验；新规则由分支明确启用。复验使用交付点 2 宿主新建中性存档，再由本版只读打开并比对书架文件和请求。

## 离线复验

从实验目录运行 `node --test character/v3/*.test.mjs`，并运行角色书、角色交换、创作页、群聊、分支及记忆回归。独立本机预览可执行 `node character/v3/preview.mjs <专用数据目录> <创作端口> <群聊端口>`。控制台输出角色和分支地址。输入“潮12”查看卡内条目“潮位编号”的命中；测试数据与夹具回执保存在指定目录。

规格依据为 [Character Card V3 f3a86af0](https://github.com/kwaroran/character-card-spec-v3/blob/f3a86af019fbd99f788f7a1155f399655b34ab35/SPEC_V3.md) 和 [Character Card V2 8083fb38](https://github.com/malfoyslastname/character-card-spec-v2/blob/8083fb388615ccbce768e97cbbd49d2b3214632c/spec_v2.md)。
