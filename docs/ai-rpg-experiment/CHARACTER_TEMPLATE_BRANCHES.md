# 封存版本比较与分支换版

在角色库打开一个封存版本，展开“比较封存版本”，选择同作品的对照版本。角色书分支页也可在确认前比较当前角色在锚点的版本和目标版本。比较覆盖角色定义、未知字段、展示设置、封存资源清单及角色绑定的独立书。长字段显示差异附近的节选，封存原文可分别在对应版本打开。

在“会话分支”选择来源分支、查看角色、继承位置和目标版本，先核对绑定，再确认派生。单聊保留玩家身份，后续使用新角色的单聊场景。群聊只替换选中的实例，保留原群场景、成员实例身份和历史开场。相同作品的另一名成员保留原绑定。创建子分支沿用家族的预算归属；派生及差异比较本身没有请求或费用。此入口使用独立角色书工作区的离线回执。

## 分支和状态

- 以消息 ID 和修订定位历史，子分支继承位置为当前末尾或所选消息之后。换版记录在继承位置生效。从子分支再次选择换版前的历史消息，使用那个时点的版本。已完成回复的精确重生成读取原请求上下文和模型快照。
- 参与区间和限定接收范围继续决定可见历史。不能用成员缺席、未加入或无权读取的消息作为该成员的换版锚点。单聊及群聊的原始版本配置和请求证据继续由原宿主核验。
- 资料按所属成员、可用修订及消息依赖筛选。只对锚点已经有效的前缀证明固定历史范围，追加新输入后仍可复核原消息。缺少来源的旧私有资料仍需审阅。R4b 独立记忆工作台的笔记没有跨库导入本入口。
- 角色绑定书按目标封存版本读取；会话和玩家书沿用锚点授权。卡内书条目使用完整定义、书级设置、格式和唯一匹配核对，保留能对齐的条目的已触发、持续及冷却状态。新增、改写或有歧义的条目重新开始，移除条目退出。再次换回旧版也不能恢复已经重置的状态。
- 待确认请求、尚未结束的整轮或无法核实的整轮状态阻止换版。含 R8 旁白的来源目前不能完整映射其历史可见范围，入口给出原因并拒绝派生。

## 验证与边界

中性夹具“钟楼记录员”提供两份封存版本，群聊使用该角色的两个独立实例。测试核对角色书重排、同 ID 冲突、变更后再次换回、独立书读者、缺席历史与限定范围、已证实记忆和未来资料、子分支原请求哈希、父分支历史和重启恢复。旧书库副本对照核对了原成员视图、预览结果与源文件哈希，并验证合法封装内的未知运行指纹仍被拒绝。

桌面 1150 像素的单聊与窄屏 390 像素的群聊均走通比较、选锚点、确认新分支、刷新与续聊预览。模型与真实语音均为零调用。设备延期、旧世界场景与 Provider 审计既有失败沿用 [R8 验收记录](./CHARACTER_R8_ACCEPTANCE.md)。R4c ①的人工采纳及精确端点、②的刷新后实时增量及精确端点待证。④仅证实宿主停止读取，供应商最终计费待证，保留 US$0.018990 未结预留。
