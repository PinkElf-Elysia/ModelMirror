# R5b 交付点 1 · 一次性角色书条目

在卡内 V3 角色书或独立书条目的正文首行写 `@@dont_activate_after_match`，下一行填写知识内容。支持 LF 和 CRLF。该行单独使用；带参数、附加装饰器、回退链和空正文沿用跳过诊断。源文件仍按原文导出。书架“模拟一次性条目尚未使用”可试算新条目，实际分支状态在“会话分支”面板查看。

创建或派生分支时勾选“在新分支启用一次性触发”，运行策略固定为 `once-on-history/1`。正则触发沿用独立的勾选项。每个角色成员在自己的分支中，对同一本封存书版的同一原始条目位置可使用一次。卡内来源按作品和精确模板版本固定。显示名、作者 ID 与书目的绑定层级都不会另发次数。

| 时点 | 记录 |
|---|---|
| 预览 | 先过滤授权并合并书，再从最终保留的可见历史、书预算和请求预算计算拟纳入项。预览只读，重复运行和裁剪不会消耗。 |
| 请求准备 | 通过修订、预览哈希和预算核验后，与请求及上下文哈希一次落盘保存最终条目标识。占用可由请求及其状态恢复。 |
| 完整回复入史 | 验证回执的请求、目标成员、模型和内容后，与正式回复一并写入使用记录，定位到该回复。重收原回执不再追加。 |
| 失败、中断与未知 | 已核验终态失败解除条目占用，费用沿用独立回执规则。未知、待派发、证据不一致或只查到部分结果时维持原状态。刷新不自动发送。 |
| 精确重生成 | 使用原上下文与原条目内容；候选不改变消耗位置。原请求若已计费或保留预算，继续由原账本处理。 |
| 派生与换书 | 按分支点复制覆盖至该位置的使用记录。停在触发轮玩家输入时可用，停在触发回复上或之后则已用。子分支独立发展。换书使用新的版本键，重新绑定原版可恢复原消耗。历史位置早于启用规则时，需显式启用。 |

独立预览仅使用本地夹具。从实验目录执行 `node character/book-library/once-preview.mjs <专用目录> <创作端口> <群聊端口>`，打开输出的回环地址。在“本次输入”填“查看登记簿”，可反复预览。点击生成离线夹具回复，再预览同一句话，结果可定位到已使用的回复。切换成员可分别验证。

专项回归命令为 `node --test character/book-library/once.test.mjs`。覆盖最终预算排除、同名成员与条目、多路径绑定去重、完整回执、失败与未知恢复、故障落盘边界、精确重生成、源版本切换和导出隔离。R5a 及更早的书架仅对已核验的精确源码描述符开放兼容读取。回退时停止专用预览，保留其副本，原书架继续由原宿主打开。扫描深度覆盖、周期、回退、持续、冷却、概率和互斥组均另行安排。
