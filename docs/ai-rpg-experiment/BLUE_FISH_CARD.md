## 编辑器与隔离

支持原有模块、预览、模板、撤销重做、草稿、Markdown 和 setting JSON 交换；导入 JSON 的未知顶层字段、世界书和快捷命令字段随导出保留。名称经过 HTML 转义；导入文件最多 2 MB。“带入聊天”上限 20,000 字符。

原卡在不具有同源权限的 sandbox iframe 运行。`bridge.js` 与父级 `blue-fish-storage.ts` 仅处理当前 iframe 的消息，使用独立存储命名空间、容量边界及本地文本下载；不会向原网站读取账户或发送数据。原 iframe 内下载在嵌套浏览器中未可靠落盘，现由父级验证文件名及大小后下载，已核对实际生成的 Markdown 和 JSON 文件。独立打开原始静态 HTML 不是持久化使用入口，应使用以上 RPG 页面。

SortableJS 1.15.0 和 MDI 7.2.96 按用户授权本地化，许可证随附 `public/vendor/`。`manifest.json` 记录来源和原文件哈希；MDI CSS 改本地字体地址，文本资源统一 LF；与上游字节不同的文件另记本地版本哈希，许可证正文不变。未新增 npm 生产依赖。
