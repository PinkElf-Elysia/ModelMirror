# 角色工作台界面改造与验收

日期：2026-11-14。基于 `codex/rpg-character-r2-fix` / `0cb019df` 的未提交 R1/R2 候选继续整理。范围包含前轮角色库、单角色创作、预览和独立对话，不仅是群聊页面。

## 用户体验变化

- `/characters` 默认进入角色库，可按角色名称及角色卡标签查找，继续编辑或预览已创建的版本。
- 创作按基础与肖像、人物设定、开场与示例、知识条目、补充指令、作者与标签分区。手机使用章节选择器；刷新保留当前章节。
- 知识条目可直接编辑关键词、内容和启用状态；标签使用普通输入框。高级 JSON 默认折叠，未编辑的扩展字段保留。
- 预览独立展示角色与候选开场，知识触发结果以可读说明呈现；完整发送内容保留在折叠区。
- “创建对话版本”明确表示本地不可变版本，不表示公开发布。草稿预览提供直接创建入口，已创建版本保持只读。
- 对话使用完整消息区和固定输入区，设置与记忆折叠；区分演示回复、等待、失败和原请求待核对。刷新不重新生成。
- 移除“首张正式素材尚未提供”等过时开发文案，减少角色库重复按钮。保留真正影响操作的兼容警告、版本说明与错误反馈。

## 实现与接口边界

仅改写 `character/editor.html`、`editor.css`、`editor.mjs`，新增 `editor.test.mjs`。复用原角色作品、预览、导入导出、版本、会话和事件接口；没有新增后端路由、依赖或数据迁移。

浏览器渲染知识条目时按字段更新完整角色书，不将可视化字段重新拼成缩减对象。无效 JSON 保留原文并阻止保存。保存中暂锁定编辑，修订冲突保留输入和浏览器备份。

角色库展示标签来自完整角色卡，不假定其与通用作品 metadata.tags 同步。目录详情读取失败仍保留打开入口。

旧单角色宿主、上下文装配、角色标准解析、世界合同、群预算与请求恢复代码均不改。UI 文件不进入既有角色、R1 或 R2 运行指纹。回退本轮三个界面文件并停止本轮预览即可恢复前一界面，保留数据。
