## 0. 一句话结论

模型市场目前更像"目录页"，不像"浏览器"。本方案对标浏览器的三大核心心智——**地址栏（搜索状态保留）+ 书签（收藏）+ 历史（最近浏览）**，外加快捷键与视觉细节统一，把模型市场升级为"模型浏览器"。全部纯前端、低风险。

## 3. 优化点（对标浏览器，全部纯视觉/交互）

### 🔴 P0：浏览器三大核心心智

**B1. 筛选/搜索/分页状态进 URL（返回保留）**
- 现状：搜索词、筛选、分页都在 `useState`，点模型进聊天再返回**全丢**。
- 改进：同步到 URL 参数（`?q=图像&free=1&page=2`），返回时状态完整保留。
- 价值：对标浏览器"返回=回到刚才在哪搜了什么"的核心心智，**最值钱的一项**。
- 成本：中（`useSearchParams` 已在使用，把 filters/searchTerm/visibleCount 双向绑定 URL）。

**B2. 模型收藏（书签）**
- 现状：只有"加入对比"，无收藏。
- 改进：模型卡片加"☆ 收藏"（localStorage 持久化 + 收藏优先排序），**复用 MCP 卡片收藏的成熟模式**。
- 价值：书签式复访，浏览器标配。
- 成本：低（模式已存在，复制 McpServerCard 的收藏实现）。

**B3. 最近浏览历史**
- 现状：点模型进 `/chat/:modelId` 不记录。
- 改进：进聊天时写 localStorage 最近浏览列表；列表页显示"最近浏览"区块，一键回访。
- 价值：历史回访，浏览器标配。
- 成本：低（localStorage 数组 + 列表页小区块）。

### 🟠 P1：快捷键 + 快速导航

**B4. 列表页快捷键**
- 现状：零快捷键。
- 改进：
  - `Cmd+K` / `/` 聚焦搜索框
  - `↑/↓` 结果间移动、`Enter` 进聊天、`Esc` 清空搜索
  - `j/k` 上下浏览
- 价值：效率工具感，浏览器 Cmd+L 心智。
- 成本：低（addEventListener + 搜索框 ref + 当前高亮 index state）。

**B5. 搜索词记忆 + 热门搜索**
- 现状：词不记忆。
- 改进：localStorage 记忆最近 N 个搜索词；搜索框下拉显示"最近搜索/热门搜索"。
- 成本：低。

**B6. 聊天页模型切换器**
- 现状：ChatPage 单模型，进聊天即离开列表。
- 改进：聊天页顶部加"模型名 + 最近浏览/对比模型一键切换"（轻量标签页替代）。
- 成本：中（ChatPage 布局，需谨慎）。

### 🟡 P2：视觉细节统一

**B7. 面包屑/当前位置**
- 现状：无多级面包屑。
- 改进：列表页顶部加"模型市场 › 搜索结果（N）"式当前位置指示。
- 成本：低。

**B8. 搜索防抖**
- 现状：逐字符重算全量过滤。
- 改进：150-200ms 防抖，减少大列表重算。
- 成本：低。

**B9. 空态/加载态细节**
- 现状：空态有引导，无 skeleton。
- 改进：搜索时显示轻量"正在过滤..."反馈；分页加载时按钮转 loading。
- 成本：低。
