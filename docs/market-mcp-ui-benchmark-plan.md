## 0. 一句话结论

延续工作流画布「对标 n8n / Coze / Dify」的**去装饰化 + 可扫描**思路，对模型招聘会与 MCP 工具选择做第二批优化。核心问题均为**信息过载 + 颜色滥用 + 状态语义不统一**。本文档给出两块共 **20 个优化点**，其中 **8 项低风险增量**建议本轮开工，其余标注可行性约束。

---

## 1. 背景与目标

- 上一批（工作流画布）已把编辑器从"静态结构图"升级为"可观测执行视图"，确立了三原则：**信息先于装饰、单一语义色、状态单点表达**。
- 本批把同一套原则应用到**资源发现/选择**场景：模型招聘会（`/models`）与 MCP 工具采购（`/mcps`）。
- 目标：让模型卡片与 MCP 卡片达到**可扫描、状态一眼可辨、交互反馈明确**的专业工具水准。

## 4. 可行性分析（关键约束）

### 4.1 测试约束（MCP 优化必须注意）

`McpServerCard.playwright-card.test.tsx` **把"精简、去技术化"方向固化了**：
- 断言可用卡**出现**："可用"、"主要能力"、4 个能力胶囊、"打开工具台"/"配置与使用"按钮、`connectionNote` 文案。
- 断言**不出现**："README 摘要/资料核验/适配批次/风险等级/生产验收门槛/受控连接"。
- 断言不可用卡**出现**"未适配"禁用按钮 + 具体原因文案。

**含义**：
- **C1/C2/C5（加工具数、状态色板、连接反馈）是安全增量**——工具数/权限是新语义，不触发"不出现"断言；状态色板是换色不改文案。
- 若要引入"风险等级/批次"等旧内部信息，会**直接违反**"不出现"断言，需同步更新测试。
- 统一卡片骨架（C10）时需保留上述断言文案（"可用"、"打开工具台"、"配置与使用"等）。

### 4.2 数据可用性

- C1 的"工具数/只读/需审批"数据来自 `McpCatalogAdapterStatus.tool_policies`，**已存在**，前端聚合即可，无需后端改动。
- M 系列全部为前端样式/交互改动，不触碰 `data/models.ts` 数据结构。
- 所有改动**保持纯前端**，后端契约零改动（延续上批原则）。

### 4.3 风险分级

| 级别 | 项 | 风险说明 |
|---|---|---|
| ✅ 低风险（本轮做） | M1/M2/M3/M5/M6/M7/M8/M10、C1/C2/C3/C5/C6/C7/C8/C9/C10 | 纯样式/纯交互，不改数据结构，测试约束可控 |
| ⚠️ 中风险（评估后做） | M4（分页+视图切换）、M9（基组件重构）、C4（工作流节点 schema 表单） | 布局/结构改动，影响面大，需独立排期 |

## 5. 实施批次

> 每批独立可验证，可单独合并。全部纯前端。

### 批次 1：模型招聘会卡片收敛（M1/M2/M3/M7/M8）—— ✅ 已实现
- **M1 按钮收敛**：竖排能力按钮 → 横排 wrap + 紧凑尺寸 + 去光晕（因测试约束保留全部能力入口，未折叠"更多能力"）
- **M2 标签收敛**：能力/输入模态标签统一中性灰，确认类标签（视频/图片/音频/批处理）统一次级灰
- **M3 状态单点**：主状态保留 emerald/slate 语义色，其余收敛中性灰
- **M7/M8**：卡片高度 340→300 自适应；价格/note 分段标签收敛为中性紧凑行

### 批次 2：模型招聘会交互增强（M5/M6/M10）—— ✅ 已实现
- **M5 已选条件条**：卡片区上方"已应用 N 个条件 · 清空全部"（计数含筛选+搜索）
- **M6 对比高亮**：加入对比的卡片橙色描边 + 光晕
- **M10 空态引导**：显示"已应用 N 个条件" + "清空条件，查看全部"按钮

### 批次 3：MCP 卡片信息与状态（C1/C2/C10）—— ✅ 已实现
- **C1 工具数摘要**：可用卡加"N 个工具 · 只读为主 / 含 N 个写入 · N 个需审批"（聚合 tool_policies）
- **C2 状态色板统一**：adapting=青、blocked=玫瑰红、planned=灰；amber 从不可用卡移除
- **C10 统一骨架**：可用/不可用卡统一 `min-h-[320px]`

### 批次 4：MCP 交互增强（C3/C5/C6/C8/C9）—— ◐ 部分完成（C7 未做）
- **C3 筛选拆四档** ✅：可用/适配中/已排期/未适配（不再合并 planned+adapting）；同步更新 2 个测试
- **C5 连接反馈** ✅：连接成功按钮绿色高亮 + ✓、错误条加 `role="alert"`
- **C6 安全区折叠** ✅：McpBrowserPanel"固定边界"默认摘要 + 展开详情
- **C8 收藏功能** ✅：本地收藏（localStorage）+ 收藏优先排序 + 卡片星标按钮
- **C9 分类条** ✅：主分类 3→6 个 + 横向滚动
- **C7 连接前步骤条** ❌：跨组件较大改动，未做
