## 教程重放

完成文章后刷新页面清除当前表单状态，按教程顺序操作：

1. 打开角色音色库，切换创建音色，填写“教程复验 · 旅店掌柜”。名称、模型和参考音频字段可见。
2. 通过文件选择器上传本机提示音。界面显示文件名、12.0 秒、本机试听控件；确认使用权后创建按钮可用。
3. 创建后进入“我的音色”，状态为“云端处理中”；点击“查询云端状态”后变为“可使用”。此处请求全部由本机 mock 响应。
4. 填写“旅店掌柜”，点击绑定；绑定列表出现对应音色。点击“试听 / 生成语音”进入沉浸语音。
5. 选择旅店掌柜绑定，填写教程中性示例，手动生成；历史显示“已保存”，播放控件和下载入口可用。下载成功。
6. 刷新后重新打开音色库及生成历史；音色、角色绑定和语音记录仍在，聊天为 0 回合。
