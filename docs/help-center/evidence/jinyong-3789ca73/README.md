1. 首页桌面 1440×1000：三张新世界并列，肥鱼助手独立一行，六个旧世界保留。
2. 平板 1000×900：金庸占首行，斗罗与龙族次行；手机 390×844：单列。手机 DOM clientWidth=scrollWidth=380，无横向溢出。
3. 首页进入斗罗、龙族、蓝色大肥鱼，均加载对应原卡；肥鱼独立编辑器显示保存、导入导出和带入聊天等既有控件。
4. 帮助文章写好后，从无历史的预览来源按步骤重放：金庸→序章→融合宇宙→中州→地方行走→沈砚/男/20岁/无门无派→洛阳茶棚问路→武学→命数选三条→人物帖。
5. 点击“以此人物帖进入聊天”，生成 0 回合空会话，490 字完整人物帖留在输入框。刷新后仍为 0 回合，姓名、年龄、三条命数及开局保留。
6. 点击发送，页面明确标注离线预览、不调用模型；随后显示已保存的第 1 回合。回首页的“接着上次的故事”可恢复同一会话。
