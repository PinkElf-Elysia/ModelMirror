1. 从首页进入“探索与创作”：斗罗、龙族与蓝色大肥鱼均可进入，其他六个世界和故障重读提示仍可用。

4. 打开档案并点击“带入聊天”：产生独立会话，0 回合，474 字符档案在可编辑输入框。刷新后姓名与开场完整保留；无自动模型请求。
