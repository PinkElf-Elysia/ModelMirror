1. Atom 1.0：预览器点击“检查订阅源”，识别 ModelMirror 主线为 Atom 1.0、20 条并显示三条摘要；工作流的真实模型调用完成，状态入口显示“监听中”。
2. RSS 2.0 泛化：在同一可见配置界面临时改为 GitHub Blog，识别为 RSS 2.0、10 条并显示三条摘要；未保存该临时改动，交付草稿仍是原 Atom 源。
3. SSRF 攻击：把地址改为 `https://127.0.0.1/private-feed.xml`，请求在发出前被拒绝。首次显示英文底层安全消息，定位为前端展示缺口；最小修复仅增加中文解释与回归测试，不修改后端拒绝逻辑。最终镜像在同一预览器复测为“此地址指向本机、内网或保留网络，不能访问。请使用无需登录的公网 HTTPS 订阅地址。”

确定性测试另外覆盖 Atom 模拟新增两条的稳定顺序、一次物化、ETag/304、租约恢复、版本/Feed 切换、XXE、DTD、响应和条目上限。公共 Feed 当前是否恰好更新不作为这些语义的证明。

## 回退

关闭 `WORKFLOW_RSS_TRIGGERS_ENABLED`，停用 RSS 部署，让 pending 执行完成或显式取消后再恢复旧镜像。不得删除草稿、历史版本、订阅或执行记录。旧运行器若重写 Store 可能丢失新增顶层 RSS 表；再次启用时只建立当前基线，不回放历史条目。首版仍是单实例文件 Store，不声明 HA、多 Worker 或任意崩溃点的副作用 exactly-once。
