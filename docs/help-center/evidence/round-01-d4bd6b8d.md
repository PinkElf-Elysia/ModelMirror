# 第一轮基线与验收记录

## 任务边界

- 单一目标：建立可持续扩展的帮助中心框架，并交付一条经过真实预览操作验证的“找到能看图片的模型并进入发送前状态”路径。
- 实施基线：`origin/main@d4bd6b8dc151b79001efc0bbe3f06e22716dae0a`。
- 实施工作树：`C:\tmp\modelmirror-help-center-round1-20260825-r3`。
- 明确不改：后端接口、数据库、持久化、共享容器、真实用户数据、模型调用合同和生产依赖。
- 文件超过 5 个的原因：本轮同时建立治理门禁、五篇不可拆分的首轮正式内容、首页、统一阅读框架、入口与自动化测试；各批次仍按单一可验证目标推进。

## 验收标准

1. 桌面和移动端均能在不改变六项资源导航数量与顺序的前提下进入帮助中心。
2. 首页五个区域均有真实入口；“按目标找指南”用于选择模型、Agent 或 Workflow，不重复罗列新手文章。
3. 一级索引、模块和展示的二级功能均可点击；所有页面使用左侧分级目录和右侧正文的统一阅读界面。
4. 第一次使用教程可在最新隔离预览中从清空状态重放两次，停在系统文件选择器，不选择或上传文件、不调用模型、不产生费用。
5. 桌面 `1440×900`、移动 `390×844` 可用，最低 `320px` 无横向溢出；配色使用克制的中性深色与单一青色主强调，不使用混乱的多色分类装饰。

## 风险、停止条件与回退

- 风险：最新模型目录、按钮文案、价格或可用状态可能与旧基线不同，所有操作性内容必须以本轮预览重新验证。
- 停止条件：导航挤压或遮挡、模型任务无法稳定重放、任何操作文案只能从源码推断、隔离环境可能影响共享栈。
- 回退：移除帮助路由、独立帮助入口、帮助内容和样式，并撤销本轮治理模板；不涉及后端、数据库或持久化迁移。
