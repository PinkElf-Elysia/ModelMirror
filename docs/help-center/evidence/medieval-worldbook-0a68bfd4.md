# 中世纪真实人生 · 世纪选择与续玩

2026-11-21，以 `main@0a68bfd4` 为基线重建主前端与卡片播放器。两次浏览器复演各使用独立端口、临时离线存储和全新浏览器上下文，浏览器请求限于本机预览。

| 操作 | 实际结果 |
|---|---|
| 从故事馆搜索“中世纪”，打开作品并点击“开启此生” | 可在“时代”页签选择 14 世纪。 |
| 点“选此时代”，打开“此生”，核对【时代】后点“以此角色进入聊天” | 档案与聊天草稿都显示 14 世纪。 |
| 发送开局，刷新会话，输入“去集市”并发送 | 两轮都返回离线回复，传输记录中的系统消息均逐字等于固定正文、名称库和第十四世纪正文的装配结果。 |
| 单独发送“切换到第五世纪” | 本轮系统消息改用第五世纪正文。 |
| 从新环境打开正式帮助页，经“RPG 故事馆”链接重走 | 再次完成上述操作。 |
