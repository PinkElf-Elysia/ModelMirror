1. 打开既有恢复帮助，核对“运行”“继续跟踪”“取消原运行”和“不重新派发”的顺序。实际浏览器结果截图视口为 1270x714；没有把源码检查代替页面操作。

4. 在等待草稿选择“运行”，输入合成文本并运行一次，看到“等待恢复”后重启后端，保留原页面。配置问题修正后点击“继续跟踪”，同一 task 完成，三个节点各一次完成。

6. 再次重启后端并超过取消任务的原唤醒时间，持久终态仍为 cancelled，等待与输出没有完成事件。此后不再运行任务；用户将补充结果截图。
