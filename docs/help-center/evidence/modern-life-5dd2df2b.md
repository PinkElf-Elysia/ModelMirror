# 《现代超真实人生》使用指南复演

2026-11-21，在 main 基线 `5dd2df2b` 加入本 PR 后构建前端与 RPG 界面，使用独立端口、临时存储和离线剧情提供方。首次演练从故事馆开始，第二次使用全新存储和独立浏览器源，从已写好的帮助文章开始。

| 操作 | 两次演练观察 |
| --- | --- |
| 在故事馆按完整名称搜索并打开卡片 | 打开五步建卡器，默认选中“现代现实”。 |
| 创建林禾，添加 NPC 余宁，填写“一起值班的社区志愿者” | 最终预览列出两人、关系及一名自建 NPC。 |
| 将预览带入聊天并刷新 | 界面显示 0 回合；两次刷新后输入框内容均与原草稿逐字一致。 |
| 手动发送、返回故事馆、选择一回合存档 | 两次均显示“第 1 回合 · 已保存 · 离线样例”，从故事馆返回各自原会话。 |
