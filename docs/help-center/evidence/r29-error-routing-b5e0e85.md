## 真实预览路径

1. 公网安全 GET 成功后把结构化结果交给真实 DeepSeek V4 Flash；运行完成，结果为公开 npm React 包的版本、许可证和名称。
2. 公网 GET 返回 503；节点生成固定安全回执，普通出口跳过，错误出口执行一次，工作流正常完成。
3. 目标为本机地址；SSRF 门禁在请求前终止工作流，错误出口没有绕过安全策略。
4. `/workflow/new` 存在旧本地草稿时出现阻塞式恢复选择；“恢复本地草稿”保留原图，“使用默认工作流新建”打开默认三节点图且不删除旧草稿。

## 已验证边界

- 可路由失败只产生固定 code、classification、节点身份、attempts 和安全文案。
- 401/403、凭据、配置、SSRF、DNS/TLS 安全策略、资源漂移和未知异常保持失败关闭。
- 成功与错误控制边互斥；未选择路径的副作用节点不运行。
- 错误出口本轮不包含自动重试；重试属于下一独立批次。

## 未验证边界

- 公共 App、Evaluation、Evolution、Planner 和写操作不在本轮可用范围。
- 本轮不证明多 Worker、HA、任意崩溃点 exactly-once 或外部站点长期可用性。
- 公网与模型调用仅使用公开合成数据；没有发送用户数据、仓库代码或真实密钥。

## 回退

停用包含错误出口的新发布版本后恢复旧镜像，避免旧运行器把 `error` 控制边当作普通成功边。草稿、历史版本和执行记录保留，不删除数据。
