## 实操与重放

使用独立 Chromium、全新浏览器上下文和新本地数据。首先操作真实页面核对按钮，修正文档中旧的“封存版本”“刷新会话”等文案；最终正文后再次清空浏览器状态，按指南完成两遍：

1. 从角色库新建灯塔向导，填写基础、人物设定与开场，保存刷新。
2. 预览展开称呼并检查知识输入，创建版本，核对只读状态和群聊链接。
3. 创建单聊、接收一次确定性回复，刷新消息不变，导出中性 JSON。
4. 携带版本进入群聊创建；指定观察员、两个离线模型、场景和开场，刷新保留表单。
5. 创建后仅一条开场；发送一次、换角色接话一次，保留未发草稿且不冒充群消息。
6. 列表检索、重新打开与刷新，仍为开场 + 玩家 + 两个离线回复共四条。
7. 手机模拟中检查无横向溢出，成员面板关闭后焦点返回。

最终构建中的两篇帮助实际打开：各一个 h1、三张图成功载入，无 pageerror 或外网请求。960px 桌面截图与干净主线 960px 角色入口进行视觉对照；新群聊主线没有对应页面，不伪造旧群图。手机为 390 CSS px、2 倍像素比例（PNG 宽 780）。图片只捕获页面，不含浏览器地址栏、凭据或正式材料。
